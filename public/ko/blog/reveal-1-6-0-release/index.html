Reveal을 사용한 DIY 사용자 지정 시각화

플랫폼에 대한 이 혁신적인 추가 기능을 통해 이제 대시보드 내에서 사용할 수 있는 차트 유형을 제어할 수 있습니다. 특정 요구 사항과 관련이 없는 기본 차트 유형을 제거하여 사용자 경험을 조정하십시오. 차트 유형을 효율적으로 구성하기 위해 사용자 지정 그룹을 만들어 직관적이고 사용자 친화적인 인터페이스를 보장하십시오.

더욱이 이름과 아이콘이 있는 사용자 지정 시각화를 4줄의 코드로 즉시 통합하여 데이터를 새롭고 흥미로운 방식으로 표시할 수 있는 무한한 가능성을 열 수 있습니다.

  1. 차트 유형 업데이트: ​기존 차트 유형을 업데이트하려면 revealView.chartTypes 속성에서 차트 유형을 찾으십시오. 차트 유형의 다양한 속성을 수정하여 이름을 바꾸거나, 아이콘을 변경하거나, 차트 유형 항목을 다시 그룹화하십시오.
var barConfig = revealView.chartTypes.find(x => x.chartType == 'BarChart'); 
barConfig.title = 'My Cool Bar'; 
barConfig.icon = 'https://help.revealbi.io/img/logo.png'; 
barConfig.groups = ["Enterprise Visualizations", "HR", "Some Other Category"];
  1. 차트 유형 제거: 제거하려는 차트 유형 항목의 인덱스를 찾은 다음 chartTypes 배열에서 제거하여 차트 유형을 제거하십시오.
var gridConfig = revealView.chartTypes.find(x => x.chartType == 'Grid'); 
revealView.chartTypes.splice(revealView.chartTypes.indexOf(gridConfig), 1);
  1. 사용자 지정 차트 유형 추가: 기존 차트 유형 항목을 업데이트하고 제거하는 것 외에도 차트 유형 드롭다운에 사용자 지정 시각화를 새 차트 유형으로 추가할 수도 있습니다.
revealView.chartTypes.push({ 
    title: "Custom Viz", 
    url: "https://host/customViz.html", // 사용자 지정 시각화에 대한 URL을 제공하십시오. 
    icon: "https://help.revealbi.io/img/logo.png", 
    groups: ["Custom Visualizations"] 
});

대화형 차트 필터링

Reveal의 최신 1.6.0 릴리스는 실시간 데이터 탐색 기능을 손쉽게 사용할 수 있도록 하는 동적 데이터 조작 기능인 대화형 차트 필터링을 도입합니다. 이 원활하고 직관적인 경험을 통해 대시보드를 즉시 필터링하여 데이터를 상호 작용하는 방식을 혁신할 수 있습니다. 작동 방식은 다음과 같습니다.

  1. 마우스를 올릴 때 사용할 수 있는 차트 작업을 활성화합니다. 활성화하려면 다음을 사용하십시오.
revealView.interactiveFilteringEnabled = true; 
$.ig.RevealSdkSettings.enableActionsOnHoverTooltip = true

  1. 차트 내의 모든 데이터 지점에 마우스를 올리고 클릭하여 대시보드를 해당 특정 데이터 지점으로 동적으로 필터링하십시오.

  2. 대시보드에서 선택 사항이 실시간으로 반영되도록 추가 필터를 추가하고 필터를 제거할 수 있습니다.

이 동적 기능을 통해 데이터를 기반으로 질문에 대한 답변을 얻는 데 필요한 통찰력을 쉽게 얻을 수 있으므로 데이터 탐색이 그 어느 때보다 매력적이고 직관적이 됩니다. 수동 필터 입력을 중단하고 Reveal을 통해 더욱 역동적이고 반응성이 뛰어난 데이터 검색을 경험하십시오.

모든 플랫폼

  • 라이선스 키 변경 사항: Reveal 1.6.0에서는 SDK 평가판 모드에서도 라이선스 키가 이제 필수입니다. 이 변경 사항은 보안 및 책임성을 향상시킵니다. 라이선스 형식도 업데이트되었습니다. 새로운 라이선스 키를 받으려면 영업 담당자에게 문의하거나 SDK 평가판 키를 등록하십시오..
  • availableChartTypes 속성이 제거되었습니다. 대체 속성은 아래의 '새로운 기능' 섹션에 설명된 'chartTypes' 속성입니다.
  • 크로스 플랫폼 성능을 향상시키기 위해 'libgdiplus'에 대한 종속성이 제거되었습니다.
  • SDK는 더 이상 Quill.js에 의존하지 않습니다.

ASP.NET

  • 대부분의 데이터 소스가 핵심 패키지에서 제거되었습니다. 이제 별도의 패키지로 제공됩니다. 데이터 소스 패키지는 반드시 등록되어야 합니다. 등록됨. 지원되는 데이터 소스 및 해당 추가 기능 NuGet 패키지에 대한 정보는 다음에서 확인할 수 있습니다. 여기.
  • Reveal은 이제 .NET 6.0 이상을 요구합니다.
  • 데이터 관련 개체가 Reveal.Sdk.Data 네임스페이스로 이동되었습니다.
  • 데이터 소스 개체(예: RVSqlServerDataSource)가 해당 네임스페이스(예: Reveal.Sdk.Data.Microsoft.SqlServer)로 이동되었습니다.

SDK 버전 1.6.1을 출시하게 되어 기쁩니다. 항상 여러분의 경험을 개선하고 Reveal을 사용하여 애플리케이션에 분석을 원활하게 통합할 수 있도록 최선을 다하고 있습니다. 이 릴리스에서 새롭고 업데이트된 내용을 자세히 살펴보겠습니다.

모든 플랫폼

  • 시각화 편집기에서 차트 유형으로 사용자 지정 시각화를 추가할 수 있습니다. 새로운 ‘chartTypes’ 속성을 통해 기존 차트 유형의 아이콘, 제목 및 그룹화를 수정하거나 사용할 수 없도록 설정할 수도 있습니다.

  • Reveal 1.6.0은 차트에 상호 작용 계층을 추가하는 베타 기능을 도입합니다. ‘Chart actions on hover’를 활성화하려면 $.ig.RevealSdkSettings.enableActionsOnHoverTooltip = true를 사용하십시오. 메뉴를 탐색할 필요 없이 정보와 기능에 액세스할 수 있으므로 데이터 탐색이 더 빠르고 직관적으로 이루어집니다.
  • 계산된 필드는 이제 선행 ‘0’ 없이 소수를 지원합니다(예: ‘.5’는 ‘0.5’를 의미). 이를 통해 데이터 계산에서 더 많은 유연성을 제공합니다. 또한 BigQuery 데이터 소스는 이제 다양한 계산된 필드 함수를 지원하여 분석의 다양성을 높입니다.
  • BigQuery 데이터 소스에 다음 계산된 필드 함수에 대한 지원이 추가되었습니다: YEAR, QUARTER, MONTH, DAY, HOUR, MINUTE, SECOND, REPLACE, WEEKDAY, MONTHNAME, MONTHSHORTNAME, EMPTY, RANDBETWEEN.
  • 복사 및 붙여넣기 기능은 이제 브라우저 탭과 페이지 새로 고침 간에 원활하게 작동하므로 중단 없이 효율적으로 작업할 수 있습니다.
  • RevealView는 이제 컨테이너 크기가 변경될 때 자동으로 크기가 조정되어 전반적인 사용자 환경을 향상시킵니다.
  • 저장 프로시저 지원이 Oracle 데이터 소스에 추가되어 데이터 분석의 새로운 가능성을 열었습니다.
  • Reveal은 이제 Athena 데이터 소스를 연결할 수 있으므로 여러 소스의 데이터를 통합하고 분석하는 것이 더 쉬워졌습니다.

버그 수정

모든 플랫폼

Reveal 1.6.0은 모든 플랫폼에서 더 원활하고 안정적인 환경을 제공하기 위해 수많은 버그 및 문제를 해결합니다.

  • 여러 메뉴 항목을 푸시할 때 menuItem 작업 함수가 마지막 작업 함수만 호출하는 문제를 해결하여 메뉴 항목이 예상대로 작동하도록 했습니다.
  • 도넛 차트는 이제 값에 대한 범례를 올바르게 표시하고 데이터를 정확하게 나타냅니다. 값
  • PDF로 내보낼 때 지정된 테마를 준수하여 내보낸 보고서에서 일관된 브랜딩과 스타일을 유지합니다.
  • 필터 내의 “X Selected” 또는 “Show All” 텍스트를 클릭하여 데이터 필터링을 더 직관적으로 수행할 수 있습니다.
  • “X Selected” 또는 “Show All” 텍스트에 대한 필터의 셀 배경은 이제 전체 너비를 차지하여 시각적으로 만족스럽고 일관된 인터페이스를 제공합니다.
  • 사용자 지정 테마 글꼴은 이제 KPI 시각화에 올바르게 적용되어 보고서 전체에서 일관된 모양과 느낌을 보장합니다.
  • JavaScript 클라이언트에서 정의된 Oracle 데이터 소스의 “제공자 ID가 지정되지 않았습니다…” 오류가 해결되어 중단 없는 데이터 검색이 가능합니다.
  • 데이터 선택 보기의 검색 창은 특정 시나리오에서 올바르게 재설정되어 사용자 탐색을 개선합니다.
  • 데이터 소스 대화 상자에서 테이블을 검색하면 오류나 충돌이 발생하지 않으므로 안정적인 환경을 유지합니다.
  • 기본 새로 고침 속도가 0이면 이미지 및 PDF 웹 리소스가 예상대로 로드되지 않습니다.
  • 숫자 형식이 이제 스파클라인, 게이지 도구 설명 및 기타 관련 시각화에 일관되게 적용되어 데이터 가독성을 향상시킵니다.
  • 게이지 도구 설명에 숫자 형식이 표시되지 않는 문제를 해결하여 데이터 통찰력을 더 정확하고 이해하기 쉽게 만들었습니다.
  • “NUMERIC” 데이터 유형, 분기별 집계 및 “MOD” 함수와 관련된 문제를 해결하여 BigQuery 함수가 분석에서 원활하게 작동하도록 했습니다.
  • BigQuery에는 분기별 집계가 누락되었지만 이 문제를 해결하여 데이터를 분기별로 원활하게 집계할 수 있습니다.
  • BigQuery의 “MOD” 함수를 사용하면 두 가지 다른 유형의 숫자 데이터(예: float64 및 int64)를 사용할 수 없습니다.
  • 스키마가 DataSourceItem에 설정되지 않은 경우 Postgres에서 “함수를 찾을 수 없습니다” 오류가 발생하던 문제가 해결되었습니다.
  • 데이터를 그리드로 볼 때 통계 함수가 올바르게 표시되어 더 포괄적인 데이터 통찰력을 제공합니다.
  • 차트 시각화를 XLSX로 내보내면 정확한 결과가 생성되어 시각화된 데이터의 무결성을 유지합니다.
  • BigQuery 추가 데이터 소스 화면에서 큰 데이터 세트를 스크롤할 때 체크박스 상태의 불일치가 해결되었습니다.
  • BigQuery DataSourceItem은 이제 프로젝트 ID가 DataSource에만 설정된 경우에도 올바르게 작동합니다.
  • 사용자 지정 날짜 형식이 있는 Excel 셀에서 가져온 데이터는 더 이상 날짜 유형으로 잘못 해석되지 않습니다.
  • 트리맵 시각화는 이제 숫자 형식을 올바르게 존중합니다.
  • 숫자 형식이 이제 금융 차트의 도구 설명에 정확하게 표시되어 금융 데이터 분석 환경을 향상시킵니다.
  • 숫자 형식이 이제 레이더 차트의 도구 설명에 정확하게 표시됩니다.
  • 10만 셀 제한 경고는 이제 Athena 및 BigQuery 데이터 소스에 대해 올바르게 표시됩니다.
  • Math 함수 ‘Log’는 이제 Athena 데이터 소스에서 예상대로 작동합니다.

ASP.NET

  • 헤드리스 및 대화형 모두에서 내보내기 기능은 이제 Linux 시스템에서 완벽하게 작동하여 호환성 옵션을 확장합니다.
  • ASP.NET 프로젝트에서 Microsoft.Data.SqlClient 버전 5.0.0 이상을 사용할 때 호환성 문제가 해결되어 Reveal과의 원활한 통합을 보장합니다.
  • Oracle 데이터 소스의 “자격 증명 확인” 오류가 해결되어 오류 없이 데이터를 검색할 수 있습니다.

Node

  • RVRESTDataSource에 대한 요청 헤더는 이제 Node SDK를 사용할 때 올바르게 작동하여 원활한 데이터 연결 및 제어를 보장합니다.

Java

  • BigQuery에서 읽은 데이터의 인코딩 문제가 이제 해결되었으며, 시스템의 기본 문자 집합이 UTF-8이 아닌 경우에도 해결됩니다.
  • IRVDataSourceProvider.changeDataSourceItem에서 null IRVUserContext 문제가 더 이상 발생하지 않으므로 데이터 공급자 환경이 더 원활해집니다.
