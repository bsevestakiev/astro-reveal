데이터는 모든 비즈니스의 핵심적인 부분입니다. 데이터에서 가치를 찾고 그 가치를 대상 청중에게 이해하기 쉬운 방식으로 제시하는 것에는 노력이 필요합니다. 단순히 숫자 행이 있는 스프레드시트를 제시하는 것만으로는 데이터의 가치를 보여주기에 충분하지 않습니다. 하지만 데이터가 이야기의 형태로 제시될 때, 사람들은 그 중요성을 이해하고 그에 따라 반응하기가 더 쉽습니다.

이것이 바로 데이터 기반 스토리텔링의 본질적인 힘입니다. 데이터 시각화 전문가 스티븐 퓨(Stephen Few)는 "숫자에는 전달해야 할 중요한 이야기가 있습니다. 그들은 명확하고 설득력 있는 목소리를 부여해 줄 당신에게 의존합니다."라고 말합니다. 데이터가 이해되지 않거나 설득력이 없다면, 아무도 그것에 행동하지 않을 것이고, 따라서 아무것도 변하지 않을 것입니다.

따라서 좋은 소식은 사람들이 이야기를 좋아한다는 것입니다. 스토리텔링은 항상 대상 청중을 교육하고, 설명하고, 영향을 미치는 강력한 기술이었습니다.

이 점을 염두에 두고, 데이터 기반 스토리텔링이 무엇인지, 데이터 기반 스토리텔링을 사용해야 하는 최고의 이유들, 스토리보드가 데이터 스토리텔링에 어떻게 도움이 되는지, 그리고 몇 가지 데이터 기반 스토리텔링 사례들을 심층 분석해 보겠습니다.

## **데이터 기반 스토리텔링이란 무엇인가요?**

그렇다면 데이터 기반 스토리텔링이란 정확히 무엇일까요? 간단히 말해, 데이터 기반 스토리텔링은 원시 데이터를 읽기 쉽고 이해하기 쉬운 평범한 이야기로 전환하여 통찰력을 행동으로 전환하는 능력을 의미합니다. 이는 [데이터 시각화](https://www.slingshotapp.io/blog/9-best-data-visualization-examples) 인포그래픽, 대시보드, 기타 시각적 요소를 통해 데이터 통찰력을 전달하는 구조화된 접근 방식입니다.

우리는 시각적으로 생각하도록 프로그래밍되어 있기 때문에, 데이터를 시각적 이야기로 변환하는 것은 비즈니스에서 데이터가 제공하는 가치를 활용하고자 하는 모든 사람에게 매우 중요합니다.

연구에 따르면 사람의 최소 75%가 시각 학습자라는 것이 밝혀졌습니다. 우리는 읽은 것의 10%, 들은 것의 15%, 본 것의 75%만을 기억합니다. 또한 우리는 텍스트보다 시각 정보를 60,000배 더 빠르게 처리하며 시각 정보에 집중하는 경향이 있습니다. 게다가, 우리는 사진을 최소 90%의 정확도로 기억하는 독특한 능력을 가지고 있습니다.

데이터 기반 스토리텔링은 조직 내부와 외부 모두에서 행동에 영향을 미칠 수 있습니다. 조직 내부에서는 팀이 무엇이 가장 중요한지 더 잘 이해하고 행동하도록 도울 수 있습니다. 조직 외부에서는 데이터 기반 스토리텔링이 원하는 행동을 동기 부여하는 데 사용됩니다. 이러한 행동의 몇 가지 예로는 뉴스레터 가입, 장바구니에 품목 추가, 또는 소셜 미디어에서 콘텐츠 확인 또는 공유가 있습니다.

![Data-Driven Storytelling](/images/2021/07/data-driven-storytelling-1024x238.png)

좋은 데이터 이야기는 세 가지 구성 요소로 이루어집니다.

- 데이터 분석
- 데이터 시각화
- 내러티브

### **데이터 분석**

데이터 분석 구성 요소는 좋은 이야기의 기반이 되므로, 데이터를 숙달하는 것은 과정의 필수적인 부분입니다. 데이터 스토리텔링은 실행 가능한 통찰력을 도출하기 위해 정확하고 최신 데이터가 필요합니다. 이것이 과정의 첫 번째 단계이며, 올바르게 수행되지 않으면 원하는 결과를 제공하지 못할 것입니다.

### **데이터 시각화**

시각화는 데이터 기반 이야기를 전달하는 매우 효과적인 방법입니다. 이는 청중의 참여를 유도하고, 감정을 자극하며, [데이터 기반 의사 결정](/blog/reveal-data-driven-decision-making)을 향상시킵니다.

[데이터 시각화](/glossary/data-visualization)는 그렇지 않았다면 놓쳤을 수 있는 추세와 패턴을 발견하는 데 도움을 줍니다. 또한 데이터를 이해하기 쉽고, 기억하기 쉬우며, 매력적인 방식으로 전달하는 데 도움을 줍니다.

데이터에서 수집된 통찰력은 차트, 인포그래픽, 표, 이미지, 그리고 [트리맵 차트](/blog/how-to-create-a-treemap)와 같은 기타 시각적 요소 및 심지어 비디오의 형태로 제시됩니다.

### **내러티브**

내러티브 구성 요소는 데이터를 설명하는 데 사용되는 단순한 언어에 관한 것입니다. 내러티브는 시각화와 통찰력을 가능한 가장 단순한 방식으로 지원하는 데 사용됩니다. 이는 주요 KPI 지표와 추세를 강조하고 의사 결정 과정을 가속화합니다.

## **데이터 기반 스토리텔링을 사용해야 하는 최고의 이유들**\*\*\*\*

스탠퍼드 대학교의 칩 히스(Chip Heath, Made to Stick 저자)의 연구에 따르면, [사람들의 63%는 이야기를 기억할 수 있었지만, 통계는 5%만이 기억할 수 있었다](https://mannerofspeaking.org/2009/10/13/making-it-stick-tell-stories/)고 합니다. 비록 이 연습에서 평균적으로 2.5개의 통계가 사용되었고 참가자의 단 10%만이 이야기를 통합했지만, 사람들의 주의를 사로잡은 것은 이야기였습니다.

이는 데이터 기반 문화를 주도하기 위해 데이터 스토리텔링을 사용하는 것이 얼마나 중요한지를 보여줍니다. 데이터 스토리텔링은 우리가 추세를 보고, 문제를 이해하거나, 웹사이트 또는 이메일 마케팅 캠페인이 어떻게 수행되고 있는지 해석할 수 있게 해주기 때문에 비즈니스에서 매우 귀중합니다. 데이터 자체만으로는 상황의 맥락에서 이해되어야 하므로 그러한 의미를 제공할 수 없습니다. 이야기의 요소를 사용하는 것은 우리가 맥락을 이해하는 데 도움을 줍니다.

커뮤니케이션 도구로서 데이터 기반 스토리텔링을 사용해야 하는 몇 가지 추가적인 이유들은 다음과 같습니다.

- **의미 및 가치** – 데이터 이야기는 데이터에 가치, 의미, 맥락을 추가하여 청중이 점들을 연결하고 통찰력을 행동으로 옮길 수 있게 합니다.
- **신뢰성** – 숫자와 사실은 주장을 입증하고 콘텐츠의 신뢰도를 높일 뿐만 아니라 청중과 신뢰할 수 있는 관계를 구축합니다.
- **주의 집중** – 훌륭한 데이터 기반 콘텐츠는 눈에 띄며, 완전히 새로운 청중에게 소개함으로써 브랜드를 높일 수 있습니다.
- **다용성** – 데이터 이야기는 사례 연구, 비디오, 웹사이트 콘텐츠, 프레젠테이션, 백서 등 많은 내부 및 외부 커뮤니케이션 채널에 통합될 수 있습니다.

일반적으로 조직은 데이터를 더 잘 이해한다면 훨씬 더 많은 것을 할 수 있고 더 큰 결과를 달성할 수 있습니다. [포브스 기사](https://www.forbes.com/sites/brentdykes/2020/01/22/why-data-storytellers-will-define-the-next-decade-of-data/?sh=4877f59a24fb)에서 Effective Data Storytelling: How to Drive Change with Data, Narrative, and Visuals의 저자인 브렌트 다이크스(Brent Dykes)는 "2020년, 데이터의 다음 10년으로 진입하면서, 당신은 데이터에 능통한 사람이 더 많이 필요할 것입니다. 직원과 관리자의 전반적인 데이터 리터러시 수준을 높이는 것과 더불어, 회사가 통찰력을 찾을 뿐만 아니라 그것을 명확하고 의미 있는 방식으로 공유할 수 있는 데이터 스토리텔러 집단을 개발하는 것이 필수적입니다."라고 씁니다.

따라서 조직은 데이터 기반 결정을 강화하고 실시간 상호 작용 데이터 시각화를 제공하는 BI 및 [임베디드 분석](/embedded-analytics) 도구에 투자해야 할 뿐만 아니라, 데이터 스토리텔러에게도 투자해야 합니다.

## **스토리보드는 데이터 스토리텔링에 어떻게 도움이 되나요**\*\*?

스토리보드는 만들 계획인 콘텐츠의 시각적 표현입니다. 데이터 스토리텔링에서 스토리보드 프로세스는 길고 복잡한 보고서에서 핵심 메시지와 데이터 요소를 추출하여 데이터 이야기를 전달하기 위해 순서대로 배열하는 훌륭한 방법입니다. 이 과정은 추상적인 아이디어를 실제 계획으로 변환하는 데 도움을 줍니다.

스토리보드 프로세스는 4단계로 쉽게 진행됩니다.

1. **개요 작성** – 스토리보드 프로세스의 첫 번째 단계에서는 핵심 데이터 포인트를 추출해야 합니다. 대상 청중에게 무엇을 말하고 싶습니까?

2. **스케치하기** – 이 단계를 사용하여 예상되는 모든 메시지를 원자재로 나열하고 스토리보드의 사각형 안에 스케치합니다. 데이터 이야기에 대한 모든 정보와 핵심 포인트를 수집했는지 확인하세요.

3. **스토리보드 배열** – 이 이야기가 어떻게 전개될지, 그리고 빠진 부분이 없는지 생각합니다.

4. **시각화 브레인스토밍** – 마지막 단계는 데이터를 어떻게 시각화할지 생각하고 다양한 아이디어를 시도하는 것입니다.

스토리보드 프로세스에서 가장 중요한 부분은 이야기에 포함하고 싶은 핵심 데이터 포인트와 메시지를 찾는 것입니다. 그 후, [시각화 편집기](/blog/visualization-editor)의 도움을 받아 데이터 이야기는 확실히 핵심을 짚을 것입니다.

## **데이터 기반 스토리텔링 사례**

이미 많은 브랜드들이 여러분이 깨닫지 못하는 사이에 데이터 스토리텔링을 사용하고 있습니다. 데이터 기반 스토리텔링이 얼마나 강력할 수 있는지 보여드리기 위해 이미 이 기술을 마스터한 브랜드 몇 가지 사례를 모았습니다.

### **스포티파이(Spotify)**

스포티파이는 최고의 예시 중 하나입니다. 이 스트리밍 서비스는 3억 4,500만 명의 사용자가 어떤 노래, 아티스트, 플레이리스트를 듣는지에 대한 데이터를 수집합니다. 그들은 수집된 데이터를 사용하여 각 사용자 개개인의 관심사에 맞춰 새로운 음악을 추천할 뿐만 아니라, 스포티파이 인사이트 블로그를 위한 독창적인 콘텐츠를 만듭니다.

[Spotify Wrapped](https://newsroom.spotify.com/2018-12-06/relive-your-year-in-music-with-spotify-wrapped-2018/)는 그들이 데이터를 사용하여 이야기를 전달하는 주목할 만한 예시입니다. 매년 말, 이 음악 앱은 지난 한 해 동안의 음악 감상을 요약하는 고유한 프레젠테이션을 각 사용자에게 만듭니다.

![spotify data-driven storytelling example](/images/2021/03/Spotify-data-driven-storytelling-example-1024x391.jpg)

### **우버(Uber)**

마찬가지로, 우버는 매년 데이터 스토리텔링을 사용하여 사용자들과 소통합니다.

"우리는 사람들이 우버가 [사용자]의 삶에서 어떤 역할을 하는지 상기시키고, 차량 공유 서비스의 사용이 매일 도시를 이동할 수 있게 해주는 파트너십임을 보여주고 싶었습니다." – 우버의 에샨 포나두란

![uber data-driven storytelling example](/images/2021/03/data-story-by-uber-1024x963.jpg)

우버가 정확한 데이터, 내러티브, 그리고 관련 시각화—좋은 데이터 스토리텔링의 세 가지 구성 요소 모두—를 어떻게 사용했는지 알 수 있습니다.

### **제2차 세계대전의 희생자들**

마지막 예시는 제2차 세계대전의 인간적 비용을 보여주는 데이터 기반 다큐멘터리입니다. 이 예시는 데이터가 이야기로 변환되는 방식이 매우 감동적이어서 매우 강력합니다.

결론적으로, 만약 귀하의 비즈니스에서 데이터 기반 스토리텔링을 사용하고 있지 않다면, 많은 것을 놓치고 있는 것입니다. 귀하의 조직은 복잡한 데이터 기반 비즈니스 결정을 내리고 귀하의 주장, 아이디어 및 관점의 가치를 뒷받침하는 데 도움을 줄 수 있는 풍부한 원시 데이터를 가지고 있을 가능성이 높습니다.
