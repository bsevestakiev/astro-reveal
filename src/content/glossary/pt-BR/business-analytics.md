## O que são Análises de Negócios?

Análise de negócios é a revisão e análise de dados para ajudar a impulsionar a tomada de decisões bem fundamentada. As empresas usam a análise para descobrir as causas raiz dos problemas, encontrar oportunidades de melhoria e tomar decisões na esperança de melhorar métricas chave, como satisfação do cliente ou receita. A análise de negócios é frequentemente parte de iniciativas de melhoria contínua, como Six Sigma, mas também pode ser um fator importante nas operações diárias do negócio.

## Os Principais Tipos de Análise de Negócios

Profissionais de análise sempre puderam extrair uma grande quantidade de insights dos dados, e quanto mais dados eles têm para trabalhar, melhores conclusões os analistas podem tirar. Mas a análise de negócios moderna frequentemente adiciona elementos de automação e aprendizado de máquina que tornam possível processar números em conjuntos de dados cada vez maiores em períodos de tempo mais curtos, colocando o poder das decisões baseadas em dados a serviço de organizações de qualquer tamanho ou tipo.

Um dos primeiros passos para aplicar a análise de negócios em sua organização é entender as três principais categorias de análise e quando você pode querer usá-las.

### Análise Descritiva

Análise descritiva faz exatamente o que parece: ela descreve o estado do que é ou foi. Quantos funcionários trabalharam ontem? Quantas unidades foram vendidas no mês passado? Qual é a velocidade média de uma resposta no call center nesta hora? Estas são todas perguntas que a análise descritiva pode responder.

Em algumas organizações, este tipo de análise é referido como business intelligence. É usado para responder a perguntas sobre o que está acontecendo agora e relatar métricas KPI. Os tomadores de decisão podem usar relatórios extraídos da análise descritiva para tomar decisões sobre:

![Description Analytics Chart](/images/2020/11/business-intelligence-descriptive-analytics.svg)

- Se precisam adicionar ou remover recursos de um processo para desempenho ideal e custo-eficácia
- Quais funcionários estão atingindo metas para que possam oferecer incentivos apropriados, e quais funcionários se beneficiariam de coaching adicional
- O que aconteceu durante um processo e quais causas raiz podem ter estado envolvidas em um resultado menos desejável

### Análise Preditiva

A análise preditiva usa dados existentes e métodos de análise estatística para fazer previsões de probabilidade sobre resultados futuros. Quantos widgets provavelmente serão vendidos no próximo trimestre? Quantas pessoas precisamos para cobrir os volumes de chamadas esperados para o próximo mês? Qual é uma meta realista, mas desafiadora, para definir para a receita do próximo ano? Estes são os tipos de perguntas que a análise preditiva responde.

Em algumas organizações, quando as pessoas falam sobre análise de negócios, elas estão se referindo principalmente à análise preditiva. Este tipo de análise ajuda os líderes a entender como planejar e alocar pessoal apropriadamente para o futuro, que tipos de receita podem ser esperados e como direcionar melhor as abordagens de marketing para impulsionar mais ROI.

![Forecast chart for Leads to New Sales Conversions](/images/2020/11/reveal-glossary-predictive-analytics-768x482.jpg)

### Análise Prescritiva

A análise prescritiva ajuda a prescrever uma solução potencial para uma pergunta ou preocupação. Ao usar uma combinação de dados descritivos e preditivos e métodos de análise prescritiva, profissionais experientes podem oferecer respostas para cenários "e se". O objetivo é usar dados de situações passadas para analisar o que pode acontecer no futuro e oferecer soluções que são estatisticamente prováveis de levar a melhores resultados.
