Os dados são uma parte crucial de qualquer negócio. Encontrar valor nos dados e apresentar esse valor ao seu público-alvo de uma maneira compreensível exige esforço. Simplesmente apresentar planilhas com linhas de números não é suficiente para exibir o valor dos dados. Mas quando os dados são apresentados na forma de uma história, é mais fácil para as pessoas entenderem sua importância e agirem de acordo.

E esse é essencialmente o poder da narrativa orientada por dados (data-driven storytelling). "Os números têm uma história importante para contar. Eles dependem de você para dar-lhes uma voz clara e convincente." – diz o especialista em visualização de dados Stephen Few. Se os dados não forem compreendidos e não forem convincentes, ninguém agirá sobre eles, e, portanto, nada mudará.

Então, a boa notícia é que as pessoas adoram histórias. Contar histórias sempre foi uma técnica poderosa para educar, explicar e influenciar um público-alvo ou uma ação desejada.

Com isso em mente, vamos mergulhar mais fundo no que é a narrativa orientada por dados, os principais motivos para usar essa técnica, como um storyboard ajuda na narrativa de dados e passar por alguns exemplos de narrativa orientada por dados.

## **O que é Narrativa Orientada por Dados?**

Então, o que exatamente é narrativa orientada por dados? Simplesmente, narrativa orientada por dados é a capacidade de transformar dados brutos em histórias simples, fáceis de ler e de entender, que nos ajudam a transformar insights em ações. É uma abordagem estruturada para comunicar insights de dados por meio de [visualização de dados](https://www.slingshotapp.io/blog/9-best-data-visualization-examples), infográficos, painéis e outros elementos visuais.

Somos programados para pensar visualmente, então transformar dados em uma história visual é crucial para qualquer pessoa que queira alavancar o valor que os dados fornecem em seu negócio.

Estudos mostraram que pelo menos 75% das pessoas são aprendizes visuais. Lembramos apenas 10% do que lemos, 15% do que ouvimos e 75% do que vemos. Também processamos visuais 60.000 vezes mais rápido do que o texto e tendemos a focar em informações visuais. Além disso, temos a capacidade única de lembrar de imagens com pelo menos 90% de precisão.

A narrativa orientada por dados pode influenciar ações dentro e fora de uma organização. Dentro da organização, pode ajudar sua equipe a entender melhor o que é mais importante e agir sobre isso. Fora da organização, a narrativa orientada por dados é usada para motivar a ação desejada. Alguns exemplos de tais ações são se inscrever em uma newsletter, adicionar um item ao seu carrinho e finalizar a compra ou compartilhar conteúdo em mídias sociais.

![Data-Driven Storytelling](/images/2021/07/data-driven-storytelling-1024x238.png)

Uma boa história de dados é formada por três componentes:

- Análise de dados
- Visualização de dados
- Narrativa

### **Análise de dados**

O componente de análise de dados é a base de uma boa história; portanto, dominar seus dados é uma parte essencial do processo. A narrativa de dados exige dados precisos e atualizados para derivar insights acionáveis. Este é o primeiro passo do processo; se não for feito corretamente, não entregará os resultados desejados.

### **Visualização de dados**

As visualizações são uma maneira altamente eficaz de contar uma história orientada por dados. Elas engajam o público, desencadeiam emoções e aprimoram a [tomada de decisão orientada por dados](/blog/reveal-data-driven-decision-making).

[Visualização de dados](/glossary/data-visualization) ajuda-nos a identificar tendências e padrões que, de outra forma, poderiam ser perdidos. Também nos ajuda a transmitir o significado dos dados de uma maneira que é compreensível, memorável e atraente.

Os insights coletados dos dados são apresentados na forma de gráficos, infográficos, tabelas, imagens e outros elementos visuais, como um [gráfico de treemap](/blog/how-to-create-a-treemap) e até vídeos.

### **Narrativa**

O componente narrativo é sobre a linguagem simples usada para descrever os dados. Uma narrativa é usada para apoiar as visualizações e os insights da maneira mais simples possível. Ela destaca métricas de KPIs e tendências, e acelera o processo de tomada de decisão.

## **Principais Motivos para Usar Narrativa Orientada por Dados**\*\*\*\*

Um estudo do professor Chip Heath de Stanford (autor de Made to Stick) descobriu que [63% das pessoas conseguiam lembrar de histórias, enquanto apenas 5% conseguiam lembrar de estatísticas](https://mannerofspeaking.org/2009/10/13/making-it-stick-tell-stories/). Embora 2,5 estatísticas tenham sido usadas em média no exercício e apenas 10% dos participantes tenham incorporado uma história, foram as histórias que capturaram a atenção das pessoas.

Isso mostra quão importante é usar a narrativa de dados para impulsionar uma cultura orientada por dados. A narrativa de dados é inestimável nos negócios porque nos permite ver tendências, entender problemas ou interpretar como nosso site ou nossas campanhas de marketing por e-mail estão performando. Os dados por si só não podem fornecer esse significado porque devem ser compreendidos no contexto da situação. Usar elementos da história ajuda-nos a entender o contexto.

Aqui estão alguns motivos adicionais para usar a narrativa orientada por dados como ferramenta de comunicação:

- **Significado e valor** – as histórias de dados adicionam valor, significado e contexto aos dados para que o público possa conectar os pontos e colocar os insights em ação.
- **Credibilidade** – números e fatos podem validar suas alegações e aumentar a credibilidade de seu conteúdo, bem como construir relacionamentos confiáveis com seu público.
- **Atenção** – um ótimo conteúdo orientado por dados se destaca e pode elevar sua marca ao apresentá-la a um público totalmente novo.
- **Versatilidade** – as histórias de dados podem ser incorporadas em muitos canais de comunicação internos e externos, como estudos de caso, vídeos, conteúdo de site, apresentações, white papers e muito mais.

Em geral, as organizações podem fazer muito mais e alcançar melhores resultados usando seus dados se os entenderem melhor. [Em um artigo da Forbes](https://www.forbes.com/sites/brentdykes/2020/01/22/why-data-storytellers-will-define-the-next-decade-of-data/?sh=4877f59a24fb), Brent Dykes, autor de Effective Data Storytelling: How to Drive Change with Data, Narrative, and Visuals, escreve: "Em 2020, à medida que entramos na próxima década de dados, você precisará de mais pessoas que sejam fluentes em dados. Além de aumentar os níveis gerais de literacia de dados de seus funcionários e gerentes, é imperativo que sua empresa comece a desenvolver um grupo de contadores de histórias de dados que não apenas encontrem insights, mas que os compartilhem de maneiras claras e significativas."

Portanto, sua organização não deve apenas investir em ferramentas de BI e [análise incorporada](/embedded-analytics) que capacitam decisões orientadas por dados e trazem visualizações de dados interativas em tempo real, mas também deve investir em contadores de histórias de dados.

## **Como o Storyboarding Ajuda na Narrativa de Dados**\*\*?**

Storyboards são representações visuais do conteúdo que você planeja criar. Na narrativa de dados, o processo de storyboarding é uma ótima maneira de extrair a mensagem principal e os elementos de dados de relatórios longos e complexos e organizá-los em ordem para contar sua história de dados. Este processo ajuda a transformar ideias abstratas em planos reais.

O processo de storyboarding em 4 etapas fáceis:

1. **Esboço (Outline)** – na primeira etapa do processo de storyboard, você deve extrair os pontos de dados principais: o que você quer contar ao seu público-alvo?

2. **Esboçar (Sketch it)** – use esta etapa para listar todas as mensagens que você antecipa precisar como material bruto e esboçá-las nos quadrados do seu storyboard. Certifique-se de ter reunido todas as informações e pontos-chave para sua história de dados.

3. **Organizar o storyboard** – pense em como esta história se desenrolará e se há algum ponto que está faltando e que você não precisará.

4. **Brainstorm de visualizações** – a última etapa é pensar em como você visualizará seus dados e experimentar diferentes ideias.

A parte mais importante do processo de storyboarding é encontrar os pontos de dados e as mensagens-chave que você deseja incluir em sua história. Depois disso, e com a ajuda de um [editor de visualização](/blog/visualization-editor), sua história de dados certamente estará no ponto.

## **Exemplos de Narrativa Orientada por Dados**

Muitas marcas já usam a narrativa de dados sem que você perceba. Reunimos alguns exemplos de marcas que já dominaram a narrativa orientada por dados para que você possa ver quão poderosa ela pode ser.

### **Spotify**

O Spotify é um dos melhores exemplos. O serviço de streaming coleta dados sobre quais músicas, artistas e playlists seus 345 milhões de usuários ouvem. Eles usam os dados coletados para sugerir novas músicas a cada um desses usuários, atendendo aos seus interesses individuais, bem como para criar conteúdo original para o blog Spotify Insights.

[Spotify Wrapped](https://newsroom.spotify.com/2018-12-06/relive-your-year-in-music-with-spotify-wrapped-2018/) é um exemplo notável de como eles usam dados para contar uma história. No final de cada ano, o aplicativo de música cria uma apresentação única para cada usuário, resumindo o ano passado em audição de música.

![spotify data-driven storytelling example](/images/2021/03/Spotify-data-driven-storytelling-example-1024x391.jpg)

### **Uber**

Da mesma forma, o Uber usa a narrativa de dados para se comunicar com seus usuários anualmente.

"Queríamos lembrar às pessoas do papel que o Uber desempenha na vida dos [usuários] e demonstrar como o uso do serviço de transporte por aplicativo é uma parceria que lhes permite se mover pelas cidades todos os dias." – Eshan Ponnaduran, da Uber

![uber data-driven storytelling example](/images/2021/03/data-story-by-uber-1024x963.jpg)

Você pode ver como o Uber usou dados precisos, narrativa e visuais relevantes – os três componentes de uma boa narrativa de dados.

### **Os Caídos da Segunda Guerra Mundial**

E o último exemplo é um documentário orientado por dados que ilustra o custo humano da Segunda Guerra Mundial. Este exemplo é muito poderoso porque a maneira como os dados foram transformados em história é muito emocional.

Em conclusão, diremos que se você não está usando a narrativa orientada por dados em seu negócio, você está perdendo muito. Sua organização provavelmente tem dados brutos abundantes esperando para ajudar você e sua equipe a tomar decisões de negócios complexas e orientadas por dados e apoiar o valor de suas alegações, ideias e pontos de vista.
