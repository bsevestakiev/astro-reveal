## O Que São Análises Contextuais?

Os dados por si só nem sempre fornecem todo o valor que podem oferecer. Quando as pessoas estão olhando para números brutos, acham difícil interpretar e entender os insights escondidos nos dados e, portanto, não conseguem usá-los estrategicamente para melhorar suas decisões. Análise contextual leva em consideração o contexto específico em que os dados são coletados, em vez de simplesmente analisar os dados isoladamente. Este contexto pode incluir informações sobre tempo, localização e outros fatores que podem influenciar os dados.

O objetivo da análise contextual é ajudar os usuários a identificar o contexto da situação com base em similaridades, restrições, caminhos e comunidades sem ter que alternar entre janelas e aplicativos para obter os dados de que precisam para tomar decisões de negócios informadas.

## Como Funciona a Análise Contextual?

Análise contextual ou análise enriquecida por contexto é a fusão de capacidades analíticas e das aplicações de negócios em que são incorporadas para tornar os dados mais contextualizados e personalizados em benefício do usuário final.

Em outras palavras, podemos chamar análise contextual de [análise incorporada](/embedded-analytics). E, como qualquer análise, elas transformam dados brutos em [gráficos fáceis de digerir](/glossary/embedded-charts) e [painéis](/glossary/embedded-dashboard) que fornecem uma visão lógica e contextual dos dados com os quais os funcionários de negócios trabalham, nos aplicativos em que trabalham. Esses gráficos e painéis representam dados contextuais que melhoram a usabilidade dos dados para usuários de negócios para uma melhor tomada de decisões.

## Para Que Posso Usar Dados Contextuais?

Dados contextuais ajudam a revelar onde e como os processos e decisões podem ser melhorados e otimizados para o desempenho e lucratividade máximos. Aqui estão alguns exemplos de como os dados contextuais podem ser usados:

**Análise preditiva** – Os dados contextuais podem ser usados para criar modelos preditivos que podem antecipar comportamentos ou resultados futuros com base em padrões passados. Por exemplo, usar [análise preditiva na área da saúde](/blog/predictive-analytics-in-healthcare) pode ajudar a identificar grupos expostos a um possível surto de doenças. Em tal cenário, os profissionais de saúde podem começar a procurar tratamentos imediatamente, o que melhora as chances de sobrevivência das pessoas.

**Tomada de decisão** – Os dados contextuais podem ser usados para tomar decisões mais informadas e precisas, fornecendo informações adicionais sobre uma situação ou ambiente. Por exemplo, [dados de fabricação em tempo real](/manufacturing-analytics) de inúmeras fontes como máquinas, pedidos, entrega e pessoas podem ser usados para estimar prazos de envio, capacidades de produção da linha de produção, disponibilidade de espaço de armazém e muito mais.

**Segurança** – Ao fornecer informações adicionais sobre uma pessoa ou situação, os dados contextuais também podem ser usados para aprimorar medidas de segurança. Um exemplo é a tecnologia de reconhecimento facial que pode usar dados contextuais para identificar indivíduos em uma multidão.

**Marketing** – Em marketing, dados contextuais são reis e podem ser usados para influenciar o comportamento do consumidor, segmentando públicos específicos com conteúdo ou anúncios relevantes com base em sua localização, interesses, interações, etc.
