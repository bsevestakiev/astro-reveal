<p class="wp-block-paragraph">Neste primeiro ponto da nossa lista de recursos, exploraremos os recursos fundamentais que devem estar no coração de qualquer ferramenta de BI incorporado. Esses recursos essenciais formam a base de uma solução analítica versátil e poderosa e não devem ser negligenciados. Ao iniciar sua jornada para selecionar o fornecedor certo de BI incorporado, preste muita atenção a esses blocos de construção essenciais. Eles o capacitarão a desbloquear todo o potencial de seus dados e criar uma experiência analítica excepcional.</p>

<ul>
<li><strong>SDK Incorporado Verdadeiro:</strong> Um kit de desenvolvimento de software (SDK) incorporado verdadeiro elimina a necessidade de iFrames e dá aos desenvolvedores controle total sobre como a análise é apresentada dentro do seu aplicativo. Com suporte completo de API tanto no lado do cliente quanto no lado do servidor, você pode integrar a análise rapidamente e gerenciar tudo – desde o deployment até o visual completo do app.</li>
<li><strong>Conectividade de Dados</strong>: Para garantir uma base robusta, certifique-se de que a ferramenta que você está avaliando suporte uma gama diversificada de <a href="/data-sources">fontes de dados</a>, como APIs, bancos de dados SQL, armazenamento em nuvem e mais.</li>
<li><strong>Visualização de Dados:</strong> Procure uma rica biblioteca de gráficos, diagramas e outras <a href="/chart-types">ferramentas de visualização de dados</a>, incluindo visualizações geoespaciais e mapas de calor, e a capacidade de <a href="/blog/diy-custom-data-visualizations">criar visualizações personalizadas</a>. A capacidade de criar visualizações personalizadas permite uma representação adaptada dos dados, garantindo que os insights sejam transmitidos de forma eficaz e intuitiva.</li>
<li><strong>Painéis interativos:</strong> Indo além dos painéis estáticos, a ferramenta de BI incorporada que você escolher também deve facilitar painéis dinâmicos e interativos. Recursos como drill-down e filtragem são primordiais, permitindo que os usuários naveguem por camadas de dados para insights mais profundos.</li>
</ul>

<p class="wp-block-paragraph">Ao avaliar fornecedores de BI incorporado, o foco na experiência do desenvolvedor dentro do SDK torna-se um fator crítico para determinar o sucesso do conceito de prova e das fases de implementação do seu projeto de BI.</p>

<p>Aqui está o que procurar:</p>
<ul>
<li><strong>Disponibilidade de SDK:</strong> SDKs do lado do cliente adaptados para linguagens de programação modernas, como C#, JavaScript ou TypeScript, são essenciais para alcançar maior personalização e controle durante a implantação. Igualmente importantes são os SDKs de servidor compatíveis com tecnologias back-end comuns, como .NET Core, Node.js e Java.</li>

Um SDK bem documentado garante que os desenvolvedores possam navegar pelas complexidades da solução de BI incorporada, promovendo um processo de integração suave e reduzindo a curva de aprendizado.</li>
<li><strong>Amostras e treinamento:</strong> Fornecer exemplos abrangentes de ponta a ponta sobre <a href="https://github.com/" target="_blank" rel="noopener">GitHub</a> tanto para recursos do cliente quanto para recursos do servidor, juntamente com treinamento em vídeo passo a passo e guias acompanhantes, equipará sua equipe de desenvolvimento com todos os recursos necessários para integrar a solução em sua aplicação sem problemas.</li>
<li><strong>Problemas, bugs e transparência do roadmap:</strong> O acesso ao GitHub para postar novos problemas, visualizar e comentar em problemas existentes, bem como o acesso ao roadmap e notas de lançamento, inspira confiança na equipe de desenvolvimento. Esse acesso garante que o fornecedor mantenha a transparência em relação aos seus processos e ao estado atual do produto.</li>
</ul>

<h2 class="wp-block-heading whitepapers__headline-dividers" id="chapter-3">Recursos de Análise de Dados</h2>

<div class="whitepapers__chapter-breadcrumbs d-block d-md-none mt-3 mb-4"><ul class="list-inline list-inline--piped"><li class="list-inline-item"><a href="#chapter-1" class="">Capítulo 1</a></li><li class="list-inline-item"><a href="#chapter-2" class="">Capítulo 2</a></li><li class="list-inline-item"><a href="#chapter-3" class="text-secondary">Capítulo 3</a></li><li class="list-inline-item"><a href="#chapter-4" class="">Capítulo 4</a></li><li class="list-inline-item"><a href="#chapter-5" class="">Capítulo 5</a></li><li class="list-inline-item"><a href="#chapter-6" class="">Capítulo 6</a></li><li class="list-inline-item"><a href="#chapter-7" class="">Capítulo 7</a></li><li class="list-inline-item"><a href="#chapter-8" class="">Capítulo 8</a></li></ul></div>

<p class="wp-block-paragraph">Em relação à análise incorporada de autoatendimento, a prioridade para seus clientes e usuários finais é a "<a href="/blog/reveal-embedded-analytics-ease-of-use">facilidade de uso</a>". Seus clientes esperam uma experiência simples para criar visualizações e painéis, visualizar dados subjacentes e tirar conclusões sem treinamento especializado ou envolvimento de TI. Reconhecendo essa demanda, os principais recursos de análise de dados de BI incorporado se tornam componentes cruciais para facilitar uma experiência analítica perfeita e intuitiva para seus usuários.</p>

<figure class="wp-block-image size-full text-center"><img decoding="async" src="/images/2024/01/reveal-embedded-dashboard.png" alt="Data Analysis Features" title="Data Analysis Features"/></figure>

<p class="wp-block-paragraph">As <a href="/features">principais recursos de análise de dados de BI incorporado</a> você deve procurar, incluindo:</p>

<ul>
<li><strong>Filtragem e exploração de painéis de dados ad-hoc:</strong> Habilitar a filtragem e exploração de painéis de dados ad-hoc concede aos usuários a flexibilidade de ajustar e refinar dinamicamente suas visualizações de dados em tempo real.</li>
<li><strong>Drill-down de séries temporais:</strong> O recurso de análise de dados de drill-down de séries temporais permite que os usuários naveguem perfeitamente por dados temporais, descobrindo tendências e padrões em diferentes granularidades.</li>
<li><strong>Drill-down hierárquico:</strong> Com o drill-down hierárquico, os usuários podem se aprofundar em hierarquias dentro de seus conjuntos de dados, obtendo uma compreensão abrangente de como os elementos de dados são estruturados e interconectados.</li>
<li><strong>Junção e mesclagem de dados:</strong> A capacidade de <a href="/blog/data-blending">juntar e mesclar conjuntos de dados díspares</a> garante uma análise holística. Permite que os usuários reúnam múltiplas fontes em uma única visualização para uma visão mais profunda e lado a lado.</li>
<li><strong>Vinculação de painéis:</strong> O objetivo do <a href="/blog/dashboard-linking">vinculação de painéis</a> é simplificar o processo de análise de dados, fornecendo uma experiência de usuário perfeita e coesa, permitindo que os usuários naveguem por painéis relevantes sem sair do aplicativo de software que já estão usando.</li>
<li><strong>Campos calculados e personalizados</strong> – Outro recurso de BI incorporado essencial que permite aos usuários extrair e manipular dados de colunas de texto sem esforço, simplificando o processo de análise de dados.</li>
<li><strong>Dicas de ferramentas com valores de dados e resumos:</strong> Dicas de ferramentas enriquecidas com valores de dados e resumos fornecem aos usuários contexto imediato. Os usuários podem passar o mouse sobre elementos visuais para obter uma rápida compreensão dos dados subjacentes.</li>
<li><strong>Anotar e exportar visualizações como imagens:</strong> Anotações e a capacidade de exportar visualizações como imagens aprimoram o poder comunicativo dos dados. Os usuários podem adicionar contexto a elementos visuais e compartilhá-los facilmente, apoiando a colaboração e o compartilhamento de conhecimento.</li>
<li><strong>Funções estatísticas como Regressão, Previsão e Outliers:</strong> Integrar funções estatísticas como regressão, previsão e detecção de outliers permite que os usuários realizem análises avançadas, desbloqueando insights mais profundos e capacidades preditivas.</li>
<li><strong>Exportação:</strong> A capacidade de exportar painéis e visualizações permite o compartilhamento e a colaboração fáceis, permitindo que os usuários compartilhem insights com stakeholders que podem não ter acesso direto à plataforma de análise. Formatos populares de exportação de painel a serem procurados incluem Excel, Imagem, PowerPoint, PDF e JSON.</li>
</ul>

<h2 class="wp-block-heading whitepapers__headline-dividers" id="chapter-5">Segurança</h2>

<div class="whitepapers__chapter-breadcrumbs d-block d-md-none mt-3 mb-4"><ul class="list-inline list-inline--piped"><li class="list-inline-item"><a href="#chapter-1" class="">Capítulo 1</a></li><li class="list-inline-item"><a href="#chapter-2" class="">Capítulo 2</a></li><li class="list-inline-item"><a href="#chapter-3" class="">Capítulo 3</a></li><li class="list-inline-item"><a href="#chapter-4" class="">Capítulo 4</a></li><li class="list-inline-item"><a href="#chapter-5" class="text-secondary">Capítulo 5</a></li><li class="list-inline-item"><a href="#chapter-6" class="">Capítulo 6</a></li><li class="list-inline-item"><a href="#chapter-7" class="">Capítulo 7</a></li><li class="list-inline-item"><a href="#chapter-8" class="">Capítulo 8</a></li></ul></div>

<p><a href="/security">Segurança</a> é uma preocupação primordial na implementação de qualquer solução de BI incorporada. Proteger dados sensíveis e garantir acesso autorizado são componentes cruciais na construção de confiança com os usuários.</p>
<p>Aqui estão considerações e recursos chave para priorizar ao avaliar os aspectos de segurança de uma solução de BI incorporada:</p>
<p><strong>Recursos de Autenticação no Nível da Fonte de Dados:</strong>Garantir mecanismos de autenticação robustos no nível da fonte de dados é fundamental para proteger a integridade dos dados. A<br />
        solução de BI incorporada deve suportar vários métodos de autenticação, incluindo:</p>
<ul>
<li><strong>Nome de usuário e senha:</strong> Implementando acesso seguro baseado em credenciais.</li>
<li><strong>Tokens:</strong> Aproveitando a autenticação baseada em tokens para segurança aprimorada.</li>
<li><strong>OAuth:</strong> Facilitando acesso seguro e delegado a fontes de dados por meio de protocolos de autenticação padrão da indústria.
        </li>
</ul>
<p>Estes recursos de autenticação garantem que apenas indivíduos autorizados possam acessar e interagir com as fontes de dados, mitigando o risco de exposição de dados não autorizada.</p>
<p><strong>APIs de Acesso Baseado em Função:</strong> O controle de acesso baseado em função é uma medida de segurança essencial que determina quais ações os usuários têm permissão para realizar dentro da solução de BI com base em suas funções ou responsabilidades. APIs que suportam controle de acesso baseado em função permitem que os administradores definam e gerenciem funções de usuário de forma eficaz. Isso garante que cada usuário tenha acesso apenas aos dados e funcionalidades necessários para sua função específica, reduzindo o risco de manipulação ou visualização de dados não autorizada.</p>
<p><strong>APIs para Simplificar a Passagem de Contexto do Usuário:</strong> APIs que simplificam esse processo garantem que as informações relacionadas ao usuário sejam transmitidas de forma segura entre os componentes do lado do cliente e do lado do servidor da solução de BI incorporada. Isso inclui a passagem de identidade do usuário, permissões e outras informações de contexto relevantes.</p>

<h2 class="wp-block-heading whitepapers__headline-dividers" id="chapter-6">Usabilidade</h2>

<div class="whitepapers__chapter-breadcrumbs d-block d-md-none mt-3 mb-4"><ul class="list-inline list-inline--piped"><li class="list-inline-item"><a href="#chapter-1" class="">Capítulo 1</a></li><li class="list-inline-item"><a href="#chapter-2" class="">Capítulo 2</a></li><li class="list-inline-item"><a href="#chapter-3" class="">Capítulo 3</a></li><li class="list-inline-item"><a href="#chapter-4" class="">Capítulo 4</a></li><li class="list-inline-item"><a href="#chapter-5" class="">Capítulo 5</a></li><li class="list-inline-item"><a href="#chapter-6" class="text-secondary">Capítulo 6</a></li><li class="list-inline-item"><a href="#chapter-7" class="">Capítulo 7</a></li><li class="list-inline-item"><a href="#chapter-8" class="">Capítulo 8</a></li></ul></div>

<p class="wp-block-paragraph">No mundo do BI incorporado, a usabilidade é a bússola que guia seus usuários em sua jornada de dados. A facilidade com que os usuários podem navegar, analisar e interpretar dados é um aspecto fundamental de uma solução de BI incorporado bem-sucedida. Dois aspectos cruciais que definem a usabilidade de uma solução de BI incorporado são as capacidades de autoatendimento e a curva de aprendizado para os usuários, particularmente os não técnicos.</p>

<ul>
<li><strong>Autoatendimento:</strong> No coração de uma <a href="https://www.revealbi.io/" target="_blank" rel="noopener">solução de BI incorporado amigável para o usuário</a> está o princípio do<br />
        autoatendimento. A ferramenta de BI incorporado não deve limitar usuários experientes nem sobrecarregar iniciantes. Procure por uma<br />
        ferramenta de autoatendimento que fornece uma visualização robusta de O Que Você Vê É O Que Você Obtém (WYSIWYG) <a href="/blog/drag-and-drop-analytics">arrastar e soltar</a> editor<br />
        que garante que os usuários, independentemente de sua proficiência técnica, possam projetar e personalizar intuitivamente<br />
        visualizações. Este recurso garante agilidade na adaptação às necessidades analíticas em evolução dentro das organizações<br />
        e é de suma importância que a ferramenta de BI incorporado que você escolher investir tenha isso.</li>
<li><strong>Modelos de Painel:</strong> Procure por uma ferramenta que forneça modelos de painel pré-construídos para simplificar<br />
        a criação de painéis e relatórios para os usuários. Tais elementos pré-construídos atuam como blocos de construção, permitindo que os usuários<br />
