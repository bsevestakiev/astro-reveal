<h3 class="text-primary pt-4" id="reveal-api-support">Reveal SDKがサポートするAPIは何ですか？</h3>
<p>RevealのネイティブなWeb、デスクトップ、およびサーバーSDKは、.NET Core、Java、NodeJS、そしてJavaScript、React、Angular、Web Component、VueJS、jQuery、MVC、Spring、Tomcat、ApacheのようなJavaフレームワークなどのフロントエンド技術を含む、あらゆるプラットフォームおよび技術スタックのアプリケーションに組み込むことができます。Reveal SDKは、Windows向けのWPFおよびWinFormsもサポートしています。 </p>
<h3 class="text-primary pt-4" id="reveal-data-connector-support">サポートしているデータコネクタは何ですか？</h3>
<p>Amazon Redshift、Box、Dropbox、Google Analytics、Google BigQuery、Google Drive、Hubspot、Microsoft Analysis Services、Microsoft Azure Analysis Services、Microsoft Azure SQL Databases、Microsoft Azure Synapse Analytics、Microsoft Dynamics CRM、Microsoft SQL Server、MySQL、OData Feed、OneDrive、Oracle、PostgreSQL、Quickbooks、REST API、Salesforce、Sharepoint、Sybase、Web Resource、JSONファイル、スプレッドシート。</p>
<h3 class="text-primary pt-4" id="reveal-embedding">組み込みはどのように機能しますか？</h3>
<p>Reveal組み込み分析は、WebとWindowsの両方に対応した完全にスタンドアロンのソリューションです。専用サーバーへの依存や要件はありません。Webの場合、ホストアプリケーションは、ダッシュボードのデータ読み込みと処理のためのサーバーサイドコンポーネントと、クライアントサイド用のJavaScript APIセットを利用します。組み込みアプリケーション開発者は、データ読み込みの制御、認証情報の提供、機能の有効化/無効化、および各ビジュアライゼーションのエンドユーザーとのやり取りを行うための豊富なAPIを持っています。</p>
<p>Reveal組み込み分析には、ダッシュボードの閲覧機能と、作成/編集機能の両方が含まれています。</p>

<h3 class="text-primary pt-4" id="reveal-embed-applications">Revealを何個のアプリケーションに組み込めますか？</h3>
<p>Revealを複数のアプリケーションに組み込むことができます。初期の料金はアプリケーションごとであるため、複数のアプリケーションにRevealを組み込むことに関する詳細については、に連絡してください。 <a href="/about-us/#request-demo">お問い合わせ</a>. </p>

<p>Reveal SDKには、.NETバージョン4.6.1以上とVisual Studio 2015以降が必要です。</p>

<h3 class="text-primary pt-4" id="reveal-what-happens">Revealはどうなりますか？</h3>
<p>Revealは、組み込み分析における当社の製品およびブランドであり続けます。Revealは、ソフトウェア企業がデータを組み込みダッシュボード、ビジュアル分析、およびビジネスインテリジェンスに変換できるようにするビジネスインテリジェンスSDKです。</p>
