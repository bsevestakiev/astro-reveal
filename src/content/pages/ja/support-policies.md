<h1 class="mt-3 mb-5 text-center">Reveal サポートポリシー</h1>
<div class="row">
<h2 class="sr-only" id="reveal-support-levels">Reveal サポートレベル</h2>
<div class="col-12 col-md-6 pr-md-5">
<h3 class="mt-4">Reveal 標準サポート</h3>
<p>Reveal Embed SDKとReveal Appの両方で、DiscordおよびGitHub Discussionsを通じてInfragisticsの標準サポートが利用できます。</p>
<p>Reveal の PoC を開始する際に、担当の営業担当者からこれらのリソースへのアクセス方法に関する情報が提供されます。</p>
</div>
<div class="col-12 col-md-6 pl-md-5">
<h3 class="mt-4">Reveal 優先サポート</h3>
<p>Reveal の組み込み SDK の顧客は、契約費用に追加して 15% の優先サポートアドオンを購入できます。</p>
<p>優先サポートには、上記に記載されているすべての Infragistics のサポート特典に加え、以下が含まれます：</p>
<ul>
<li>1営業日以内の保証された迅速な対応</li>
<li>アカウントマネージャー経由の直接のエスカレーションパス</li>
<li>現地の営業時間中の優先電話サポート</li>
<li>フォーラム投稿における優先対応時間</li>
<li>オンラインチャットサポート</li>
<li>早期ビルドへのアクセスや変更通知を含む、Reveal 製品管理チームとの年2回のミーティング</li>
</ul>
</div>
</div>
<h2 class="h3 mt-5" id="support-term">サポート期間</h2>
<p>サポートは、顧客が契約期間内である間提供されます。</p>
<p>顧客の契約期間が満了すると、どのデバイスやプラットフォームでも Reveal Embed SDK を使用または展開する権利は失われ、したがって、技術サポートも受けられなくなります。利用権を理解するには、からの Reveal ライセンス契約書を確認してください。 <a href="/license-agreements">/license-agreements</a>.</p>
<h2 class="h3 mt-5" id="hotfix-service-releases">ホットフィックス / サービスリリース</h2>
<p>Reveal にはサービスリリーススケジュールはありません。継続的デリバリーモデルを採用しています。</p>
<ul>
<li>Reveal Embed SDK の最新リリースをインストールすると、前回のメジャーリリース以降のすべてのバグ修正が含まれます。</li>
</ul>
<p>一般的に、バグの重要度を考慮します。</p>
<ul>
<li>回避策があり、バグが重大な問題でない場合、バグ修正はすぐに優先されず、回避策が推奨される進め方となります。</li>
</ul>
<p>Reveal は活発に開発されているため、毎月多くの新機能や改善が追加されています。以下の通知について、ドキュメントやブログを定期的に更新します：</p>
<ul>
<li>リリースにおける UI / ビジュアルの変更</li>
<li>リリースにおけるインタラクションの変更</li>
</ul>
<p>破壊的変更は、以下で入手可能な公開リリースノートに記載されます： <a href="https://help.revealbi.io/web/release-notes" rel="noopener" target="_blank">https://help.revealbi.io/web/release-notes</a>.</p>
<h2 class="h3 mt-5" id="support-lifecycle">サポートライフサイクル</h2>
<ul>
<li>Reveal Embed SDK のサポートには以下が含まれます：
<ul>
<li>12か月間のバグ修正</li>
</ul>
</li>
</ul>
<p>お客様には、Reveal SDK の最新バージョンに12か月ごとにアップグレードいただくことを推奨します。組み込みアプリケーションが12か月サイクルで更新されない場合があることは理解していますが、お客様がアプリケーションを更新しないことのリスクを理解することが重要です：</p>
<ul>
<li>セキュリティパッチ</li>
<li>バグ修正</li>
<li>廃止された機能</li>
</ul>
