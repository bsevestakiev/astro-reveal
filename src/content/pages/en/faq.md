      - anchor: "reveal-embedding"
        question: "How does embedding work?"
        answer: >-
          <p>Reveal embedded analytics is a completely standalone solution for both Web and Windows. There is no dependency or requirement for a dedicated server. In Web, the host app utilizes a server-side component to load and process data for dashboards and a set of JavaScript APIs for the client side. The embedding app developer has a rich API to control loading data, providing credentials, enabling/disabling functionality, and handling end-user interaction with each visualization.</p>
          <p>Reveal embedded analytics includes both dashboard viewing and creating/editing capability.</p>
