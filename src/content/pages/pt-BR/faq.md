<h3 class="text-primary pt-4" id="reveal-embedding">Como funciona a incorporação?</h3>
<p>O Reveal embedded analytics é uma solução completamente autônoma tanto para Web quanto para Windows. Não há dependência ou requisito de um servidor dedicado. Na Web, o aplicativo hospedeiro utiliza um componente de lado do servidor para carregar e processar dados para painéis e um conjunto de APIs JavaScript para o lado do cliente. O desenvolvedor do aplicativo de incorporação possui uma API rica para controlar o carregamento de dados, fornecer credenciais, habilitar/desabilitar funcionalidade e lidar com a interação do usuário final com cada visualização.</p>
<p>O Reveal embedded analytics inclui tanto a visualização quanto a capacidade de criação/edição de painéis.</p>
