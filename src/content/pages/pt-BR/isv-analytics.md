      - question: Quais APIs o Reveal SDK suporta?
        answer: >-
          O Reveal oferece suporte completo à API tanto no lado do cliente
          quanto no lado do servidor, permitindo que você integre análises em
          seus aplicativos rapidamente e gerencie tudo, desde o deployment até o
          visual completo do aplicativo.
      - question: Quais conectores de dados o Reveal suporta?
        answer: >-
          O Reveal suporta uma variedade diversificada de fontes de dados, como
          APIs, bancos de dados SQL, armazenamento em nuvem e muito mais.
      - question: Em quantos aplicativos posso incorporar o Reveal?
        answer: >-
          Você pode incorporar o Reveal em vários aplicativos. O preço é por
          aplicativo, então, para mais informações sobre a incorporação do
          Reveal em mais de um aplicativo, certifique-se de entrar em contato
          conosco.
      - question: Posso implantar o Reveal localmente (on-premise) ou baseado em nuvem?
        answer: >-
          O componente do SDK no lado do servidor é um conjunto de bibliotecas
          ASP.NET Core (suportando .NET Framework, ASP.NET Core e Java),
          permitindo o deployment em aplicativos tanto on-premises quanto em
          nuvem.
      - question: Como o Reveal protege meus dados?
        answer: >-
          Como um SDK que vive no contexto do seu aplicativo, o Reveal opera
          dentro dos seus controles de dados existentes, sem exigir alterações.
          Nós não armazenamos seus dados. Portanto, nenhum dado sensível ou
          pessoal é acessado ou usado pelo Reveal, garantindo a privacidade e a
          segurança das suas informações.
      - question: O Reveal SDK funcionará em um ambiente multilocatário?
        answer: Sim.
      - question: Como posso criar um painel no Reveal?
        answer: >-
          Criar um painel no Reveal é muito fácil. Primeiro, você precisa se
          conectar a uma fonte de dados que contenha seus dados e, em seguida,
          criar visualizações bonitas para transmitir o significado e a mensagem
          dos insights que você obtém. Depois disso, você pode salvar seu painel
          e compartilhá-lo com todos que precisam ter acesso a ele.
      - question: Quanto custa o Reveal?
        answer: >-
          O Reveal oferece uma estrutura de preços simples, adaptada às suas
          necessidades específicas, com um preço fixo anual simples por
          aplicativo. Com nosso compromisso com a transparência, você pode ter
          certeza de que não há taxas ocultas, limitações de uso ou níveis de
          usuário complexos para se preocupar.
