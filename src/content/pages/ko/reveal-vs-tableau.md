  - type: faq
    items:
      - question: 임베디드 분석은 제품 팀에게 전통적인 BI와 어떻게 다릅니까?
        answer: >-
          Tableau와 같은 전통적인 BI 도구는 종종 독립적인 플랫폼으로 내부 보고를 위해 구축되었습니다. 반면에 <a
          href="/embedded-analytics">임베디드 분석</a>은 귀하의 SaaS 제품에 직접 통합되어 사용자가 앱을
          떠나지 않고도 인사이트를 얻을 수 있게 합니다. 제품 팀에게 이것은 더 높은 채택률, 더 강력한 기능, 그리고 별도의 BI
          워크플로우에 대한 의존도 감소를 의미합니다.
      - question: Reveal과 Tableau를 통합하는 ROI는 무엇입니까?
        answer: >-
          <a href="/">Reveal</a> 플랫 레이트 가격 모델로 운영되어 수천 명의 사용자에게 확장해도 마진에 영향을 주지
          않습니다. Tableau의 사용자당 모델은 채택률이 증가함에 따라 비용이 추가 사용자마다 급증하여 ROI 달성을 어렵게
          만듭니다. 그 결과는 더 빠른 투자 회수, 낮은 총 소유 비용, 그리고 제품 성장을 이끄는 분석입니다.
      - question: Reveal은 임베디드 분석을 위해 어떤 배포 옵션을 제공합니까?
        answer: >-
          Reveal은 설계상 유연합니다. 온프레미스, 개인 클라우드 또는 완전히 관리되는 SaaS 옵션으로 배포할 수 있습니다. 이는
          Reveal을 사용한 임베디드 분석이 보안, 규정 준수 및 인프라 요구 사항에 맞춰 조정 가능하게 만듭니다. 이는 일률적인
          BI 도구와는 다릅니다.
      - question: Reveal은 기존 데이터 소스와 어떻게 통합됩니까?
        answer: >-
          Reveal은 SQL Server, Postgres, MySQL, Azure SQL, Snowflake, Google Big
          Query 및 Oracle을 포함하여 가장 일반적인 SQL 및 클라우드 환경에 네이티브하게 연결됩니다. 또한 사용자 지정
          통합을 위한 REST API도 지원합니다. 지원되는 <a href="/data-sources">데이터 소스</a>에 대한
          자세한 내용은 사용자가 우회 방지 없이 라이브 대시보드를 얻을 수 있도록 보장합니다.
      - question: Reveal이 복잡한 사용자 정의 없이 내 앱의 UI와 일치할 수 있나요?
        answer: >-
          예. Reveal은 전체 <a href="/white-label-analytics">화이트 라벨 분석</a>을 제공하므로,
          테마부터 글꼴, 레이아웃까지 모든 요소를 제품의 디자인 시스템에 맞게 조정할 수 있습니다. 대시보드가 앱에 완전히 네이티브하게
          느껴지기 때문에 사용자가 타사 도구를 사용하고 있다는 것을 알지 못할 것입니다.
      - question: 사용량에 따라 Reveal의 가격 책정은 얼마나 예측 가능한가요?
