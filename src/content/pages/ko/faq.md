<h3 class="text-primary pt-4" id="reveal-price">Reveal 임베디드 분석의 가격은 얼마인가요?</h3>
<p><span class="NormalTextRun SCXW15188204 BCX0">Reveal에서는</span><span class="NormalTextRun SCXW15188204 BCX0">사용량 요금이나 백엔드 용량 측정 비용에 대해 걱정할 필요 없이, 어떤 장치에서든 무제한 사용자에게 도달할 수 있도록 투명하고 마찰 없는 가격을 제공하기 위해 노력하고 있습니다. 예상치 못한 비용 없이 정확히 얼마를 지불하게 될지 아세요. 더 많은 정보를 요청하세요 <a href="/request-demo">여기</a>. </span></p>
<h3 class="text-primary pt-4" id="reveal-api-support">Reveal SDK는 어떤 API를 지원하나요?</h3>
<p>Reveal의 네이티브 웹, 데스크톱 및 서버 SDK는 .NET Core, Java, NodeJS를 포함한 모든 플랫폼 및 기술 스택의 애플리케이션에 통합될 수 있으며, JavaScript, React, Angular, Web Component, VueJS, jQuery, MVC 및 Spring, Tomcat, Apache와 같은 Java 프레임워크와 같은 프론트엔드 기술도 포함됩니다. Reveal SDK는 Windows용 WPF 및 WinForms도 지원합니다. </p>
<h3 class="text-primary pt-4" id="reveal-data-connector-support">어떤 데이터 커넥터를 지원하나요?</h3>
<p>Amazon Redshift, Box, Dropbox, Google Analytics, Google BigQuery, Google Drive, Hubspot, Microsoft Analysis Services, Microsoft Azure Analysis Services, Microsoft Azure SQL Databases, Microsoft Azure Synapse Analytics, Microsoft Dynamics CRM, Microsoft SQL Server, MySQL, OData Feed, OneDrive, Oracle, PostgreSQL, Quickbooks, REST API, Salesforce, Sharepoint, Sybase, Web Resource, JSON files, 스프레드시트.</p>
<h3 class="text-primary pt-4" id="reveal-embedding">임베딩은 어떻게 작동하나요?</h3>
<p>Reveal 임베디드 분석은 웹과 윈도우 모두에서 완전히 독립적인 솔루션입니다. 전용 서버에 대한 종속성이나 요구 사항이 없습니다. 웹의 경우, 호스트 앱은 대시보드를 로드하고 데이터를 처리하기 위한 서버 측 구성 요소를 사용하며, 클라이언트 측을 위한 일련의 JavaScript API를 사용합니다. 임베딩 앱 개발자는 데이터 로드 제어, 자격 증명 제공, 기능 활성화/비활성화 및 각 시각화에 대한 최종 사용자 상호 작용 처리를 위한 풍부한 API를 갖추고 있습니다.</p>
<p>Reveal 임베디드 분석은 대시보드 보기와 생성/편집 기능을 모두 포함합니다.</p>

<h3 class="text-primary pt-4" id="reveal-what-happens">Reveal은 어떻게 되나요?</h3>
<p>Reveal은 임베디드 분석을 위한 당사의 제품이자 브랜드로 남을 것입니다. Reveal은 소프트웨어 회사들이 데이터를 임베디드 대시보드, 시각적 분석 및 애플리케이션 내 비즈니스 인텔리전스로 변환할 수 있도록 하는 비즈니스 인텔리전스 SDK입니다.</p>
