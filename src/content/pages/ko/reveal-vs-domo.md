    items:
      - question: Domo 임베디드란 무엇인가
        answer: >-
          Domo 임베디드는 회사들이 일반적으로 iFrame을 사용하여 자체 앱 내에 대시보드를 표시할 수 있도록 하는 Domo BI
          플랫폼의 확장 기능입니다. Domo의 클라우드 전용 아키텍처를 기반으로 구축되었기 때문에, 임베딩은 최소한의 사용자 정의만
          가능한 호스팅된 보기로 제한되어, 완전히 네이티브하거나 화이트 라벨 사용자 경험을 제공하기 어렵습니다.
        open: true
      - question: 임베디드 분석을 위해 Reveal이 Domo와 다른 점은 무엇인가
        answer: >-
          Reveal은 iFrame 내의 호스팅 BI 도구가 아니라 진정한 임베디드 SDK입니다. 개발자는 전체 API 액세스, 사용자
          정의 UI 제어 및 유연한 배포(클라우드, 온프레미스 또는 하이브리드)를 얻습니다. Domo가 분석을 앱에 붙이는 반면,
          Reveal은 보안적이고, 원활하며, 완전히 통합된 방식으로 분석을 내장합니다.
      - question: Reveal이 가장 비용 효율적인 Domo 대안인 이유
        answer: >-
          Domo는 사용자, 사용량 및 용량별로 요금을 부과하여 비용을 예측하기 어렵고 확장하기 어렵게 만듭니다. Reveal은
          사용자당 수수료나 초과 사용료가 없는 평면 가격을 제공합니다. 첫날부터 전체 액세스를 할 수 있으므로, 사용자가 10명이든
          10,000명이든 비용이 안정적으로 유지됩니다.
      - question: Reveal은 브랜드 맞춤화를 위한 완전한 화이트 라벨링을 지원하나요?
        answer: >-
          네, Reveal은 로고, 색상, 글꼴 및 레이아웃을 제품의 브랜딩에 맞게 사용자 정의할 수 있는 완전한 화이트 라벨링을
          제공합니다. Domo의 임베디드 대시보드는 플랫폼 브랜딩 및 스타일링 제한을 유지합니다. Reveal은 앱처럼 보이고 느껴지기
          때문에—타협이나 호스팅된 래퍼가 없습니다.
      - question: Reveal은 어떤 데이터 소스에 연결할 수 있나요?
        answer: >-
          Reveal은 SQL Server, MySQL, PostgreSQL, Oracle, Google BigQuery, REST
          API, Excel 및 Azure 및 AWS와 같은 클라우드 서비스를 포함하여 광범위한 데이터 소스를 지원합니다. Domo와
          달리 Reveal은 경직된 파이프라인에 가두지 않습니다. 제품이 의존하는 모든 데이터 소스에 실시간으로 액세스할 수 있습니다.
      - question: 임베디드 분석에 있어 Reveal이 Domo보다 개발자에게 더 친화적인가요?
        answer: >-
          물론입니다. Reveal은 진정한 임베디드 SDK, 전체 API 액세스 및 상세한 문서를 갖추고 개발자를 위해 구축되었습니다.
          이는 여러 기술 스택에 걸쳐 빠르고 유연한 통합을 위해 설계되었으며, Domo는 iFrame에 더 의존하고 코드 수준에서
          사용자 정의가 덜 됩니다.
      - question: Domo와 비교하여 Reveal은 보안 및 규정 준수를 어떻게 처리하나요?
        answer: >-
          Reveal은 역할 기반 액세스 제어(RBAC), 행 수준 보안 및 멀티테넌트 지원을 포함하여 강력한 내장 보안 기능을
