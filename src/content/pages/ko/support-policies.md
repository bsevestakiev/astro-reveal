<h1 class="mt-3 mb-5 text-center">Reveal 지원 정책</h1>
<div class="row">
<h2 class="sr-only" id="reveal-support-levels">Reveal 지원 수준</h2>
<div class="col-12 col-md-6 pr-md-5">
<h3 class="mt-4">Reveal 표준 지원</h3>
<p>Reveal 임베드 SDK와 Reveal 앱 모두 Discord 및 GitHub Discussions를 통해 Infragistics 표준 지원을 포함합니다.</p>
<p>귀하의 영업 담당자가 Reveal PoC를 시작할 때 이러한 리소스에 접근하는 방법에 대한 정보를 제공할 것입니다.</p>
</div>
<div class="col-12 col-md-6 pl-md-5">
<h3 class="mt-4">Reveal 우선 지원</h3>
<p>Reveal 임베딩 SDK 고객은 계약 비용의 추가 15%를 지불하고 우선 지원 추가 기능을 구매할 수 있습니다.</p>
<p>우선 지원에는 위에 설명된 모든 Infragistics 지원 혜택과 다음이 포함됩니다.</p>
<ul>
<li>1영업일 이내 보장된 신속한 응답</li>
<li>담당 계정 관리자를 통한 직접적인 에스컬레이션 경로</li>
<li>현지 영업 시간 동안 우선 전화 지원</li>
<li>포럼 게시물에 대한 우선 응답 시간</li>
<li>온라인 채팅 지원</li>
<li>조기 빌드 및 변경 알림에 대한 접근을 포함하여 Reveal 제품 관리팀과의 연례 회의</li>
</ul>
</div>
</div>
<h2 class="h3 mt-5" id="support-term">지원 기간</h2>
<p>고객이 계약 기간 내에 있는 동안 지원이 제공됩니다.</p>
<p>고객 계약 기간이 만료되면, 더 이상 어떤 장치나 플랫폼에서도 Reveal 임베딩 SDK를 사용/배포할 권리가 없으며, 따라서 기술 지원도 받을 수 없습니다. 사용 권한을 이해하려면, 다음에서 Reveal 라이선스 계약을 검토하십시오: <a href="/license-agreements">/license-agreements</a>.</p>
<h2 class="h3 mt-5" id="hotfix-service-releases">핫픽스 / 서비스 릴리스</h2>
<p>Reveal은 서비스 릴리스 일정이 없습니다. 저희는 지속적인 배포 모델을 따릅니다.</p>
<ul>
<li>Reveal 임베딩 SDK의 최신 릴리스를 설치하면 이전 주요 릴리스 이후의 모든 버그 수정이 포함됩니다.</li>
</ul>
<p>일반적으로, 우리는 버그의 중요성을 살펴봅니다:</p>
<ul>
<li>해결 방법이 있고, 버그가 심각한 문제가 아니라면, 버그 수정은 즉시 우선순위가 지정되지 않을 것이며, 해결 방법이 권장되는 진행 경로가 될 것입니다.</li>
</ul>
<p>Reveal은 활발하게 개발 중이며, 매달 많은 새로운 기능과 개선 사항을 추가하고 있다는 점을 알려드립니다. 우리는 다음 내용에 대한 알림과 함께 문서와 블로그를 정기적으로 업데이트할 것입니다:</p>
<ul>
<li>릴리스의 UI / 시각적 변경 사항</li>
<li>릴리스의 상호 작용 변경 사항</li>
</ul>
<p>호환성 깨지는 변경 사항은 다음에서 확인할 수 있는 게시된 릴리스 노트에 포함됩니다: <a href="https://help.revealbi.io/web/release-notes" rel="noopener" target="_blank">https://help.revealbi.io/web/release-notes</a>.</p>
<h2 class="h3 mt-5" id="support-lifecycle">지원 수명 주기</h2>
<ul>
<li>Reveal 임베드 SDK 지원에는 다음이 포함됩니다:
<ul>
<li>12개월 동안의 버그 수정</li>
</ul>
</li>
</ul>
<p>고객들에게 12개월마다 Reveal SDK의 최신 버전으로 업그레이드할 것을 권장합니다. 임베디드 애플리케이션이 12개월 주기로 업데이트되지 않을 수 있다는 점은 이해하지만, 고객이 애플리케이션을 업데이트하지 않을 때의 위험을 이해하는 것이 중요합니다:</p>
<ul>
<li>보안 패치</li>
<li>버그 수정</li>
<li>사용 중단된 기능</li>
</ul>
