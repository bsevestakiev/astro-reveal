    items:
      - question: Reveal SDK는 어떤 API를 지원하나요?
        answer: >-
          Reveal은 클라이언트 측과 서버 측 모두에서 전체 API 지원을 제공하여, 앱에 분석 기능을 빠르게 통합하고 배포부터 앱의
          전체적인 모양과 느낌까지 모든 것을 관리할 수 있게 해줍니다.
      - question: Reveal은 어떤 데이터 커넥터를 지원하나요?
        answer: 'Reveal은 API, SQL 데이터베이스, 클라우드 스토리지 등 다양한 데이터 소스를 지원합니다.'
      - question: 몇 개의 애플리케이션에 Reveal을 임베딩할 수 있나요?
        answer: >-
          Reveal을 여러 애플리케이션에 임베딩할 수 있습니다. 가격은 애플리케이션당 책정되므로, 여러 애플리케이션에 Reveal
          임베딩에 대한 더 자세한 정보는 저희에게 문의해 주십시오.
      - question: Reveal을 온프레미스 또는 클라우드 기반으로 배포할 수 있나요?
        answer: >-
          SDK 서버 측 구성 요소는 일련의 ASP.NET Core 라이브러리(닷넷 프레임워크, ASP.NET Core, Java 모두
          지원)로, 온프레미스 및 클라우드 애플리케이션 모두에 배포할 수 있습니다.
      - question: Reveal은 제 데이터를 어떻게 보호하나요?
        answer: >-
          애플리케이션의 컨텍스트 내에 존재하는 SDK로서, Reveal은 기존 데이터 제어 범위 내에서 작동하므로 변경이 필요하지
          않습니다. 저희는 데이터를 저장하지 않습니다. 따라서, Reveal은 민감하거나 개인적인 데이터에 접근하거나 사용하지 않아
          정보의 개인 정보 보호 및 보안을 보장합니다.
      - question: Reveal SDK는 멀티테넌트 환경에서 작동할 수 있나요?
        answer: 예.
      - question: Reveal에서 대시보드를 어떻게 만들 수 있나요?
        answer: >-
          Reveal에서 대시보드를 만드는 것은 매우 쉽습니다. 먼저, 데이터를 포함하는 데이터 소스에 연결한 다음, 얻은 통찰력의
          의미와 메시지를 전달하기 위해 아름다운 시각화를 만듭니다. 그 후, 대시보드를 저장하고 접근 권한이 필요한 모든 사람과 공유할
          수 있습니다.
      - question: Reveal 비용은 얼마인가요?
        answer: >-
          Reveal은 특정 요구 사항에 맞춰진 간단한 고정 연간 가격의 명료한 가격 구조를 제공합니다. 투명성을 약속드리며, 숨겨진
          수수료, 사용 제한 또는 복잡한 사용자 계층에 대해 걱정할 필요가 없다는 것을 확신할 수 있습니다.
