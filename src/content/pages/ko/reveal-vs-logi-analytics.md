      - question: Logi Symphony란 무엇인가요?
        answer: >-
          Logi Symphony는 현재 Logi Analytics의 버전이며, 현재 insightsoftware가 소유하고 있습니다.
          임베디드 BI 기능을 제공하지만, 사용자들은 인수 이후 비용 증가, 성능 저하, 제한적인 혁신을 지적했습니다. 레거시
          아키텍처는 종종 iFrame과 복잡한 설정 프로세스에 의존하여 임베딩 과정에 마찰을 더합니다.
      - question: 임베디드 분석에 있어 Reveal은 Logi Analytics와 어떻게 다른가요?
        answer: >-
          Reveal은 임베디드 분석을 위해 목적에 맞게 구축되었으며, 진정한 SDK를 제공합니다. iFrame, 래퍼 또는 제한적인
          플러그인 없이 작동합니다. 앱에 직접 통합되어 UX에 대한 완전한 제어를 제공하고 빠르고 안전하며 확장 가능한 성능을 가능하게
          합니다. 반면, Logi Symphony는 종종 복잡한 설정, iFrame 기반 임베딩, 제한적인 사용자 정의에 의존하여
          원활하고 네이티브한 경험을 제공하기 어렵게 만듭니다.
      - question: Reveal이 가장 비용 효율적인 Logi Analytics 대안인 이유는 무엇인가요?
        answer: >-
          Reveal은 사용자당 요금, 사용량 등급 또는 숨겨진 비용이 없는 평면 요금제 모델을 사용합니다. Logi의 가격 책정은
          인수 이후 더 복잡하고 비싸졌지만, Reveal은 예산 초과 걱정 없이 쉽게 확장할 수 있게 합니다. 첫날부터 완전한 액세스를
          얻기 때문에 사용자 수가 10명이든 10,000명이든 비용이 안정적입니다.
      - question: Reveal이 Logi Analytics보다 앱에 대시보드를 임베딩하는 데 더 효과적인가요?
        answer: >-
          예. Reveal은 네이티브 임베딩과 완벽한 화이트 라벨링을 지원하여, 대시보드가 제품의 일부처럼 자연스럽게 느껴지게 합니다.
          단순히 추가하는 구성 요소가 아닙니다. 개발자는 통제권을 유지하고, 사용자는 일관되고 브랜드에 맞는 경험을 즐길 수 있습니다.
      - question: 임베디드 분석 측면에서 Reveal이 Logi Analytics보다 개발자 친화적인가요?
        answer: >-
          물론입니다. Reveal은 개발자를 염두에 두고 설계되었으며, 네이티브 SDK, 전체 API 액세스, 직관적인 도구를
          제공합니다. 우회 방법도, 경직된 템플릿도 없습니다. 그저 원활한 통합과 강력한 사용자 정의가 가능합니다.
      - question: Logi Analytics와 비교하여 Reveal은 보안을 어떻게 처리하나요?
        answer: >-
          Reveal은 멀티테넌트 환경, 행 수준 보안을 지원하며 기존 인증 시스템과 통합됩니다. 설계 단계부터 안전한 임베딩을 위해
          구축되었습니다. Logi가 기본적인 보안 기능을 제공하는 것은 맞지만, 복잡한 환경과 일치시키려면 종종 사용자 지정 구성과
          추가 노력이 필요합니다. 일부 사용자는 문서가 불분명하고 기본 옵션이 제한적이라고 보고하여, 개발 시간과 위험을 증가시킵니다.
      - question: Reveal이 Logi Analytics만큼 많은 데이터 소스를 지원하나요?
        answer: >-
          예—그리고 많은 경우 더 많이 지원합니다. Reveal은 SQL Server, Postgres, Oracle, REST
          API, Excel, Google BigQuery 등 광범위한 인기 데이터 소스에 연결됩니다. 설정이 빠르고 유연하며,
          최소한의 구성만 필요합니다. Logi도 광범위한 범위를 지원하지만, 많은 통합에 추가 설정이나 지원이 필요하여 추가적인 마찰을
          만듭니다.
      - question: Reveal은 어떤 종류의 AI 분석을 제공하나요?
