    items:
      - question: 광산에서 데이터 분석이란 무엇인가요?
        answer: >-
          광산 데이터 분석 또는 마이닝 분석은 광산 회사의 운영에서 생성된 데이터를 사용하여 실시간 보고, 데이터 시각화 및 데이터
          분석 기술을 통해 가치 있는 통찰력을 추출하는 것을 의미합니다.
      - question: 광산에 임베디드 분석을 어떻게 사용할 수 있나요?
        answer: >-
          광산의 임베디드 분석을 사용하면 기업이 생산, 장비 성능, 안전 및 기타 중요한 지표를 실시간으로 모니터링할 수 있습니다.
          비효율성을 식별하고, 자원 관리를 최적화하며, 데이터 기반 결정을 내리고, 장비 고장이나 생산 추세를 예측하여 궁극적으로 더
          나은 결과를 이끌어냅니다.
      - question: 직접 분석 시스템을 구축하는 대신 Reveal을 선택해야 하는 이유는 무엇인가요?
        answer: >-
          Reveal은 강력하고 원활한 통합을 제공하여 애플리케이션에 분석을 손쉽게 임베딩할 수 있도록 합니다. 예측 분석, 실시간
          모니터링, 공간 분석을 포함한 강력한 기능을 통해 Reveal은 그렇지 않으면 맞춤형 분석 솔루션을 개발하고 유지 관리하는 데
          소비되었을 시간과 자원을 절약해 줍니다.
      - question: Reveal로 예측 분석 모델링을 사용할 수 있나요?
        answer: >-
          Reveal의 엔드투엔드 임베디드 분석 플랫폼은 Azure ML 및 Google BigQuery의 머신러닝 모델을 활용하여
          예측 분석을 통합합니다. 이를 통해 사용자는 추세를 예측하고, 이상 징후를 식별하며, 데이터에서 실행 가능한 통찰력을 도출할
          수 있습니다.
      - question: 비기술적 사용자도 Reveal을 사용하여 대시보드를 만들 수 있나요?
        answer: >-
          예, Reveal은 셀프 서비스 임베디드 분석 솔루션입니다. 직관적인 드래그 앤 드롭 대시보드 생성 기능으로 기술적 경험이나
          지식 수준에 관계없이 누구나 독립적으로 맞춤형 대시보드를 만들 수 있습니다.
      - question: 민감한 데이터를 다룹니다. Reveal은 안전한가요?
        answer: >-
          애플리케이션의 컨텍스트 내에 존재하는 SDK로서, Reveal은 기존 데이터 제어 범위 내에서 작동하므로 변경이 필요하지
          않습니다. 저희는 데이터를 저장하지 않습니다. 따라서, Reveal은 민감하거나 개인적인 데이터에 접근하거나 사용하지 않아
          정보의 개인 정보 보호 및 보안을 보장합니다.
