<h3 class="text-primary pt-4" id="reveal-api-support">¿Qué APIs admite el SDK de Reveal?</h3>
<p>Los SDK web, de escritorio y de servidor nativos de Reveal se pueden integrar en aplicaciones en cualquier plataforma y pila tecnológica, incluidos .NET Core, Java, NodeJS y tecnologías front-end como JavaScript, React, Angular, Web Component, VueJS, jQuery, MVC y frameworks Java como Spring, Tomcat, Apache. El SDK de Reveal también admite WPF y WinForms para Windows. </p>
<h3 class="text-primary pt-4" id="reveal-data-connector-support">¿Qué conectores de datos admiten?</h3>
<p>Amazon Redshift, Box, Dropbox, Google Analytics, Google BigQuery, Google Drive, Hubspot, Microsoft Analysis Services, Microsoft Azure Analysis Services, Microsoft Azure SQL Databases, Microsoft Azure Synapse Analytics, Microsoft Dynamics CRM, Microsoft SQL Server, MySQL, OData Feed, OneDrive, Oracle, PostgreSQL, Quickbooks, REST API, Salesforce, Sharepoint, Sybase, Web Resource, archivos JSON, Hojas de cálculo.</p>
<h3 class="text-primary pt-4" id="reveal-embedding">¿Cómo funciona la integración?</h3>
<p>Reveal embedded analytics es una solución completamente independiente tanto para Web como para Windows. No hay dependencia ni requisito de un servidor dedicado. En Web, la aplicación anfitriona utiliza un componente del lado del servidor para cargar y procesar datos para paneles y un conjunto de APIs de JavaScript para el lado del cliente. El desarrollador de la aplicación de integración tiene una API rica para controlar la carga de datos, proporcionar credenciales, habilitar/deshabilitar la funcionalidad y manejar la interacción del usuario final con cada visualización.</p>
<p>Reveal embedded analytics incluye tanto la visualización como la capacidad de crear/editar paneles.</p>
