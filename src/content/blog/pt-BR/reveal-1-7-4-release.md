A partir de hoje, os usuários do Reveal podem se conectar diretamente ao ambiente Databricks deles e construir painéis em tempo real usando nossa experiência completa de análise incorporada.

## Integração Nativa com Databricks

Os usuários do Databricks agora podem incorporar insights em tempo real diretamente em seus aplicativos sem etapas extras ou complexidade adicional.

Como uma plataforma de dados baseada em nuvem construída em **Apache Spark** e **ML tools**, o Databricks impulsiona análises em larga escala. Este novo conector facilita transformar esses dados em painéis ao vivo, dentro do aplicativo—totalmente integrado e pronto para os usuários.

**As equipes agora podem:**

- Dados do Databricks em apenas algumas linhas de código
- Criar e compartilhar painéis com visualizações personalizadas
- Incorporar análises diretamente em seu aplicativo com o SDK do Reveal
- Usar o Reveal AI para fazer perguntas em linguagem natural sobre seus dados do Databricks

Com o Reveal, esses insights não estão mais isolados—eles são entregues nativamente dentro dos aplicativos que as equipes estão construindo.

**Java HTTP Client**: Tratamento de erros aprimorado + melhorias de log

**DSI.DataSource**: Configuração simplificada—nenhuma configuração manual necessária

**S3 SessionToken Support**: Compatibilidade aprimorada com AWS Athena

**Correções de Bugs + Desempenho**: Melhorias contínuas de velocidade + confiabilidade
