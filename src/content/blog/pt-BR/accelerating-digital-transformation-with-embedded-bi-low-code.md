## Introdução ao Reveal

Imagine um mundo onde o business intelligence de autoatendimento se integra perfeitamente aos seus aplicativos, transformando a maneira como você interage com os dados. [Reveal](https://samples.revealbi.io/reveal-sdk-samples/2020-survey-results.html) pega o conceito de BI de autoatendimento e o apresenta como um SDK poderoso, diferenciando-o de soluções tradicionais que dependem de métodos de integração iframe [obsoletos](/blog/embedded-analytics-vs-iframes). O [SDK do Reveal](/download-sdk) redefine a experiência do usuário, oferecendo flexibilidade incomparável. Se você está desenvolvendo aplicativos web com tecnologias como [React](/blog/embedding-self-service-bi-in-react-apps-with-node-js) ou [Angular](/blog/embedding-bi-in-angular-apps), explorando [Blazor](/blog/embedding-bi-in-blazor-applications) ou componentes web, ou criando aplicativos desktop com WPF ou Windows Forms, o Reveal cobre você.

Aqui estão os principais benefícios do Reveal:

- SDK incorporado verdadeiro, eliminando a necessidade de iframes
- API poderosa que permite integração direta em seu aplicativo, garantindo uma experiência nativa e fluida
- Interface intuitiva de arrastar e soltar
- Sem custos ou complexidades ocultas nas estruturas de preços
- Compatibilidade em várias plataformas e stacks de tecnologia
- Os usuários podem personalizar a aparência e o toque dos painéis para corresponder à marca ou estética do aplicativo
- Edição simplificada de painéis
- Controle de 100% tanto do cliente quanto do servidor com a abordagem SDK

## Introdução ao App Builder

Com uma caixa de ferramentas de mais de 60 componentes UI ricos e um conjunto completo de grades e gráficos de dados de alto desempenho, transforme seus aplicativos legados em experiências web modernas e responsivas. [App Builder](https://www.appbuilder.dev/) é uma ferramenta low-code baseada em nuvem, WYSIWYG, que acelera o desenvolvimento de aplicativos web modernos, permitindo que as equipes entreguem aplicativos 80% mais rápido. Ele vem repleto de modelos pré-construídos, layouts responsivos e temas personalizáveis para dar ao seu aplicativo uma identidade única. O App Builder também oferece uma caixa de ferramentas de mais de 60 controles UI e suporta geração de código para Angular, Blazor e Web Components, garantindo uma representação pixel-perfect de seus designs em HTML, TypeScript e CSS prontos para produção. Além disso, você pode importar sem esforço seus designs Sketch ou Figma designs e conectar-se a qualquer fonte de dados REST.

Aqui estão os principais benefícios do App Builder:

- Elimina a codificação manual propensa a erros para tarefas repetitivas e mundanas.
- Transforma arquivos de design em aplicativos ricos em dados.
- Economiza 80% do tempo dos desenvolvedores em design de UI e UX para telas de aplicativos.
- Oferece ligação de dados, navegação e temas.
- Garante paridade de componentes e recursos em Angular, Blazor e Web Components.
- Fornece pré-visualização de código e geração de código com um clique.

## Reveal BI + App Builder

A mágica acontece quando o Reveal e o App Builder se unem. Os desenvolvedores podem integrar painéis do Reveal diretamente da Caixa de Ferramentas do App Builder, especificando URLs para hospedagem de dados do Reveal Server SDK. O resultado é uma mistura harmoniosa de [análise incorporada](/embedded-analytics) e desenvolvimento rápido de aplicativos, oferecendo uma prévia do que é possível quando essas tecnologias convergem.

Tanto o Reveal quanto o App Builder capacitam os desenvolvedores a se libertarem das restrições tradicionais, permitindo-lhes entregar aplicativos impressionantes integrados perfeitamente com BI incorporado.
