**Reveal 1.8.1** introduz duas grandes melhorias que tornam a construção de análise incorporada mais rápida, inteligente e escalável: **Formatação Condicional** e o **Redis Cache Provider**. Essas atualizações ajudam desenvolvedores, equipes de dados e usuários corporativos a entregar insights mais claros e desempenho superior com menos complexidade. Se você está aprimorando painéis com lógica de cores ou otimizando velocidades de consulta para aplicações de alto tráfego, o Reveal continua a definir o padrão para BI incorporado personalizável que simplesmente funciona.

## **Formatação Condicional: Deixe Seus Dados Contarem a História**

![Conditional Formatting](https://static.infragistics.com/marketing/reveal/blogs/launch/2025/nov/reveal-conditional-formatting-grids.png)

Os dados só importam quando são claros. Com a Formatação Condicional, você pode aplicar lógica de cores diretamente a gráficos e painéis, tornando tendências e valores atípicos instantaneamente visíveis.

**Principais Benefícios:**
• **Coloração flexível baseada em regras:** Aplique cores baseadas em lógica para séries, categorias ou rótulos, como >=100, \<AmountField, ou =’SalesPersonName’.
• **Sem código necessário:** Combine visuais com lógica de negócios diretamente no painel.
• **Funciona em vários tipos de gráficos:** Garanta um design visual e uma experiência do usuário consistentes.

Isso dá aos analistas e gerentes de produto o poder de destacar o que é mais importante. Mostre crescimento em verde, risco em vermelho e crie painéis que contam uma história em um relance. Os desenvolvedores agora podem trazer design orientado por lógica para cada visualização sem adicionar complexidade.

## **Redis Cache Provider: Velocidade e Escala Empresarial**

![Redis Cache Provider](https://static.infragistics.com/marketing/reveal/blogs/launch/2025/nov/reveal-redis-cache-provider.png)

Para organizações que gerenciam grandes cargas de trabalho analíticas, a velocidade é inegociável. O novo Redis Cache Provider introduz cache distribuído em memória, substituindo o SQLite para uso empresarial, o que ajuda as equipes a entregar desempenho mais rápido e consistente.

**Por que Redis:**
• Resposta de consulta ultrarrápida com cache em memória.
• Escalabilidade horizontal para cargas de trabalho distribuídas.
• Lógica de repetição, políticas de expiração e conexões seguras configuráveis.

## **Integração Fácil via .NET Fluent API:**

.AddRedisCache(options =>
{
options.ConnectionString = “your-redis-connection-string”;
options.CacheExpiration = TimeSpan.FromSeconds(30);
options.RetryDelayMs = 200;
})

**NuGet Package:** Reveal.Sdk.Caching.Redis

O Redis Cache Provider garante estabilidade e capacidade de resposta para plataformas SaaS multilocatário e sistemas de relatórios em tempo real, mantendo a análise funcionando sem problemas mesmo sob carga pesada.

## **Próximos Passos para o Reveal**

O Reveal 1.8.1 continua nossa missão de tornar a integração de análise mais rápida, simples e poderosa para desenvolvedores e equipes de negócios. Tanto a Formatação Condicional quanto o Redis Cache foram moldados por feedback de clientes, projetados para ajudar você a lançar mais rápido, escalar de forma mais inteligente e entregar melhores insights.
