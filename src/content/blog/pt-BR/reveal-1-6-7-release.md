## **Novidades no Reveal 1.6.7?**

### **Nova Barra de Ferramentas \[Beta]**

Um dos recursos mais notáveis deste lançamento é a introdução da nova barra de ferramentas. Esta barra de ferramentas atualizada aprimora a experiência do usuário ao oferecer análise de dados avançada e recursos interativos. Acesse rapidamente zoom, formate gráficos em tempo real, adicione linhas de tendência e muito mais!

![New Dashboard Toolbar in Reveal](/images/2024/06/reveal-new-toolbar.png)

### **Filtragem Baseada em % do Gráfico \[Beta]**

A Filtragem Baseada em % do Gráfico no Reveal aprimora a interatividade do seu painel, permitindo interações baseadas em porcentagem em várias visualizações. Este recurso permite que um ponto de dados selecionado em um gráfico influencie e atualize dinamicamente outros gráficos no painel.

Quando você seleciona um valor percentual em uma visualização, o Reveal ajusta automaticamente outras visualizações relacionadas para refletir esse foco. Esse comportamento interconectado ajuda você a ver como um segmento dos seus dados impacta outros, fornecendo uma compreensão mais profunda de relacionamentos e contribuições dentro dos seus conjuntos de dados.

![Chart % Based Filtering ](/images/2024/06/reveal-chart-percentage-based-filtering.gif)

### **Evento de Carregamento/Alteração do Painel**

Com o novo recurso Evento de Carregamento/Alteração do Painel, o Reveal capacita os desenvolvedores a responderem com lógica personalizada quando um painel é carregado ou modificado. Ao aumentar a capacidade de resposta e a interação do aplicativo, ele permite a integração imediata de ações personalizadas após o carregamento ou alteração de dados.

## **Melhorias Adicionais**

Além desses novos recursos poderosos de análise, o lançamento do Reveal 1.6.7 também inclui várias melhorias, incluindo:

- **Segurança Aprimorada para Fontes de Dados SQL**: Removemos capacidades de consulta personalizadas do lado do cliente para reforçar a segurança e prevenir riscos como injeção SQL.
- **Tabelas Ordenadas Alfabeticamente**: Para um melhor gerenciamento de dados, as tabelas no diálogo de fonte de dados agora são ordenadas alfabeticamente.
- **Nova API para Filtros de Visualização**: Esta API permite que os usuários acessem e manipulem valores de filtro de visualização diretamente, aumentando a flexibilidade e a interação com os dados.

## **Correções de Bugs**

Como em todo lançamento, nossa atualização mais recente aborda vários bugs para garantir uma experiência mais confiável. As correções incluem melhorias nas exportações do Excel, correções de formatação de data e desempenho aprimorado. Para detalhes, consulte nossas [notas de lançamento](https://help.revealbi.io/web/release-notes).
