Esta atualização está repleta de melhorias de personalização, usabilidade e desempenho para ajudar você a construir experiências analíticas fluidas e de alto impacto mais rapidamente.

## Recursos da Última Atualização:

- **Personalização de Títulos de Eixo:** Modifique os títulos dos eixos diretamente no editor para um rótulo mais claro e preciso.

- **Linhas Fixas para Gráficos:** Defina pontos de referência estáticos para destacar tendências de dados importantes.

- **Rotulagem de Eixo Numérico Mais Inteligente:** Reduza a poluição de rótulos e melhore a legibilidade.

- **Posicionamento Flexível da Legenda do Gráfico:** Mova e alinhe legendas para um melhor design de painel.

- **Paginação de Grade com Classificação:** Organize dados instantaneamente com novos recursos de classificação de colunas.

- **Posicionamento Otimizado de Rótulos de Dados:** Visibilidade melhorada para gráficos de colunas e barras.

- **Atualização da API de Filtro de Data:** Filtragem mais estruturada para desenvolvedores.

Esses recursos revolucionários tornam mais fácil do que nunca entregar análises intuitivas e com a marca, dentro de seus aplicativos.

## **Detalhe dos Recursos: O que há de novo e o que isso significa para você**

### **Personalização de Títulos de Eixo: Mais Clareza, Menos Confusão**

- **Personalização Direta:** Clique e edite os títulos dos eixos diretamente no editor de visualização.

- **Melhor Legibilidade:** Rótulos mais descritivos significam interpretação de dados mais rápida.

### **Linhas Fixas: Defina Pontos de Referência Chave em Gráficos**

- **Pontos de Referência Estáticos:** Destaque facilmente limites importantes para melhores comparações.

- **Aparência Personalizável:** Ajuste a cor e a espessura da linha para melhor visibilidade.

![Ajuste a cor e a espessura da linha para melhor visibilidade](/images/2025/03/reveal-launch-1-7-3-employee-sales-abalysis-dashboard-body.png)

### **Rotulagem de Eixo Numérico: Limpa, Precisa e Legível**

- **Espaçamento Inteligente de Rótulos:** Evite sobreposição e rótulos desnecessários.

- **Exibição Otimizada:** Obtenha um visual mais limpo sem perder contexto crítico.

### **Legendas do Gráfico: Posicione e Alinhe para um Melhor Layout**

- **Posicionamento Flexível:** Mova legendas para o topo ou fundo das visualizações.

- **Alinhamento Personalizado:** Esquerda, direita ou centro — controle na aba Configurações.

### **Paginação de Grade: Agora com Classificação para Organização de Dados Mais Rápida**

- **Classificação Interativa:** Clique nos cabeçalhos das colunas para reordenar dados instantaneamente.

- **Usabilidade Melhorada:** Encontre e analise informações chave rapidamente.

### **Posicionamento Otimizado de Rótulos de Dados: Insights Mais Claros à Primeira Vista**

- **Gráficos de Colunas:** Os rótulos agora ficam acima das colunas para identificação rápida.

- **Gráficos de Barras:** Os rótulos aparecem à direita das barras para clareza melhorada.

- **Visibilidade Refinada:** Posicionamento aprimorado para fácil interpretação em vários gráficos.

### **Atualização da API de Filtro de Data: Mais Poder para Desenvolvedores**

- **Usabilidade Aprimorada da API:** O evento onDateFilterMenuOpening agora utiliza objetos IRVDateFilterMenuItem para um manuseio mais estruturado.

## **Conclusão: Construa Análises Mais Inteligentes, Rápidas e Intuitivas**

Esta atualização não se trata apenas de novos recursos — trata-se de dar a você mais controle, melhor desempenho e uma experiência analítica ainda mais fluida.

Para uma lista completa de melhorias, novos recursos e correções de bugs, certifique-se de conferir as [Notas de Lançamento](https://help.revealbi.io/web/release-notes/?_ga=2.67398801.1020496211.1741714344-323732178.1730367545).
