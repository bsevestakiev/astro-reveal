Se você tem usado o Reveal, você sabe como é fácil criar painéis com qualquer número de fontes de dados. O Reveal foi construído por especialistas em experiência do usuário e feito para usuários de negócios. Ele tem uma experiência familiar de arrastar e soltar que o torna simples de usar. No entanto, o editor de visualização está repleto de recursos sobre os quais você talvez nem saiba. Hoje, vamos guiá-lo por cada seção do editor e mostrar todas as capacidades que o Reveal possui.

**Campos**

**![All of the available fields within your data source in Reveal BI](/images/2020/10/6153.Feilds.png)**

Todos os campos disponíveis em sua fonte de dados aparecerão no painel esquerdo. Cada campo tem um indicador que informa aos usuários qual é o tipo de campo: Data, Valor, Texto. O ícone *mais* neste painel permite que você mescle fontes de dados ou calcule um campo:

- Mesclar Fonte de Dados: Este é um recurso poderoso que permite trazer campos de outra fonte e uni-los com base em um campo comum.
- Campo Calculado: Permite que você defina novos campos construídos com base em expressões usando os campos existentes.

**Campos de Visualização**
![Visualization Fields in Reveal BI ](/images/2020/10/4405.Fields.png)

É aqui que você arrastará e soltará, ou clicará no sinal de + para ver os campos disponíveis e selecionar aqueles que deseja usar para a visualização que está criando.

**Área de Trabalho de Visualização**
![Visualization Workspace in Reveal BI](/images/2020/10/7120.Visualization-Viewer.png)

É aqui que você poderá ver a visualização que está criando ou editando enquanto arrasta e solta campos. A visualização não será preenchida até que você tenha todos os campos necessários para criar esse tipo de gráfico.

![Visualization In Reveal BI when you are creating or editing as you drag and drop fields ](/images/2020/10/7120.Data-Source.png)

**Fonte de Dados**

A fonte de dados com a qual você está trabalhando será exibida aqui. Com um clique, você pode alternar entre diferentes planilhas, tabelas ou visualizações dentro da sua fonte ou alterar sua conexão para uma nova fonte inteiramente sem precisar sair do editor.

**Seletor de Visualização**

![Visualization Picker in Reveal BI ](/images/2020/10/6562.Visualization-Picker.png)

Alternar entre qualquer uma de nossas mais de 30 visualizações diferentes usando o seletor suspenso. À medida que você alterna entre os diferentes tipos de gráficos, você notará que a seção de campos de visualização muda. É aqui que o Reveal leva a facilidade de uso a um novo nível! Nós forneceremos todos os campos necessários que você precisa preencher para um determinado tipo de visualização – eliminando a necessidade de você pensar. Assim que todos os campos necessários para criar um gráfico bonito estiverem lá – seu gráfico será exibido na seção de área de trabalho de visualização.

**Configurações de Visualização**

![Visualization Settings in Reveal BI ](/images/2020/10/6562.Settings.png)

Cada visualização vem com suas próprias configurações que permitem que você personalize o que deseja mostrar:

- Grade: mostrar título, alinhamento de seus campos, tamanho da fonte, primeira coluna fixa
- Grade Dinâmica: mostrar título, alinhamento de seus campos, tamanho da fonte, totais gerais
- Coluna, Barra, Linha, Área, Área em Degraus, Linha em Degraus, Spline, Área Spline: mostrar título, mostrar legenda, cor inicial, linha de tendência do gráfico, configuração do eixo, limites do eixo
- Coluna Empilhada, Barra Empilhada, Área Empilhada: mostrar título, mostrar legenda, cor inicial, distribuição percentual, configuração do eixo, limites do eixo
- Texto: mostrar título, limites de formatação condicional para indicador
- Texto, Visualização Web: mostrar título
- Pizza, Rosca, Funil: mostrar título, mostrar legenda, cor inicial, posição inicial, formatação do rótulo da fatia
- Medidor Circular, Medidor Linear, Gráfico de Bullet: mostrar título, limites, limites de formatação condicional para indicador
- KPI vs Tempo, KPI vs Meta: mostrar título, período de tempo, formatação de diferença, cor do indicador
- OHLC, Candlestick: mostrar título, configuração do eixo, limites do eixo
- Radial: mostrar título, mostrar legenda, cor inicial, linha de tendência do gráfico
- Sparkline: mostrar título, alinhamento para campos, tamanho da fonte, tipo de gráfico, número de meses exibidos, como as duas últimas colunas, mostrar coluna de diferença, cor do indicador

Dentro de cada uma dessas telas de configurações, você verá a opção de links. Este é um recurso poderoso que leva o detalhamento (drill down) a um nível totalmente novo. Vincule uma visualização a um painel totalmente novo para mostrar mais detalhes com um clique. Ou vincule a uma URL que fornece insights mais profundos para seus usuários.
