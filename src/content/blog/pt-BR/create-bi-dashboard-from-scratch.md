Se você não está familiarizado com a criação de painéis, pode ser um pouco avassalador tentar descobrir como se conectar a todos os dados que você tem em diferentes sistemas e construir um painel para reunir todos os seus dados em uma visão completa de 360 graus do seu negócio.

O Reveal é um software de [business intelligence](/blog/business-intelligence-tools-enable-data-driven-decision-making) de autoatendimento que permite visualizar suas métricas de negócios importantes, como desempenho de marketing, monitoramento de tendências operacionais, visualização de KPIs e otimização de portfólios de clientes, em um local centralizado. Para mostrar como alcançar isso rapidamente, este blog guiará você pelos seguintes passos usando um arquivo Excel de dados de amostra fornecido dentro do aplicativo:

1. Conectar-se a um arquivo Excel
2. Criar visualizações
3. Alterar o tema de um painel
4. Salvar seu painel

No final, seu painel terá esta aparência:

![Como criar um painel no Reveal ](/images/2020/10/6685.Finished-Dashboard.png)

## Passos para Insights de Dados

Quando você entrar no Reveal pela primeira vez, será apresentado aos diferentes exemplos que construímos para você explorar. Para começar a criar o seu, navegue até a seção Painéis no painel lateral. Clique no botão novo no canto superior direito e selecione painel.

![Passos para Insights de Dados - clique no botão novo no canto superior direito e selecione painel](/images/2020/10/4544.1.png)

Para adicionar sua primeira visualização, clique no *sinal de mais* no canto superior direito. É aqui que você poderá escolher sua primeira fonte de dados para conectar aos seus dados:

![Passos para Insights de Dados - clique no mais no canto superior direito.](/images/2020/10/7268.Data-Source-Picker.png)

Dentro do OneDrive, navego até o arquivo que desejo trazer para o meu painel. Assim que seleciono meu arquivo Excel, o Reveal trará as diferentes planilhas que tenho dentro desse arquivo, com seus nomes (Marketing, Vendas). Além disso, posso escolher com que frequência quero que meus dados sincronizem com meu painel. Aqui você pode ver que selecionei uma vez por hora.

![Arquivo Excel configurado no Reveal](/images/2020/10/7268.Excel-FIle-Set-Up.png)

Assim que você seleciona sua planilha, será levado ao editor de widgets. No lado esquerdo, você verá todas as colunas dentro dessa planilha Excel, juntamente com um indicador do tipo de campo que elas são (Data, Valor, Categoria). Na barra superior é onde você pode selecionar seus tipos de visualização.

Ao começar a arrastar campos para o campo de colunas, você verá seus dados começarem a ser preenchidos à direita. Ou, se você souber a visualização que deseja criar, pode selecionar isso primeiro! O Reveal alterará os campos de entrada para informar exatamente o que você precisa para criar esse visual.
