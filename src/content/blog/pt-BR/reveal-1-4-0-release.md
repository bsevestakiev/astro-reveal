[Reveal](/) é um produto orientado pelo cliente – entregamos recursos com base no seu feedback contínuo para que você possa entregar mais valor aos seus clientes. Hoje, estamos entusiasmados em entregar 15 novos recursos e melhorias do produto para o editor de visualização Reveal, API, [fontes de dados](/data-sources), e docs.

## Aqui está o que há de novo no Reveal em nosso lançamento do T1 de 2023:

1. Novo: API de Coluna de Filtro para Editor de Visualização

2. Novo: Novos Gráficos Padrão com UX Atualizada

3. Novo: Consulta Personalizada adicionada ao Item de Fonte de Dados Snowflake

4. Novo: Propriedade para Warehouse em Fonte de Dados Snowflake

5. Novo: Consulta Personalizada adicionada ao Item de Fonte de Dados Athena

6. Novo: Consulta Personalizada adicionada para SQL Server em Servidor NodeJS

7. Novo: Suporte para ARM em Mac M1 / M2 Apple Native Silicon

8. Novo: Exportar para PDF/PPTX/Excel em Servidor NodeJS

9. Novo: Docs: Playground de Desenvolvedor - [https://help.revealbi.io/playground](https://help.revealbi.io/playground)

10. Novo: Docs: Trechos de Código TypeScript / Java

11. Novo: Amostras Github atualizadas em [https://github.com/RevealBi/sdk-samples-javascript](https://github.com/RevealBi/sdk-samples-javascript)

12. Melhoria: Tratamento Aprimorado de Título / Subtítulo na Configuração de Fonte de Dados Cliente

13. Melhoria: Requisito de Banco de Dados para Item de Fonte de Dados Athena no Cliente Removido

14. Melhoria: Pré-visualização de Fonte de Dados CVS

15. Melhoria: Habilitado Mais de 2 Tabelas em Joins Cliente

Também transferimos solicitações de suporte, relatórios de bugs e solicitações de recursos para o GitHub. [Enviar um problema](https://github.com/RevealBi/Reveal.Sdk/issues/new/choose) ou solicitação de recurso! Se você precisar de suporte em tempo real, os membros da equipe de produto Reveal estão prontos para ajudar - [inscreva-se](https://discord.com/invite/Ped3sSK5Xw) no Servidor Discord do Reveal e junte-se à Comunidade Reveal hoje!

## **Próximos Passos?**

Estamos trabalhando duro em conectores de dados, melhorias de UX e API, e capacidades avançadas de análise / inteligência artificial para ajudar você e seus clientes a tirar o máximo proveito de seus dados. Nosso lançamento do T2 será no período de maio/junho, e nossos objetivos para o ano estão no [blog do roadmap](/blog/reveal-roadmap). Para atualizações regulares e builds intermediárias, junte-se ao servidor Discord mencionado para anúncios e downloads.

Se você está procurando por recursos que não vê, tem uma nova ideia de produto, uma pergunta sobre o produto ou um problema de produto, envie um e-mail diretamente para [CaseyM@revealbi.io](mailto:CaseyM@revealbi.io) e vamos conversar! Obrigado por ser um cliente Reveal!
