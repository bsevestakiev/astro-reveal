- Análise Preditiva e Avançada

## Análise Avançada com Funções Estatísticas

Em apenas alguns cliques, você, como usuário de negócios, pode obter rapidamente mais insights sobre seus dados e realizar uma variedade de análises estatísticas usando qualquer uma das seguintes funções embutidas:

### Detecção de Outliers

Com a Detecção de Outliers, detecte facilmente pontos em seus dados que são anomalias e diferem de grande parte do seu conjunto de dados. Você pode mostrar ou ocultar esses outliers da visualização, para que eles estejam sempre visíveis ou para que não interfiram em sua análise.

![Outliers Detection in Reveal](/images/2020/11/4274.OUtliers.PNG-1040x1626-1.png)

### Previsão de Séries Temporais

Com a Previsão de Séries Temporais, o Reveal fará previsões de valores futuros com base em dados e tendências históricas. Isso é útil em inúmeras aplicações, como previsão de vendas e receita, gerenciamento de estoque e muitas outras.

![Time Series Forecasting in dashboard ](/images/2020/10/5340.Time-Series-Forecast.png)

### Regressão Linear

Com a Regressão Linear, você poderá ver visualmente tendências em seus dados encontrando a relação entre duas variáveis e vendo uma aproximação linear de seus dados – incluindo tendências futuras. Juntamente com a Regressão Linear, o Reveal inclui estas linhas de tendência de algoritmos: Linear Fit, Quadratic Fit, Cubic Fit, Quartic Fit, Logarithmic Fit, Exponential Fit, Power Law Fit, Simple Average, Exponential Average, Modified Average, Cumulative Average, e Weighted Average.

![Linear regeression ](/images/2020/10/7416.Linear-Regression.png)

## Machine Learning

Agora você pode trazer o poder do Machine Learning para o Reveal! A Integração de Modelos de Machine Learning do Microsoft Azure permite que você use modelos treinados aplicados aos seus dados do Azure Machine Learning Studio para construir visualizações bonitas. Basta apontar seus dados para a URL do seu modelo Azure e o Reveal renderizará uma visualização com base em seu cenário de machine learning. Você também pode usar modelos treinados aplicados aos seus dados da Google BigQuery Platforms para construir visualizações impressionantes.

![ Machine learning models in Reveal BI](/images/2020/10/ML-Models.png)

## Scripting em R e Python

Agora suportamos scripting em R e Python, que é a porta de entrada para o seu Cientista de Dados Cidadão interno realizar análises estatísticas e de dados que expandem os limites do que o Reveal pode fazer com seu conjunto de dados. Por exemplo, você pode pré-/pós-processar dados para melhorar sua saída de visualização ou renderizar visualizações exclusivas que estão incluídas em bibliotecas R ou Python. Basta colar uma URL para seus scripts ou colar seu código no editor de scripts.

![R & Python Scripting](/images/2020/10/R-_2600_-Python.png)

## Novos Conectores de Fonte de Dados!

Por demanda popular, adicionamos 3 novos conectores de dados importantes ao Reveal:

- Azure SQL
- Azure Synapse
- Google Big Query

Com esses novos conectores poderosos, você pode puxar milhões de registros para o Reveal e criar visualizações sem sacrificar a velocidade! Testamos 100 milhões de registros no Azure Synapse... e carrega num piscar de olhos!

Para as necessidades de Marketing, Vendas e TI, adicionamos novos conectores para:

- Google Analytics
- Microsoft SQL Server Reporting Services (SSRS)
- Salesforce

Com o Google Analytics, um dos serviços de análise web mais usados no mercado, você pode construir painéis que trazem insights do tráfego do seu site, uso de seus aplicativos e muito mais! Com o Reporting Services, você pode renderizar uma visualização PDF como uma Visualização Reveal ou usar os campos do seu relatório para criar novas visualizações que o Reporting Services não oferece. Isso é perfeito para usos legados – basta apontar sua URL do SSRS para o Reveal e dar vida nova e interativa aos seus dados.

![Connecting Google Analytics with Reveal BI](/images/2020/10/Google-Analytics.png)
