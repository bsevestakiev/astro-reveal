Explore como esses recursos revolucionários podem acelerar o crescimento do seu produto.

**Recursos da Última Atualização:**

- **Barras de Ferramentas Personalizadas:** Controle total sobre os menus do painel.

- **Filtragem Interativa:** Compare dados instantaneamente.

- **Controle de Título do Eixo:** Aprimore a clareza dos dados.

- **Visuais e Fontes de Dados Aprimorados:** Gráficos mais inteligentes, dados mais rápidos.

- **Controles para Desenvolvedores:** UI simplificada e suporte a SQLite.

![Obtenha controle total com ferramentas de personalização poderosas e interação de dados perfeita para construir experiências analíticas intuitivas e personalizadas. ](/images/2025/01/image.png)

## **Opções de Barra de Ferramentas Personalizadas: Controle Total Sobre os Menus**

Os desenvolvedores agora podem personalizar totalmente as barras de ferramentas de painel e visualização usando o manipulador de eventos revealView\.onMenuOpening. Isso permite que você:

- Adicionar itens de menu personalizados adaptados a painéis ou visualizações específicas.

- Ajustar dinamicamente o comportamento do menu com base nas condições do usuário (por exemplo, título da visualização).

- Ocultar itens de menu predefinidos para uma interface de usuário mais limpa.

**Exemplo:** Adicionar uma opção “Atualizar Todos os Dados” em todo o painel ou um botão “Ver Detalhes” em gráficos específicos como “Tarefas Concluídas.”

## **Filtragem Interativa: Compare Dados Instantaneamente**

O Reveal agora permite que os usuários filtrem e comparem dados dentro da mesma visualização. A nova opção “Filtrar Por” em tooltips permite que os usuários isolam e analisem dados lado a lado sem perder o contexto.

**Melhorias Principais:**

- Os filtros agora são somente leitura após serem aplicados para proteger a integridade dos dados.

- A filtragem baseada em data permite a seleção de uma única data para análise precisa.

- Suporta fontes de dados XMLA e destaca países selecionados em mapas coropletos.

## **Controle de Título do Eixo: Aprimore a Clareza dos Dados**

Os usuários agora podem alternar os títulos dos eixos no eixo x, eixo y, ou ambos, dando-lhes mais flexibilidade para enfatizar pontos de dados chave e tornar as visualizações mais fáceis de interpretar.

## **Melhorias em Visualização e Fontes de Dados**

**Ferramentas de Visualização Melhoradas:**

- Personalizar linhas de grade do eixo: nenhuma, horizontal, vertical ou ambas.

- Gráficos de rosca agora oferecem modos de rótulo central: nenhum, rótulo, valor ou ambos.

**Suporte Expandido a Fontes de Dados:**

- PostgreSQL agora suporta visões materializadas para processamento de dados mais rápido.

- BigQuery agora suporta mesclagem de dados para insights mais profundos.

## **Recursos Centrados no Desenvolvedor: Personalização Mais Inteligente**

**Atualizações do Reveal View:**

- Mostrar/Ocultar Título do Painel com a nova propriedade showTitle.

- Alternar o Botão Salvar com a propriedade ShowSave.

- Controlar Filtros de Visualização com showVisualizationFilters.

**Suporte à Plataforma:**

- O suporte a SQLite foi adicionado para ASP.NET e Node com criptografia opcional para segurança aprimorada.

**Conclusão: Pronto para Construir de Forma Mais Inteligente, Rápida e Melhor?**
