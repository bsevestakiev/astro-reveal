오늘부터 Reveal 사용자는 Databricks 환경에 직접 연결하여 당사의 완전한 임베디드 분석 경험을 사용하여 실시간 대시보드를 구축할 수 있습니다.

## 네이티브 Databricks 통합

Databricks 사용자는 이제 추가 단계나 복잡성 없이 실시간 인사이트를 애플리케이션에 직접 임베딩할 수 있습니다.

**Apache Spark**와 **ML tools**를 기반으로 구축된 클라우드 기반 데이터 플랫폼인 Databricks는 대규모 분석을 구동합니다. 이 새로운 커넥터는 해당 데이터를 라이브의, 인앱 대시보드로 쉽게 변환할 수 있게 해주며, 이는 사용자에게 완전히 통합되어 준비됩니다.

**이제 팀은 다음을 할 수 있습니다:**

- 몇 줄의 코드로 Databricks 데이터 연결
- 맞춤형 시각화를 사용하여 대시보드를 구축하고 공유
- Reveal의 SDK를 사용하여 분석을 앱에 직접 임베딩
- Reveal AI를 사용하여 Databricks 데이터에 자연어 질문하기

Reveal을 사용하면 이러한 인사이트는 더 이상 사일로화되지 않습니다. 팀이 구축하는 애플리케이션 내부에 네이티브하게 제공됩니다.

## 추가 기술 개선 사항

1.7.4 업데이트에 포함된 내용:

**Java HTTP Client**: 향상된 오류 처리 + 로그 개선

**DSI.DataSource**: 간소화된 설정—수동 구성 불필요

**S3 SessionToken 지원**: 개선된 AWS Athena 호환성

**버그 수정 + 성능**: 지속적인 속도 및 안정성 개선

개선 사항, 새로운 기능 및 버그 수정 목록 전체를 확인하려면 전체 [릴리스 노트](https://help.revealbi.io/web/release-notes/?_gl=1*viwg03*_gcl_au*MTQ1MDIyNjU3NC4xNzQ2MDAwNjE4*_ga*MTA0OTA3MTg2LjE3NDA2NTkxNzY.*_ga_PN11HXDV6X*czE3NDczMDIxNjkkbzQyOSRnMSR0MTc0NzMwMjIwOSRqMjAkbDAkaDgwODc0NzE4NA..&_ga=2.10375347.76541148.1747209420-104907186.1740659176)를 확인하세요.
