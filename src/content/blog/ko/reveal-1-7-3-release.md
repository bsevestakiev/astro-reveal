이 업데이트에는 사용자 지정성, 사용성 및 성능 개선 사항이 가득 담겨 있어 더욱 빠르고 원활하며 영향력 있는 분석 경험을 구축하는 데 도움을 줍니다.

## 최신 업데이트 기능:

- **축 제목 사용자 지정:** 편집기에서 축 제목을 직접 수정하여 더 명확하고 정확한 레이블링을 할 수 있습니다.

- **차트용 고정선:** 정적인 참조점을 설정하여 주요 데이터 추세를 강조합니다.

- **더 스마트한 숫자 축 레이블링:** 레이블 혼잡도를 줄이고 가독성을 향상시킵니다.

- **유연한 차트 범례 위치 지정:** 더 나은 대시보드 디자인을 위해 범례를 이동하고 정렬할 수 있습니다.

- **정렬 기능이 포함된 그리드 페이지 매김:** 새로운 열 정렬 기능을 통해 데이터를 즉시 정리할 수 있습니다.

- **최적화된 데이터 레이블 배치:** 열 차트 및 막대 차트의 가시성이 향상되었습니다.

- **날짜 필터 API 업데이트:** 개발자를 위한 보다 구조화된 필터링을 제공합니다.

이러한 혁신적인 기능들은 애플리케이션 내부에 직관적이고 브랜드에 맞는 분석을 제공하는 것을 그 어느 때보다 쉽게 만듭니다.

## **기능 상세 분석: 새로운 기능 및 사용자에게 미치는 영향**

### **축 제목 사용자 지정: 더 높은 명확성, 낮은 혼란**

- **직접 사용자 지정:** 시각화 편집기에서 축 제목을 클릭하고 바로 편집할 수 있습니다.

- **향상된 가독성:** 더 설명적인 레이블은 더 빠른 데이터 해석을 의미합니다.

### **고정선: 차트에서 주요 벤치마크 설정**

- **정적 참조점:** 더 나은 비교를 위해 중요한 임계값을 쉽게 강조 표시할 수 있습니다.

- **사용자 지정 가능한 모양:** 더 나은 가시성을 위해 선의 색상과 두께를 조정할 수 있습니다.

![Adjust line color and thickness for better visibility](/images/2025/03/reveal-launch-1-7-3-employee-sales-abalysis-dashboard-body.png)

### **숫자 축 레이블링: 깔끔하고, 정확하며, 가독성이 높음**

- **스마트 레이블 간격:** 겹치거나 불필요한 레이블을 방지합니다.

- **최적화된 표시:** 중요한 맥락을 잃지 않으면서 더 깔끔한 모양을 얻을 수 있습니다.

### **차트 범례: 더 나은 레이아웃을 위한 위치 지정 및 정렬**

- **유연한 위치 지정:** 범례를 시각화의 상단 또는 하단으로 이동할 수 있습니다.

- **사용자 지정 정렬:** 왼쪽, 오른쪽 또는 중앙—설정 탭에서 제어할 수 있습니다.

### **그리드 페이지 매김: 이제 정렬 기능으로 더 빠른 데이터 정리 가능**

- **대화형 정렬:** 열 헤더를 클릭하여 데이터를 즉시 재정렬할 수 있습니다.

- **향상된 사용성:** 핵심 정보를 빠르고 쉽게 찾고 분석할 수 있습니다.

### **최적화된 데이터 레이블 배치: 한눈에 더 명확한 통찰력**

- **열 차트:** 레이블이 이제 열 위에 위치하여 빠른 식별이 가능합니다.

- **막대 차트:** 레이블이 막대 오른쪽에 나타나 명확성이 향상되었습니다.

- **개선된 가시성:** 차트 전반에 걸쳐 쉬운 해석을 위한 향상된 배치입니다.

### **날짜 필터 API 업데이트: 개발자를 위한 더 많은 기능**

- **향상된 API 사용성:** onDateFilterMenuOpening 이벤트는 이제 더 구조화된 처리를 위해 IRVDateFilterMenuItem 객체를 활용합니다.

## **결론: 더 스마트하고, 빠르며, 직관적인 분석 구축**

이 업데이트는 단순히 새로운 기능에 관한 것이 아니라, 더 많은 제어권, 더 나은 성능, 그리고 훨씬 더 원활한 분석 경험을 제공하는 것입니다.

향상된 기능, 새로운 기능 및 버그 수정 목록 전체를 확인하려면 전체 [릴리스 노트](https://help.revealbi.io/web/release-notes/?_ga=2.67398801.1020496211.1741714344-323732178.1730367545)를 확인하십시오.
