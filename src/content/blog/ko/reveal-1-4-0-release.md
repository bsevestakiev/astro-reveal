[Reveal](/)는 고객 주도형 제품입니다. 고객의 지속적인 피드백을 바탕으로 기능을 제공하여 고객에게 더 많은 가치를 전달할 수 있도록 합니다. 오늘 저희는 Reveal 시각화 편집기, API, [데이터 소스](/data-sources), 및 문서에 15가지 새로운 기능 및 제품 개선 사항을 제공하게 되어 기쁩니다.

## Reveal Q1 2023 릴리스의 새로운 기능:

1. New: 시각화 편집기용 필터 열 API

2. New: 업데이트된 UX가 적용된 새로운 기본 차트

3. New: Snowflake 데이터 소스 항목에 사용자 지정 쿼리 추가

4. New: Snowflake 데이터 소스에서 웨어하우스 속성 추가

5. New: Athena 데이터 소스 항목에 사용자 지정 쿼리 추가

6. New: NodeJS 서버에서 SQL Server용 사용자 지정 쿼리 추가

7. New: Mac M1 / M2 Apple Native Silicon용 ARM 지원

8. New: NodeJS 서버에서 PDF/PPTX/Excel로 내보내기

9. New: 문서: 개발자 플레이그라운드 - [https://help.revealbi.io/playground](https://help.revealbi.io/playground)

10. New: 문서: TypeScript / Java 코드 스니펫

11. New: [https://github.com/RevealBi/sdk-samples-javascript](https://github.com/RevealBi/sdk-samples-javascript)의 업데이트된 Github 샘플

12. Enhancement: 클라이언트 측 데이터 소스 구성에서 제목/부제목 처리 개선

13. Enhancement: 클라이언트 측에서 Athena 데이터 소스 항목 데이터베이스 요구 사항 제거

14. Enhancement: CVS 데이터 소스 미리 보기

15. Enhancement: 클라이언트 측 조인에서 2개 이상의 테이블 활성화

또한 지원 요청, 버그 보고서 및 기능 요청을 GitHub로 옮겼습니다. [이슈 제출](https://github.com/RevealBi/Reveal.Sdk/issues/new/choose) 또는 기능 요청을 해주세요! 실시간 지원이 더 필요하다면, Reveal 제품 팀 멤버들이 도움을 드릴 준비가 되어 있습니다. Reveal Discord Server에 [가입](https://discord.com/invite/Ped3sSK5Xw)하고 오늘 Reveal 커뮤니티에 참여하세요!

## **다음 계획은?**

저희는 고객과 고객이 데이터로부터 최대한의 가치를 얻을 수 있도록 데이터 커넥터, UX 및 API 개선, 고급 분석/인공지능 기능을 위해 열심히 노력하고 있습니다. Q2 릴리스는 5월/6월경에 있을 예정이며, 연간 목표는 [로드맵 블로그](/blog/reveal-roadmap)에서 확인할 수 있습니다. 정기 업데이트 및 임시 빌드를 받으려면, 공지 및 다운로드를 위해 앞서 언급된 Discord 서버에 가입하세요.

만약 찾고 있는 기능이 없거나, 새로운 제품 아이디어나 제품 관련 질문, 또는 제품 문제가 있다면, [CaseyM@revealbi.io](mailto:CaseyM@revealbi.io)로 직접 이메일을 보내주시고 논의해 봅시다! Reveal 고객이 되어주셔서 감사합니다!
