## **임베딩을 위한 데이터 분석 빌드 – 간단하고. 빠르고. 예측 가능합니다.**

이것이 Reveal의 헤드라인입니다.  저희가 [임베디드 분석](/embedded-analytics) 제품을 출시한 이래로, 3가지 주요 목표를 가지고 왔습니다:

- **빠르고 쉬운 통합** – 고객이 추가 요구 사항 없이 기존 애플리케이션에 통합할 수 있는 사용하기 쉬운 데이터 분석 솔루션을 제공합니다. [Reveal의 유연한 아키텍처와 풍부한 API](https://static.infragistics.com/marketing/reveal/reveal-architecture-and-security-2021-02.pdf?_ga=2.4049392.1164794683.1623678258-1759676262.1615825090&gasource=google&gamedium=organic&gacampaign=(not%20set)&gaterm=(not%20provided))는 앱의 기능을 제어할 수 있게 하여, 사용자 앱 경험의 원활한 부분이 되도록 합니다.
- **뛰어난 사용자 경험**– 사용자가 애플리케이션을 벗어나지 않고도 자체 데이터 시각화에 머신러닝 모델을 생성, 편집 및 적용하기 쉽게 만들어 사용자에게 흥미를 유발합니다. [증거 기반 의사 결정](/blog/reveal-data-driven-decision-making)의 채택률을 높입니다.
- **투명하고 저렴한 가격 책정** – 어떤 놀라움 없이 정확히 얼마를 지불하게 될지 아십시오. 저희의 간단하고 고정된 가격으로, 추가 사용료를 지불할 필요 없이 모든 장치에서 무제한 사용자에게 도달할 수 있습니다.

저희의 목표는 셀프 서비스 BI, 심층 데이터 분석, 그리고 [데이터 스토리텔링](/glossary/data-driven-storytelling)을 위한 놀라운 최종 사용자 UX를 제공하는 것입니다.  이를 통해 사용하기 쉽고 시작하기 쉬운 SDK 경험을 제공합니다. 이는 귀하와 이해관계자에게 엄청난 가치를 제공하는 적절한 수준의 기능을 갖춘 간단하고 아름다운 경험을 의미합니다.

이 점을 염두에 두고, 저희는 다음 4개 영역에 노력을 집중하고 있습니다:

- 데이터 커넥터
- 데이터 시각화 사용자 경험
- SDK 내 사용하기 쉬운 API
- 고급 분석 / 인공지능

역사적으로, 주요 기능은 8~10주 간격으로, 그리고 월별 및 온디맨드 핫픽스와 함께 제공됩니다. 즉, 몇 달마다 대규모 기능(새 데이터 커넥터 또는 새 차트 유형과 같은)과 월별 또는 그 이전에 더 작은 기능이나 버그 수정이 있을 것으로 예상할 수 있습니다.

*버그의 경우, 저희가 해결책을 제공할 수 없는 심각한 버그가 있다면, 수정되는 즉시 제공해 드립니다*\*– 저희는 귀하가 저희와 마찬가지로 소프트웨어를 구축하고 있다는 것을 알기 때문에, 이러한 문제의 중요성과 긴급성을 이해할 수 있습니다.\*

*SDK를 설치/업데이트할 때, 버그가 수정됨에 따라 버전을 선택할 수 있으며, 어떤 버전을 설치해야 하는지 알려드리겠습니다.*

## 2022년에 출시된 기능

2022년은 기능 제공이 활발했던 한 해였습니다. 주요 하이라이트 중 일부는 NodeJS 서버와 Reveal Dom이었습니다. NodeJS 서버를 통해 Angular, React, Vue 및 기타 최신 웹 플랫폼에서 앱을 구축하는 팀은 기존 ASP.NET Core 및 Java 서버 변형 SDK 위에 새로운 옵션을 갖게 되었습니다. Reveal Dom 프로젝트는 Reveal .rdash 파일 형식에 대한 Document Object Model (DOM)입니다. 이는 Reveal SDK를 사용하는 개발자가 .NET을 사용하여 대시보드를 로드, 편집 및 생성할 수 있도록 합니다.

이러한 대규모 기능 외에도, 기존 고객들로부터 수많은 기능 요청 및 업데이트를 처리했으며 데이터 소스 및 업데이트된 차트 기능을 계속해서 발전시켰습니다. 여기에 올해 현재까지의 업데이트 전체 목록이 있습니다.

### 데이터 시각화 사용자 경험

- 차트 확대 수준과 스크롤바를 활성화하여 차트의 초기 수평 또는 수직 확대 수준을 설정할 수 있는 새로운 API 및 UI.
- 차트 시리즈에 대한 색상 할당을 허용하는 새로운 API.
- 파이 차트 "기타" 그룹에 대한 임계값 사용자 정의를 위한 새로운 API.
- 새로운 시리즈 색상 및 데이터 레이블 옵션을 포함하여 모든 차트 유형에 대한 새로운 시각화.

### 데이터 커넥터

- Google Search Console 데이터 커넥터
- Salesforce Marketing Cloud 업데이트
- Google Analytics 업데이트

### SDK

- 새로운 NodeJS 서버.
- 웹용 Reveal Client SDK를 위한 새로운 글로벌 CDN 옵션.
- 서버 측 내보내기 작업을 위한 새로운 Headless Exporting.
- 새로운 대화형 차트 필터링.
- 사용자 지정 데이터 소스 대화 상자를 허용하고 선택된 데이터 소스를 시각화에 설정하는 새로운 콜백.
- 시각화에 사용할 특정 데이터 소스를 간단히 찾기 위한 새로운 데이터 소스 검색/필터 텍스트 상자.
- JavaScript SDK용 새로운 지역화/형식 지정 옵션.
- 큐브 기반 데이터 소스를 위한 새로운 메타데이터 속성.
- 시각화 배경색을 변경하는 새로운 속성.
- 대시보드의 제목(이름 + kebab)을 표시/숨김하는 새로운 속성.
- 데이터 객체 이름에 대한 새로운 서버 측 필터링.
- 데이터 소스에 대한 새로 고침 빈도를 설정하는 새로운 옵션.
- Playwright를 사용한 내보내기 시 Puppeteer 종속성 제거.
- REST 데이터 소스에 대한 업데이트된 날짜 처리.
- 추가 데이터 소스를 추가하기 위한 업데이트된 열거형.
- 대시보드 파일 이름 처리 업데이트 – 이제 대소문자를 구분하지 않으므로, 대시보드 이름을 변수로 전달하기 위해 추가 코드를 작성할 필요가 없습니다.
- 이전에 데이터베이스에서 얻은 대로 날짜가 표시되던 곳에서 사용자가 로컬 시간대에 날짜를 볼 수 있는 업데이트된 옵션.
- 압축된 Reveal client SDK의 파일 크기 개선.

## Reveal의 2023년 로드맵

저희의 로드맵은 고객 주도형입니다. 저희가 추가하는 모든 것은 고객 피드백과 수요를 기반으로 합니다. 저희가 시장에서 경쟁력을 갖는다고 믿는 항목이나 일반적인 시장 방향 또는 분석가 피드백을 기반으로 하는 기능을 추가할 수도 있지만, 성공적인 소프트웨어를 제공하는 데 필요한 귀하의 요구 사항에 맞춰 끊임없이 조정하고 적응하고 있습니다.

2023년 상반기에는 몇 가지 주요 항목에 집중하고 있습니다:

- 드릴다운 및 차트 필터링을 위한 개선된 툴팁 UX
- 차트 도구 모드 및 고정선을 통한 차트의 전반적인 UX 개선
- jQuery 종속성을 제거하기 위한 클라이언트 SDK 리팩토링
- 클라이언트 SDK의 Reveal View를 위한 개선된 API (간소화된 API)
- MongoDB 데이터 커넥터

가장 큰 UX 기능이 차트 도구 모드 작업이므로, 기대할 수 있는 내용을 알 수 있도록 저희가 나아가는 방향을 살펴보겠습니다.

### 차트 도구 모드

차트 도구 모드 기능은 대시보드의 각 시각화에서 생성자와 뷰어에게 더 많은 분석 기능을 제공하는 것을 목표로 합니다. 차트 유형(게이지, 파이 차트, 라인 차트, 막대 차트 등)에 따라 다양한 옵션을 사용할 수 있습니다.

일반적인 라인 차트의 도구 모드 예시입니다:

![chart toolbar feature](/images/2022/07/embedded-analytics-Chart-Toolbar-1024x278.jpg)

도구 모드는 항상 표시되는 것은 아니며, 시각화가 호버 상태일 때 표시됩니다:

![embedded analytics dashboard example](/images/2022/07/embedded-dashboard-1024x544.jpg)

도구 모드 항목을 클릭하면 분석 경험을 사용자 정의하기 위한 더 많은 옵션을 볼 수 있습니다. 예를 들어, '분석(Analyze)' 도구 모드 버튼이 있으며, 여기에서 드릴다운 메뉴를 통해 대시보드에 표시/숨김할 추가 기능을 제공하는 고정선, 추세선, 이상치 감지 등을 추가할 수 있습니다.

![analyze toolbar item feature](/images/2022/07/embedded-analytics-Analyze-Toolbar-Item.jpg)

대시보드 생성자가 대시보드를 구축할 때 추가한 모든 고정선은 기본적으로 표시되지만, 대시보드 뷰어는 볼 때 고정선을 켜거나 끌 수 있습니다. SDK는 메뉴 항목을 기본적으로 켜거나 끌 수 있는 옵션을 제공하므로, 예를 들어 분석 도구 모드 옵션을 완전히 숨겨 뷰어가 생성자가 정의한 내용만 보도록 강제할 수 있습니다.

### 라인 사용자 정의

생성자로서, 분석을 위한 도구 모드 옵션은 동일하지만, 무엇이 표시되고 어떻게 표시되는지에 대해 더 많은 제어 권한을 갖습니다. 예를 들어, 고정선에 대한 매개변수를 사용자 정의하거나, 여러 분위수(Percentile) 고정선을 추가하거나, 수익 목표 또는 목표 전환과 같은 사용자 지정 레이블이 있는 사용자 지정 고정선을 추가할 수 있습니다.

대시보드를 생성할 때 드롭다운 메뉴가 어떻게 보이는지 다음을 참조하십시오:

![creator fixed lines feature](/images/2022/07/embedded-analytics-Creator-Fixed-Lines-1024x538.jpg)

또한, 설정(Settings)에서 새로운 분석 라인(Analytics Lines) 섹션을 볼 수 있으며, 여기에서 시각화에 추가하는 라인의 모양과 느낌을 더욱 사용자 정의할 수 있습니다.

![creator customize line styles ](/images/2022/07/embedded-analytics-Creator-Customize-Line-Styles-1024x540.jpg)

사용자 정의할 수 있는 옵션은 다음과 같습니다:

- 색상
- 선 두께
- 선 스타일 (실선, 점선, 대시, 중간 크기 대시, 중간 크기 대시 / 짧은 대시, 긴 대시, 긴 대시 / 짧은 대시, 긴 대시 / 짧은 대시 / 짧은 대시)
