Reveal을 사용해 오셨다면, 어떤 데이터 소스로든 대시보드를 얼마나 쉽게 만들 수 있는지 아실 겁니다. Reveal은 사용자 경험 전문가들이 구축했으며 비즈니스 사용자를 위해 만들어졌습니다. 친숙한 드래그 앤 드롭 경험 덕분에 사용하기 매우 간단합니다. 하지만 시각화 편집기에는 모른다고 생각할 수도 있는 기능들이 가득합니다. 오늘 저희는 편집기의 각 섹션을 안내해 드리고 Reveal이 가진 모든 기능을 보여드리겠습니다.

**필드(Fields)**

**![Reveal BI에서 사용 가능한 모든 데이터 소스 필드](/images/2020/10/6153.Feilds.png)**

데이터 소스 내에서 사용 가능한 모든 필드는 왼쪽 패널에 표시됩니다. 각 필드에는 해당 필드의 유형(날짜, 값, 텍스트)을 사용자에게 알려주는 표시기가 있습니다. 이 패널의 *플러스* 아이콘을 사용하면 데이터 소스를 결합하거나 필드를 계산할 수 있습니다.

- 데이터 소스 결합(Blend Data Source): 이 강력한 기능은 다른 소스에서 필드를 가져와 공통 필드를 기반으로 결합할 수 있게 해줍니다.
- 계산된 필드(Calculated Field): 기존 필드를 사용하여 수식 기반으로 새로운 필드를 정의할 수 있습니다.

**시각화 필드(Visualization Fields)**
![Reveal BI의 시각화 필드 ](/images/2020/10/4405.Fields.png)

여기는 드래그 앤 드롭을 하거나 + 표시를 클릭하여 사용 가능한 필드를 보고, 만들고자 하는 시각화에 사용할 필드를 선택하는 곳입니다.

**시각화 작업 공간(Visualization Workspace)**
![Reveal BI의 시각화 작업 공간](/images/2020/10/7120.Visualization-Viewer.png)

여기는 필드를 드래그 앤 드롭함에 따라 만들거나 편집하는 시각화를 볼 수 있는 곳입니다. 필요한 모든 필드가 갖춰지기 전까지는 시각화가 채워지지 않습니다.

![필드를 드래그 앤 드롭하여 만들거나 편집하는 Reveal BI의 시각화](/images/2020/10/7120.Data-Source.png)

**데이터 소스(Data Source)**

현재 작업 중인 데이터 소스가 여기에 표시됩니다. 클릭 한 번으로 소스 내의 다른 시트, 테이블 또는 뷰 간에 전환하거나, 편집기를 떠나지 않고도 완전히 새로운 소스로 연결을 변경할 수 있습니다.

**시각화 선택기(Visualization Picker)**

![Reveal BI의 시각화 선택기 ](/images/2020/10/6562.Visualization-Picker.png)

드롭다운 선택기를 사용하여 30가지가 넘는 다양한 시각화 유형 간에 전환할 수 있습니다. 다른 차트 유형 간에 전환할 때 시각화 필드 섹션이 변경되는 것을 알 수 있습니다. 바로 이곳에서 Reveal이 사용 편의성을 새로운 차원으로 끌어올립니다! 특정 시각화 유형을 위해 필요한 모든 필드를 제공하여, 사용자가 생각할 필요를 없애줍니다. 아름다운 차트를 만드는 데 필요한 모든 필드가 갖춰지면, 차트가 시각화 작업 공간 섹션에 표시됩니다.

**시각화 설정(Visualization Settings)**

![Reveal BI의 시각화 설정 ](/images/2020/10/6562.Settings.png)

각 시각화는 원하는 것을 사용자 정의할 수 있는 자체 설정을 가지고 있습니다.

- 그리드(Grid): 제목 표시, 필드 정렬, 글꼴 크기, 고정 첫 번째 열 표시
- 피벗 그리드(Pivot Grid): 제목 표시, 필드 정렬, 글꼴 크기, 총합계 표시
- 열(Column), 막대(Bar), 선(Line), 영역(Area), 단계 영역(Step Area), 단계 선(Step Line), 스플라인(Spline), 스플라인 영역(Spline Area): 제목 표시, 범례 표시, 시작 색상, 차트 추세선, 축 구성, 축 범위 표시
- 누적 열(Stacked Column), 누적 막대(Stacked Bar), 누적 영역(Stacked Area): 제목 표시, 범례 표시, 시작 색상, 백분율 분포, 축 구성, 축 범위 표시
- 텍스트(Text): 제목 표시, 지표에 대한 조건부 서식 범위 표시
- 텍스트(Text), 웹 보기(Web View): 제목 표시
- 파이(Pie), 도넛(Doughnut), 깔때기(Funnel): 제목 표시, 범례 표시, 시작 색상, 시작 위치, 슬라이스 레이블 서식 표시
- 원형 게이지(Circular Gauge), 선형 게이지(Linear Gauge), 벌트 그래프(Bullet Graph): 제목 표시, 제한 범위, 지표에 대한 조건부 서식 범위 표시
- KPI 대 시간(KPI vs Time), KPI 대 목표(KPI vs Target): 제목 표시, 기간, 차이 서식, 지표 색상 표시
- OHLC, 캔들스틱(Candlestick): 제목 표시, 축 구성, 축 범위 표시
- 방사형(Radial): 제목 표시, 범례 표시, 시작 색상, 차트 추세선 표시
- 스파크라인(Sparkline): 제목 표시, 필드 정렬, 글꼴 크기, 차트 유형, 표시할 월 수, 마지막 두 열 표시 방식, 차이 열 표시, 지표 색상 표시

이러한 각 설정 화면 내에서 링크 옵션을 볼 수 있습니다. 이는 드릴다운을 완전히 새로운 차원으로 끌어올리는 강력한 기능입니다. 시각화를 완전히 새로운 대시보드에 연결하여 클릭 한 번으로 더 많은 세부 정보를 보여줄 수 있습니다. 또는 사용자에게 더 깊은 통찰력을 제공하는 URL로 연결할 수도 있습니다.
