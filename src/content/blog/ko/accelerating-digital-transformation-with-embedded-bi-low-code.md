포괄적인 소프트웨어 솔루션을 만드는 것은 어려운 작업일 수 있습니다. 오늘날의 빠르게 변화하는 세상에서 사용자들은 애플리케이션에 대해 높은 기대를 가지고 있으며, 이러한 요구 사항을 따라잡는 것은 결코 쉬운 일이 아닙니다. 다행히도 우리는 애플리케이션의 모든 측면을 수동으로 코딩하는 데 몇 달 또는 심지어 몇 년을 소비할 필요 없이, 원활하고 기능이 풍부한 사용자 경험을 달성할 수 있는 시대에 살고 있습니다.

오늘날에는 놀라운 사용자 경험, 원활한 상호 작용, 원활한 테마 지정, 강력한 데이터 바인딩, 셀프 서비스 대시보드, 그리고 강력한 [비즈니스 인텔리전스](/glossary/business-intelligence)를 갖춘 소프트웨어 솔루션을 개발하는 것이 가능할 뿐만 아니라 매우 효율적입니다. 본 블로그에서는 번거롭고 오류가 발생하기 쉬운 수동 코딩으로 전통적으로 몇 주 또는 몇 달이 걸리는 대신, 단 몇 분 만에 이 모든 것을 어떻게 달성할 수 있는지 보여드리겠습니다.

이 흥미로운 소프트웨어 개발 분야를 선도하는 사람은 당사의 개발자 도구 수석 부사장인 Jason Beres입니다. 최근 그는 엔터프라이즈 기술 분야의 산업 전문가들을 위한 독점 이벤트인 [Solutions Review](https://solutionsreview.com/)의 Solution Spotlights 웨비나에서 게스트 연사로 무대에 올랐습니다. 이 행사에서 Jason은 임베디드 BI(Reveal)와 로우코드 도구(App Builder)의 세계를 깊이 파고들었으며, 이들이 디지털 전환 노력을 어떻게 가속화할 수 있는지 시연했습니다.

## Reveal 소개

셀프 서비스 비즈니스 인텔리전스가 애플리케이션에 원활하게 통합되어 데이터 상호 작용 방식을 변화시키는 세상을 상상해 보세요. [Reveal](https://samples.revealbi.io/reveal-sdk-samples/2020-survey-results.html)은 셀프 서비스 BI 개념을 가져와 강력한 SDK로 제시하며, 구식 iframe [통합 방식](/blog/embedded-analytics-vs-iframes)에 의존하는 기존 솔루션들과 차별화됩니다. [Reveal’s SDK](/download-sdk)는 비교할 수 없는 유연성을 제공하며 사용자 경험을 재정의합니다. [React](/blog/embedding-self-service-bi-in-react-apps-with-node-js) 또는 [Angular](/blog/embedding-bi-in-angular-apps)와 같은 기술로 웹 애플리케이션을 개발하든, [Blazor](/blog/embedding-bi-in-blazor-applications) 또는 웹 컴포넌트를 탐색하든, WPF 또는 Windows Forms로 데스크톱 애플리케이션을 제작하든, Reveal이 모든 것을 지원합니다.

다음은 Reveal의 주요 이점입니다.

- iframe의 필요성을 제거하는 진정한 임베디드 SDK
- 애플리케이션에 직접 통합할 수 있는 강력한 API로 네이티브하고 원활한 경험 보장
- 직관적인 드래그 앤 드롭 인터페이스
- 가격 구조에 숨겨진 비용이나 복잡성이 없음
- 다양한 플랫폼 및 기술 스택 전반의 호환성
- 사용자가 대시보드의 모양과 느낌을 브랜드 또는 애플리케이션 미학과 일치하도록 맞춤 설정할 수 있음
- 간소화된 대시보드 편집
- SDK 접근 방식을 통한 클라이언트와 서버에 대한 100% 제어

## App Builder 소개

60개 이상의 풍부한 UI 컴포넌트 도구 상자와 고성능 데이터 그리드 및 차트 전체 제품군을 사용하여 레거시 앱을 현대적이고 반응형 웹 경험으로 변환하세요. [App Builder](https://www.appbuilder.dev/)는 클라우드 기반의 WYSIWYG, 로우코드 도구로, 현대 웹 앱 개발을 가속화하여 팀이 앱을 80% 더 빠르게 제공할 수 있도록 합니다. 이 도구는 앱에 고유한 정체성을 부여하기 위해 사전 구축된 템플릿, 반응형 레이아웃, 사용자 정의 테마가 가득합니다. App Builder는 또한 60개 이상의 UI 컨트롤 도구 상자를 제공하며 Angular, Blazor, Web Components용 코드 생성을 지원하여 프로덕션 준비가 된 HTML, TypeScript, CSS에 디자인의 픽셀 단위 완벽한 표현을 보장합니다. 또한, Sketch 또는 Figma designs를 손쉽게 가져오고 모든 REST 데이터 소스에 연결할 수 있습니다.

다음은 App Builder의 주요 이점입니다.

- 반복적이고 사소한 작업을 위한 오류가 발생하기 쉬운 수동 코딩 제거.
- 디자인 파일을 데이터가 풍부한 앱으로 변환.
- 앱 화면의 UI 및 UX 디자인에 드는 개발자의 시간 80% 절약.
- 데이터 바인딩, 탐색 및 테마 지정 제공.
- Angular, Blazor, Web Components 전반에 걸쳐 컴포넌트 및 기능의 동등성 보장.
- 코드 미리 보기 및 원클릭 코드 생성 제공.

## Reveal BI + App Builder

Reveal과 App Builder가 결합할 때 마법이 일어납니다. 개발자는 App Builder 도구 상자에서 Reveal 대시보드를 직접 통합하고, Reveal 서버 SDK가 호스팅하는 데이터의 URL을 지정할 수 있습니다. 그 결과는 [임베디드 분석](/embedded-analytics)과 빠른 앱 개발의 조화로운 결합으로, 이 기술들이 수렴할 때 가능한 것을 미리 보여줍니다.

Reveal과 App Builder 모두 개발자가 전통적인 제약에서 벗어나 임베디드 BI와 원활하게 통합된 놀라운 애플리케이션을 제공할 수 있도록 지원합니다. 전체 잠재력을 확인하고 라이브 데모를 탐색하려면, Solutions Review의 Solution Spotlights에서 Jason Beres의 전체 웨비나를 시청하세요.

이러한 도구들을 더 자세히 탐색하는 데 관심이 있다면, 무료 체험을 시작하거나 당사 제품 전문가와 데모를 예약할 수 있습니다.
