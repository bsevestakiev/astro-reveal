이러한 혁신적인 기능들이 제품 성장을 어떻게 가속화할 수 있는지 알아보세요.

**최신 업데이트 기능:**

- **사용자 지정 도구 모음:** 대시보드 메뉴에 대한 완벽한 제어.

- **대화형 필터링:** 데이터를 즉시 비교하세요.

- **축 제목 제어:** 데이터 명확성을 높이세요.

- **향상된 시각화 및 데이터 소스:** 더 스마트한 차트, 더 빠른 데이터.

- **개발자 제어:** 간소화된 UI 및 SQLite 지원.

![강력한 사용자 지정 도구와 원활한 데이터 상호 작용을 통해 맞춤형의 직관적인 분석 경험을 구축하여 완벽한 제어권을 얻으세요. ](/images/2025/01/image.png)

## **사용자 지정 도구 모음 옵션: 메뉴에 대한 완벽한 제어**

개발자는 이제 revealView\.onMenuOpening 이벤트 핸들러를 사용하여 대시보드 및 시각화 도구 모음을 완전히 사용자 지정할 수 있습니다. 이를 통해 다음을 수행할 수 있습니다:

- 특정 대시보드 또는 시각화에 맞춘 사용자 지정 메뉴 항목 추가.

- 사용자 조건(예: 시각화 제목)에 따라 메뉴 동작을 동적으로 조정.

- 더 깔끔한 사용자 인터페이스를 위해 미리 정의된 메뉴 항목 숨기기.

**예시:** 전체 대시보드에 "모든 데이터 새로 고침" 옵션을 추가하거나 "작업 완료"와 같은 특정 차트에 "세부 정보 보기" 버튼을 추가합니다.

## **대화형 필터링: 데이터를 즉시 비교**

Reveal은 이제 사용자가 동일한 시각화 내에서 데이터를 필터링하고 비교할 수 있도록 합니다. 툴팁의 새로운 "필터링 기준" 옵션은 사용자가 컨텍스트를 잃지 않으면서 데이터를 분리하고 나란히 분석할 수 있도록 합니다.

**주요 개선 사항:**

- 필터는 데이터 무결성을 보호하기 위해 적용 후 읽기 전용입니다.

- 날짜 기반 필터링은 정확한 분석을 위해 단일 날짜 선택을 허용합니다.

- XMLA 데이터 소스를 지원하며, 코로플레스 지도에서 선택된 국가를 강조 표시합니다.

## **축 제목 제어: 데이터 명확성 강화**

이제 사용자는 x축, y축 또는 둘 다에 축 제목을 토글할 수 있어 주요 데이터 포인트를 강조하고 시각화를 해석하기 더 쉽게 할 수 있는 유연성을 갖게 됩니다.

## **시각화 및 데이터 소스 개선 사항**

**개선된 시각화 도구:**

- 축 그리드라인 사용자 지정: 없음, 가로, 세로 또는 둘 다.

- 도넛 차트는 이제 중앙 레이블 모드를 제공합니다: 없음, 레이블, 값 또는 둘 다.

**확장된 데이터 소스 지원:**

- PostgreSQL은 이제 더 빠른 데이터 처리를 위해 materialized views를 지원합니다.

- BigQuery는 이제 더 깊은 통찰력을 위해 데이터 블렌딩을 지원합니다.

## **개발자 중심 기능: 더 스마트한 사용자 지정**

**Reveal View 업데이트:**

- 새로운 showTitle 속성을 사용하여 대시보드 제목 표시/숨기기.

- ShowSave 속성으로 저장 버튼 토글.

- showVisualizationFilters로 시각화 필터 제어.

**플랫폼 지원:**

- ASP.NET 및 Node용 SQLite 지원이 추가되었으며, 향상된 보안을 위해 선택적 암호화 기능을 제공합니다.

**결론: 더 스마트하고, 빠르고, 더 나은 것을 구축할 준비가 되셨나요?**

이 업데이트는 단순히 새로운 기능에 관한 것이 아니라, 개발자와 제품 소유자에게 사용자가 데이터와 상호 작용하는 방식에 대한 완벽한 제어권을 부여하는 것입니다.  
 
Reveal은 타의 추종을 불허하는 사용자 지정, 강력한 데이터 통찰력, 원활한 사용자 경험을 제공함으로써 [임베디드 분석](/embedded-analytics) 분야를 계속 선도하고 있습니다.
