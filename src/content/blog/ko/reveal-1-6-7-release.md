## **Reveal 1.6.7의 새로운 기능은 무엇인가요?**

### **새로운 도구 모음 \[베타]**

이번 릴리스의 주요 기능 중 하나는 새로운 도구 모음의 도입입니다. 이 업데이트된 도구 모음은 고급 데이터 분석 및 대화형 기능을 제공하여 사용자 경험을 향상시킵니다. 확대/축소, 실시간 차트 서식 지정, 추세선 추가 등 다양한 기능을 빠르게 이용하세요!

![New Dashboard Toolbar in Reveal](/images/2024/06/reveal-new-toolbar.png)

### **차트 % 기반 필터링 \[베타]**

Reveal의 차트 % 기반 필터링은 다양한 시각화 전반에 걸쳐 백분율 기반 상호 작용을 허용하여 대시보드의 상호 작용성을 높입니다. 이 기능을 사용하면 한 차트에서 선택된 데이터 포인트가 대시보드의 다른 차트에 동적으로 영향을 미치고 업데이트할 수 있습니다.

하나의 시각화에서 백분율 값을 선택하면, Reveal이 자동으로 다른 관련 시각화들을 조정하여 이 초점을 반영합니다. 이러한 상호 연결된 동작은 데이터 세트 내에서 하나의 세그먼트가 다른 세그먼트에 어떻게 영향을 미치는지 파악하는 데 도움을 주어, 관계와 기여도에 대한 더 깊은 이해를 제공합니다.

![Chart % Based Filtering ](/images/2024/06/reveal-chart-percentage-based-filtering.gif)

### **대시보드 로드/변경 이벤트**

새로운 대시보드 로드/변경 이벤트 기능을 통해, Reveal은 대시보드가 로드되거나 수정될 때 개발자가 사용자 지정 로직으로 응답할 수 있도록 지원합니다. 애플리케이션 응답성과 상호 작용성을 높임으로써, 데이터 로드 또는 변경 시 사용자 지정 작업을 즉시 통합할 수 있습니다.

## **추가 개선 사항**

이러한 새로운 강력한 분석 기능 외에도, Reveal 1.6.7 릴리스에는 다음을 포함한 여러 개선 사항이 포함되어 있습니다:

- **SQL 데이터 소스 보안 강화**: 보안을 강화하고 SQL 인젝션과 같은 위험을 방지하기 위해 클라이언트 측 사용자 지정 쿼리 기능을 제거했습니다.
- **알파벳순 정렬 테이블**: 더 나은 데이터 관리를 위해 데이터 소스 대화 상자의 테이블이 이제 알파벳순으로 정렬됩니다.
- **시각화 필터용 새 API**: 이 API를 사용하면 사용자가 시각화 필터 값을 직접 액세스하고 조작할 수 있어 데이터의 유연성과 상호 작용성이 향상됩니다.
