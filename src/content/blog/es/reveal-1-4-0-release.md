[Reveal](/) es un producto impulsado por el cliente: entregamos funciones basándonos en sus comentarios continuos para que usted pueda ofrecer más valor a sus clientes. Hoy estamos emocionados de entregar 15 nuevas funciones y mejoras de producto al editor de visualización Reveal, la API, [fuentes de datos](/data-sources), y la documentación.

## Esto es lo nuevo en Reveal en nuestro lanzamiento del T1 de 2023:

1. Nuevo: API de Columna de Filtro para el Editor de Visualización

2. Nuevo: Nuevos Gráficos Predeterminados con UX Actualizada

3. Nuevo: Consulta Personalizada añadida a Elemento de Fuente de Datos de Snowflake

4. Nuevo: Propiedad para Almacén en Elemento de Fuente de Datos de Snowflake

5. Nuevo: Consulta Personalizada añadida a Elemento de Fuente de Datos de Athena

6. Nuevo: Consulta Personalizada añadida para SQL Server en Servidor NodeJS

7. Nuevo: Soporte para ARM en Mac M1 / M2 Apple Native Silicon

8. Nuevo: Exportar a PDF/PPTX/Excel en Servidor NodeJS

9. Nuevo: Docs: Playground de Desarrollador - [https://help.revealbi.io/playground](https://help.revealbi.io/playground)

10. Nuevo: Docs: Fragmentos de Código TypeScript / Java

11. Nuevo: Muestras actualizadas de Github en [https://github.com/RevealBi/sdk-samples-javascript](https://github.com/RevealBi/sdk-samples-javascript)

12. Mejora: Manejo Mejorado de Título / Subtítulo en la Configuración de Fuente de Datos del Lado del Cliente

13. Mejora: Eliminado Requisito de Base de Datos de Elemento de Fuente de Datos de Athena en el Cliente

14. Mejora: Vista Previa de Fuente de Datos CVS

15. Mejora: Habilitado Más de 2 Tablas en Uniones del Lado del Cliente

También hemos trasladado las solicitudes de soporte, informes de errores y solicitudes de funciones a GitHub. ¡[Enviar un problema](https://github.com/RevealBi/Reveal.Sdk/issues/new/choose) o una solicitud de función! Si necesita soporte en tiempo real, los miembros del equipo de producto de Reveal están listos para ayudar: ¡[registrarse](https://discord.com/invite/Ped3sSK5Xw) en el servidor de Discord de Reveal y únase a la Comunidad Reveal hoy mismo!

## **¿Qué sigue?**

Estamos trabajando arduamente en conectores de datos, mejoras de UX y API, y capacidades avanzadas de análisis / inteligencia artificial para ayudarle a usted y a sus clientes a sacar el máximo provecho de sus datos. Nuestro lanzamiento del T2 será en el plazo de mayo/junio, y nuestros objetivos para el año se encuentran en el [blog de hoja de ruta](/blog/reveal-roadmap). Para actualizaciones regulares y compilaciones provisionales, únase al servidor de Discord mencionado para anuncios y descargas.

Si está buscando funciones que no ve, tiene una nueva idea de producto, una pregunta sobre el producto o un problema con el producto, envíeme un correo electrónico directamente a [CaseyM@revealbi.io](mailto:CaseyM@revealbi.io) y ¡hablemos! ¡Gracias por ser cliente de Reveal!
