## **Novedades en Reveal 1.6.7?**

### **Nueva Barra de Herramientas \[Beta]**

Una de las características más destacadas de esta versión es la introducción de la nueva barra de herramientas. Esta barra de herramientas actualizada mejora la experiencia del usuario al ofrecer análisis de datos avanzado y funciones interactivas. ¡Accede rápidamente al zoom, formatea gráficos sobre la marcha, añade líneas de tendencia y más!

![New Dashboard Toolbar in Reveal](/images/2024/06/reveal-new-toolbar.png)

### **Filtrado Basado en % de Gráfico \[Beta]**

El Filtrado Basado en % de Gráfico en Reveal mejora la interactividad de tu panel al permitir interacciones basadas en porcentajes en varias visualizaciones. Esta función permite que un punto de datos seleccionado en un gráfico influya y actualice dinámicamente otros gráficos en el panel.

Cuando seleccionas un valor porcentual en una visualización, Reveal ajusta automáticamente otras visualizaciones relacionadas para reflejar este enfoque. Este comportamiento interconectado te ayuda a ver cómo un segmento de tus datos impacta a otros, proporcionando una comprensión más profunda de las relaciones y contribuciones dentro de tus conjuntos de datos.

![Chart % Based Filtering ](/images/2024/06/reveal-chart-percentage-based-filtering.gif)

### **Evento de Carga/Cambio de Panel**

Con la nueva función de Evento de Carga/Cambio de Panel, Reveal permite a los desarrolladores responder con lógica personalizada cuando un panel se carga o modifica. Al aumentar la capacidad de respuesta e interacción de la aplicación, permite la integración inmediata de acciones personalizadas tras la carga o el cambio de datos.

## **Mejoras Adicionales**

Además de estas nuevas y potentes funciones de análisis, la versión Reveal 1.6.7 también incluye varias mejoras, entre ellas:

- **Seguridad Mejorada para Fuentes de Datos SQL**: Hemos eliminado las capacidades de consultas personalizadas del lado del cliente para reforzar la seguridad y prevenir riesgos como la inyección SQL.
- **Tablas Ordenadas Alfabéticamente**: Para una mejor gestión de datos, las tablas en el diálogo de fuente de datos ahora se ordenan alfabéticamente.
- **Nueva API para Filtros de Visualización**: Esta API permite a los usuarios acceder y manipular valores de filtro de visualización directamente, mejorando la flexibilidad y la interacción con los datos.

## **Corrección de Errores**

Como con cada versión, nuestra última actualización aborda varios errores para garantizar una experiencia más fiable. Las correcciones incluyen mejoras en las exportaciones de Excel, correcciones de formato de fecha y un rendimiento mejorado. Para obtener detalles, consulta nuestras [notas de la versión](https://help.revealbi.io/web/release-notes).
