## **Construye Analítica de Datos para Integración – Simple. Rápido. Predecible.**

Ese es nuestro titular para Reveal.  Desde que lanzamos nuestro producto de [analítica integrada](/embedded-analytics), hemos tenido 3 objetivos principales:

- **Integración Rápida y Fácil** – Proporcionar una solución de analítica de datos fácil de integrar que los clientes puedan incorporar en sus aplicaciones existentes sin requisitos adicionales. [La arquitectura flexible y las ricas APIs de Reveal](https://static.infragistics.com/marketing/reveal/reveal-architecture-and-security-2021-02.pdf?_ga=2.4049392.1164794683.1623678258-1759676262.1615825090&gasource=google&gamedium=organic&gacampaign=(not%20set)&gaterm=(not%20provided)) les dan control sobre las funciones en su aplicación, convirtiéndola en una parte perfecta de la experiencia de usuario.
- **Experiencia de Usuario Superior**– Excite a sus usuarios haciéndoles fácil crear, editar y aplicar modelos de aprendizaje automático a sus propias visualizaciones de datos sin salir de su aplicación. Aumente la adopción de [toma de decisiones basada en evidencia](/blog/reveal-data-driven-decision-making).
- **Precios Transparentes y Asequibles** – Sepa exactamente cuánto pagará sin sorpresas. Con nuestro precio fijo y simple, puede llegar a un número ilimitado de usuarios en cualquier dispositivo sin pagar tarifas de uso adicionales.

Nuestro objetivo es ofrecer una increíble UX para el usuario final para BI de autoservicio, analítica de datos profunda y [data storytelling](/glossary/data-driven-storytelling).  Con esto, una experiencia de SDK que es fácil de usar y empezar. Esto significa una experiencia simple y hermosa con el nivel adecuado de funciones que brindan un valor abrumador para usted y sus partes interesadas.

Teniendo esto en cuenta, centramos nuestros esfuerzos en estas 4 áreas:

- Conectores de Datos
- Experiencia de Usuario de Visualización de Datos
- API Fácil de Usar en el SDK
- Analítica Avanzada / Inteligencia Artificial

Históricamente, trabajamos en ciclos de 8 a 10 semanas para características importantes, con correcciones de errores mensuales y bajo demanda. En otras palabras, puede esperar características grandes cada pocos meses (como un nuevo conector de datos o un nuevo tipo de gráfico) y características más pequeñas o correcciones de errores de forma mensual o antes.

*Para errores, si tiene un error crítico para el que no podemos proporcionar una solución temporal, se lo haremos disponible tan pronto como se corrija* – sabemos que usted está construyendo software como nosotros, por lo que podemos entender la importancia y la urgencia de tal asunto.*

*Cuando instale/actualice el SDK, puede seleccionar la versión, ya que a medida que se corrigen errores, le informaremos qué versión instalar.*

## Lo que lanzamos en 2022

2022 fue un gran año de entrega de características. Algunos de los puntos más destacados fueron el servidor NodeJS y el Dom de Reveal. Con el servidor NodeJS, los equipos que están construyendo aplicaciones en Angular, React, Vue y otras plataformas web modernas tienen una nueva opción además de las variantes existentes de servidor ASP.NET Core y Java del SDK. El proyecto Reveal Dom es un Document Object Model (DOM) para el formato de archivo .rdash de Reveal. Permite a los desarrolladores que utilizan el SDK de Reveal cargar, editar y crear paneles utilizando .NET.

Junto con esas características más grandes, abordamos una tonelada de solicitudes de características y actualizaciones de clientes existentes y continuamos avanzando con fuentes de datos y capacidades de gráficos actualizadas. Aquí hay una lista completa de actualizaciones hasta ahora este año.

### Experiencia de Usuario de Visualizaciones de Datos

- Nueva API y UI que permite el nivel de zoom del gráfico + una barra de desplazamiento que establece el nivel de zoom horizontal o vertical inicial de un gráfico que activa una barra de desplazamiento.
- Nueva API que permite la asignación de color para una serie de gráficos.
- Nueva API para personalizar umbrales en la agrupación "Otros" de Gráfico Circular.
- Nuevas visualizaciones para todos los tipos de gráficos, incluyendo nuevos colores de series y opciones de etiquetas de datos.

### Conectores de Datos

- Conector de Datos de Google Search Console
- Actualizaciones de Salesforce Marketing Cloud
- Actualizaciones de Google Analytics

### SDK

- Nuevo Servidor NodeJS.
- Nueva opción global CDN para Reveal Client SDK para Web.
- Nueva Exportación Headless para operaciones de exportación del lado del servidor.
- Nuevo filtrado interactivo de gráficos.
- Nuevo callback que permite un diálogo de fuente de datos personalizado y devuelve la fuente de datos seleccionada y la establece en la visualización.
- Nuevo cuadro de texto de Búsqueda/Filtro de Fuente de Datos para encontrar simplemente fuentes de datos específicas para usar en una visualización.
- Nuevas opciones de Localización/Formato para el SDK de JavaScript.
- Nuevas propiedades de Metadatos para fuentes de datos basadas en cubos.
- Nueva propiedad para cambiar el color de fondo de la visualización.
- Nueva propiedad para mostrar/ocultar el Título de un panel (nombre + kebab).
- Nuevo filtrado del lado del servidor para nombres de objetos de datos.
- Nuevas opciones para establecer la Tasa de Actualización en una fuente de datos.
- Eliminación de la dependencia de Puppeteer para exportaciones con Playwright.
- Manejo de fechas actualizado para fuentes de datos REST.
- Enumeración actualizada para agregar fuentes de datos adicionales.
- Manejo actualizado de nombres de archivos de panel: ahora no distinguen entre mayúsculas y minúsculas, lo que significa que no necesita escribir código adicional para pasar un nombre de panel como variable.
- Opciones actualizadas para que los usuarios puedan ver fechas en su zona horaria local, donde anteriormente las fechas se mostraban tal como se obtenían de la base de datos.
- Tamaño de archivo mejorado para el SDK cliente de Reveal comprimido.

## Hoja de Ruta de Reveal para 2023

Nuestra hoja de ruta está impulsada por el cliente. Todo lo que añadimos se basa en los comentarios y la demanda de los clientes. Si bien podemos añadir elementos que creemos que nos hacen competitivos en el mercado o características que se basan en la dirección general del mercado o en comentarios de analistas, estamos constantemente ajustándonos y adaptándonos a lo que usted necesita para ofrecer software exitoso.

En la primera mitad de 2023, nos centramos en algunos elementos de gran envergadura:

- Mejorar la UX de la Información sobre herramientas para Profundización y Filtrado de Gráficos
- Mejorar la UX general del Gráfico con Barra de Herramientas de Gráfico y Líneas Fijas
- Refactorizar el SDK cliente para eliminar la dependencia de jQuery
- API mejorada para Reveal View en el SDK cliente (API simplificada)
- Conector de datos MongoDB

Dado que la característica de la Barra de Herramientas de Gráfico es el trabajo de UX más grande, veamos la dirección que estamos tomando para que sepa qué esperar.

### Barra de Herramientas de Gráfico

La característica de la barra de herramientas de gráficos tiene como objetivo dar al creador y al visor más capacidades de análisis en cada visualización de un panel. Según el tipo de gráfico (medidor, gráfico circular, gráfico de líneas, gráfico de barras, etc.), tendrá diferentes opciones disponibles.

Aquí hay un ejemplo de la barra de herramientas en un gráfico de líneas típico:

![chart toolbar feature](/images/2022/07/embedded-analytics-Chart-Toolbar-1024x278.jpg)

La barra de herramientas no siempre es visible; será visible cuando la visualización esté en estado de pasar el ratón:

![embedded analytics dashboard example](/images/2022/07/embedded-dashboard-1024x544.jpg)

Cuando hace clic en los elementos de la barra de herramientas, verá más opciones para personalizar su experiencia de análisis. Por ejemplo, hay el botón de barra de herramientas Analizar, donde puede agregar líneas fijas, líneas de tendencia, realizar detección de valores atípicos, etc., con menús de profundización que brindan características adicionales para mostrar/ocultar en el panel.

![analyze toolbar item feature](/images/2022/07/embedded-analytics-Analyze-Toolbar-Item.jpg)

Cualquier línea fija que se agregara cuando un creador de paneles construyó el panel es visible por defecto, pero un visor de paneles puede activar o desactivar la línea fija al ver. El SDK le dará las opciones para activar o desactivar los elementos del menú por defecto, por lo que, por ejemplo, puede elegir ocultar la opción de barra de herramientas de Análisis por completo, obligando al visor a ver solo lo que el creador definió.

### Personalización de Líneas

Como creador, tiene las mismas opciones en la barra de herramientas para Analizar, sin embargo, tiene más control sobre lo que se muestra y cómo se muestra. Por ejemplo, puede personalizar parámetros en líneas fijas, puede agregar múltiples líneas fijas de Percentil o líneas fijas personalizadas con etiquetas personalizadas, como Objetivo de Ingresos o Conversión Objetivo.

Así es como se ve el menú desplegable al crear un panel:

![creator fixed lines feature](/images/2022/07/embedded-analytics-Creator-Fixed-Lines-1024x538.jpg)

Además, verá una nueva sección de Líneas de Análisis en Configuración, que le permite personalizar aún más el aspecto y la sensación de las líneas que está agregando a la visualización.

![creator customize line styles ](/images/2022/07/embedded-analytics-Creator-Customize-Line-Styles-1024x540.jpg)

Verá opciones para personalizar:

- Color
- Grosor de la línea
- Estilo de línea (Sólido, Punteado, Guion, Guion Medio, Guion Medio / Guion Corto, Guion Largo, Guion Largo / Guion Corto, Guion Largo / Guion Corto / Guion Corto)
