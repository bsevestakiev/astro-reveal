## Analítica Avanzada con Funciones Estadísticas

Con solo unos clics, como usuario empresarial puedes obtener rápidamente más información sobre tus datos y realizar una variedad de análisis estadísticos utilizando cualquiera de las siguientes funciones integradas:

### Detección de Valores Atípicos (Outliers Detection)

Con Detección de Valores Atípicos, detecta fácilmente puntos en tus datos que son anomalías y que difieren de la mayor parte de tu conjunto de datos. Puedes mostrar u ocultar estos valores atípicos de la vista, para que siempre se muestren o para que no interfieran con tu análisis.

![Outliers Detection in Reveal](/images/2020/11/4274.OUtliers.PNG-1040x1626-1.png)

### Pronóstico de Series de Tiempo (Time Series Forecasting)

Con Pronóstico de Series de Tiempo, Reveal realizará predicciones sobre valores futuros basándose en datos y tendencias históricas. Esto es útil en una gran cantidad de aplicaciones, como pronóstico de ventas e ingresos, gestión de inventario y muchas otras.

![Time Series Forecasting in dashboard ](/images/2020/10/5340.Time-Series-Forecast.png)

### Regresión Lineal (Linear Regression)

Con Regresión Lineal, podrás ver visualmente las tendencias en tus datos encontrando la relación entre dos variables y viendo una aproximación lineal de tus datos, incluyendo tendencias futuras. Junto con Regresión Lineal, Reveal incluye estas algoritmos de líneas de tendencia: Linear Fit, Quadratic Fit, Cubic Fit, Quartic Fit, Logarithmic Fit, Exponential Fit, Power Law Fit, Simple Average, Exponential Average, Modified Average, Cumulative Average, y Weighted Average.

![Linear regeression ](/images/2020/10/7416.Linear-Regression.png)

## Machine Learning

¡Ahora puedes llevar el poder del Machine Learning a Reveal! La Integración de Modelos de Machine Learning de Microsoft Azure te permite utilizar modelos entrenados aplicados a tus datos de Azure Machine Learning Studio para crear hermosas visualizaciones. Simplemente apunta tus datos a la URL de tu modelo de Azure y Reveal renderizará una visualización basada en tu escenario de machine learning. También puedes usar modelos entrenados aplicados a tus datos de Google BigQuery Platforms para crear visualizaciones impactantes.

![ Machine learning models in Reveal BI](/images/2020/10/ML-Models.png)

## Scripting en R y Python

Ahora admitimos scripting en R y Python, que es la rampa de acceso para tu Científico de Datos Ciudadano interior para realizar análisis estadísticos y análisis de datos que empujan los límites de lo que Reveal puede hacer con tu conjunto de datos. Por ejemplo, puedes pre-/post-procesar datos para mejorar tu salida de visualización o renderizar visualizaciones únicas que están incluidas en librerías de R o Python. Simplemente pega una URL a tus scripts o pega tu código en el editor de scripts.

![R & Python Scripting](/images/2020/10/R-_2600_-Python.png)
