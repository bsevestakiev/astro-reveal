Si has estado usando Reveal, sabes lo fácil que es crear paneles con cualquier número de fuentes de datos. Reveal está construido por expertos en experiencia de usuario y está hecho para usuarios de negocios. Tiene una familiar experiencia de arrastrar y soltar que lo hace simple de usar. Sin embargo, el editor de visualización está repleto de funciones que quizás ni siquiera conozcas. Hoy vamos a guiarte por cada sección del editor y a mostrarte todas las capacidades que tiene Reveal.

**Campos**

**![All of the available fields within your data source in Reveal BI](/images/2020/10/6153.Feilds.png)**

Todos los campos disponibles dentro de tu fuente de datos aparecerán en el panel izquierdo. Cada campo tiene un indicador que informa a los usuarios qué tipo de campo es: Fecha, Valor, Texto. El ícono de *más* en este panel te permite fusionar fuentes de datos o calcular un campo:

- Fusionar Fuente de Datos: Esta es una función potente que te permite incorporar campos de otra fuente y unirlos basándose en un campo común.
- Campo Calculado: Te permite definir nuevos campos creados basándose en una expresión utilizando los campos existentes.

**Campos de Visualización**
![Visualization Fields in Reveal BI ](/images/2020/10/4405.Fields.png)

Aquí es donde arrastrarás y soltarás, o harás clic en el signo + para ver los campos disponibles y seleccionar los que deseas usar para la visualización que estás creando.

**Área de Trabajo de Visualización**
![Visualization Workspace in Reveal BI](/images/2020/10/7120.Visualization-Viewer.png)

Aquí es donde podrás ver la visualización que estás creando o editando a medida que arrastras y sueltas campos. La visualización no se poblará hasta que tengas todos los campos necesarios para crear ese tipo de gráfico.

![Visualization In Reveal BI when you are creating or editing as you drag and drop fields ](/images/2020/10/7120.Data-Source.png)

**Fuente de Datos**

La fuente de datos con la que estás trabajando actualmente se mostrará aquí. Con un clic puedes cambiar entre las diferentes hojas, tablas o vistas dentro de tu fuente o cambiar tu conexión a una fuente completamente nueva sin tener que salir del editor.

**Selector de Visualización**

![Visualization Picker in Reveal BI ](/images/2020/10/6562.Visualization-Picker.png)

Cambia entre cualquiera de nuestras más de 30 visualizaciones diferentes usando el selector desplegable. A medida que cambias entre los diferentes tipos de gráficos, notarás que la sección de campos de visualización cambia. ¡Aquí es donde Reveal lleva la facilidad de uso a un nuevo nivel! Te proporcionaremos todos los campos necesarios que necesitas rellenar para un determinado tipo de visualización, eliminando la necesidad de que pienses. Una vez que todos los campos necesarios para crear un hermoso gráfico estén allí, tu gráfico se mostrará en la sección del área de trabajo de visualización.

**Configuración de Visualización**

![Visualization Settings in Reveal BI ](/images/2020/10/6562.Settings.png)

Cada visualización viene con su propia configuración que te permite personalizar lo que quieres mostrar:

- Cuadrícula: mostrar título, alineación de tus campos, tamaño de fuente, primera columna fija
- Cuadrícula Dinámica: mostrar título, alineación de tus campos, tamaño de fuente, totales generales
- Columna, Barra, Línea, Área, Área de Pasos, Línea de Pasos, Spline, Área Spline: mostrar título, mostrar leyenda, color inicial, línea de tendencia del gráfico, configuración del eje, límites del eje
- Columna Apilada, Barra Apilada, Área Apilada: mostrar título, mostrar leyenda, color inicial, distribución porcentual, configuración del eje, límites del eje
- Texto: mostrar título, límites de formato condicional para el indicador
- Texto, Vista Web: mostrar título
- Circular, Anillo, Embudo: mostrar título, mostrar leyenda, color inicial, posición inicial, formato de etiqueta de la porción
- Indicador Circular, Indicador Lineal, Gráfico de Barras: mostrar título, límites, límites de formato condicional para el indicador
- KPI vs Tiempo, KPI vs Objetivo: mostrar título, período de tiempo, formato de diferencia, color del indicador
- OHLC, Velas: mostrar título, configuración del eje, límites del eje
- Radial: mostrar título, mostrar leyenda, color inicial, línea de tendencia del gráfico
- Gráfico de Puntos: mostrar título, alineación para campos, tamaño de fuente, tipo de gráfico, número de meses mostrados, cómo las dos últimas columnas, mostrar columna de diferencia, color del indicador

Dentro de cada una de estas pantallas de configuración verás la opción de enlaces. Esta es una función potente que lleva el análisis detallado a un nivel completamente nuevo. Vincula una visualización a un panel totalmente nuevo para mostrar más detalles con un solo clic. O enlaza a una URL que proporciona información más profunda para tus usuarios.
