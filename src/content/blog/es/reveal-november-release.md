Nuestro último lanzamiento incluye soporte para .NET 8, personalización expandida de la información sobre herramientas (tooltip), vinculación de URL, mejoras en la selección de paneles y envoltorios de componentes web. Esto es lo que estas actualizaciones significan para sus proyectos.

## Nuevas Funcionalidades

**Soporte para .NET 8: Mejoras de Rendimiento y Seguridad**

Con .NET 8, Reveal es totalmente compatible con el último framework de desarrollo, lo que garantiza una integración perfecta en entornos tecnológicos actualizados. Esta compatibilidad significa que Reveal puede utilizar las mejoras de rendimiento y seguridad de .NET 8, ofreciendo a sus aplicaciones estabilidad, seguridad y acceso a funciones modernas mejoradas.

**Elementos Personalizados en la Información sobre Herramientas: Interactividad y Compromiso Mejorados**

Reveal permite agregar elementos personalizados directamente a las información sobre herramientas, lo que permite a los usuarios iniciar acciones personalizadas directamente desde la información sobre herramientas. Esta función se trata de interactividad. Le permite adaptar las experiencias de visualización de datos al incrustar información procesable que mejora el compromiso del usuario y optimiza los flujos de trabajo. Ya sea que la acción sea lanzar un informe detallado, activar un evento personalizado o vincularse a un recurso externo, este nivel de personalización permite una experiencia de usuario más dinámica directamente desde las visualizaciones de datos.

![.NET 8, Información sobre Herramientas Personalizables, y Más: Mejore su Experiencia de Desarrollo con Reveal](/images/2024/10/reveal-launch-nov-body-custom-tooltip-items.jpg)

**Vinculación de URL y Flexibilidad del Selector de Paneles**

Nuestra última actualización para la vinculación de URL aporta control y simplicidad adicionales a la navegación de paneles. Ahora, los enlaces URL están disponibles por defecto en la configuración, separados de la interfaz de vinculación de paneles. Anteriormente, la vinculación de URL y la vinculación de paneles tenían que implementarse juntas, lo que limitaba cómo los usuarios podían navegar entre paneles y fuentes externas. Con esta actualización, la vinculación de URL se habilita de forma independiente, lo que proporciona flexibilidad a los clientes para crear rutas únicas para navegar por información de datos y contenido externo sin requerir la vinculación de paneles.

![.NET 8, Información sobre Herramientas Personalizables, y Más: Mejore su Experiencia de Desarrollo con Reveal](/images/2024/10/reveal-launch-nov-body-url-linking.jpg)

**Envoltorios de Componentes Web (Beta): Expandiendo la Flexibilidad de Integración**

Los Envoltorios de Componentes Web permiten que Reveal se integre de manera más fluida en una gama más amplia de aplicaciones y frameworks web. El soporte para componentes web modernos significa que los desarrolladores pueden integrar Reveal de manera más fluida en diversas pilas tecnológicas, ampliando la compatibilidad y mejorando la facilidad de integración de analítica en aplicaciones modernas y prácticas de desarrollo.
