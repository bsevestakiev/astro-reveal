Esta actualización está repleta de mejoras de personalización, usabilidad y rendimiento para ayudarle a crear experiencias analíticas fluidas y de alto impacto más rápido.

## Características de la Última Actualización:

- **Personalización de Títulos de Ejes:** Modifique los títulos de los ejes directamente en el editor para un etiquetado más claro y preciso.

- **Líneas Fijas para Gráficos:** Establezca puntos de referencia estáticos para resaltar tendencias clave de datos.

- **Etiquetado Numérico de Ejes más Inteligente:** Reduzca el desorden de etiquetas y mejore la legibilidad.

- **Posicionamiento Flexible de Leyendas de Gráficos:** Mueva y alinee las leyendas para un mejor diseño del panel.

- **Paginación de Cuadrícula con Ordenación:** Organice datos instantáneamente con nuevas capacidades de ordenación de columnas.

- **Colocación Optimizada de Etiquetas de Datos:** Visibilidad mejorada para gráficos de columnas y barras.

- **Actualización de la API de Filtro de Fecha:** Filtrado más estructurado para desarrolladores.

Estas características revolucionarias hacen más fácil que nunca ofrecer análisis intuitivos y con la marca en sus aplicaciones.

## **Desglose de Características: Qué es Nuevo y Qué Significa para Usted**

### **Personalización de Títulos de Ejes: Más Claridad, Menos Confusión**

- **Personalización Directa:** Haga clic y edite los títulos de los ejes directamente desde el editor de visualización.

- **Mejor Legibilidad:** Etiquetas más descriptivas significan una interpretación de datos más rápida.

### **Líneas Fijas: Establezca Puntos de Referencia Clave en Gráficos**

- **Puntos de Referencia Estáticos:** Resalte fácilmente umbrales importantes para mejores comparaciones.

- **Apariencia Personalizable:** Ajuste el color y el grosor de la línea para una mejor visibilidad.

![Adjust line color and thickness for better visibility](/images/2025/03/reveal-launch-1-7-3-employee-sales-abalysis-dashboard-body.png)

### **Etiquetado Numérico de Ejes: Limpio, Preciso y Legible**

- **Espaciado Inteligente de Etiquetas:** Evite etiquetas superpuestas e innecesarias.

- **Visualización Optimizada:** Obtenga un aspecto más limpio sin perder contexto crítico.

### **Leyendas de Gráficos: Posicionar y Alinear para un Mejor Diseño**

- **Posicionamiento Flexible:** Mueva las leyendas a la parte superior o inferior de las visualizaciones.

- **Alineación Personalizada:** Izquierda, derecha o centro: controle esto en la pestaña Configuración.

### **Paginación de Cuadrícula: Ahora con Ordenación para una Organización de Datos Más Rápida**

- **Ordenación Interactiva:** Haga clic en los encabezados de las columnas para reordenar los datos instantáneamente.

- **Usabilidad Mejorada:** Encuentre y analice información clave rápidamente.

### **Colocación Optimizada de Etiquetas de Datos: Ideas Más Claras de un Vistazo**

- **Gráficos de Columnas:** Las etiquetas ahora se sitúan encima de las columnas para una identificación rápida.

- **Gráficos de Barras:** Las etiquetas aparecen a la derecha de las barras para una claridad mejorada.

- **Visibilidad Refinada:** Colocación mejorada para una fácil interpretación en todos los gráficos.

### **Actualización de la API de Filtro de Fecha: Más Potencia para Desarrolladores**

- **Usabilidad Mejorada de la API:** El evento onDateFilterMenuOpening ahora utiliza objetos IRVDateFilterMenuItem para un manejo más estructurado.

## **Conclusión: Cree Análisis Más Inteligentes, Rápidos e Intuitivos**

Esta actualización no se trata solo de nuevas características, sino de darle más control, mejor rendimiento y una experiencia analítica aún más fluida.

Para una lista completa de mejoras, nuevas capacidades y correcciones de errores, asegúrese de consultar las [Notas de la Versión](https://help.revealbi.io/web/release-notes/?_ga=2.67398801.1020496211.1741714344-323732178.1730367545).
