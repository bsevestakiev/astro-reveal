[Reveal](/) is a customer-driven product- we deliver features based on your continuous feedback so you can deliver more value to your customers.  Today we are excited to deliver 15 new features & product enhancements to the Reveal visualization editor, API, [data sources](/data-sources), and docs.

## Here is what’s new in Reveal our Q1 2023 release:

1. New: Filter Column API for Visualization Editor

2. New: New Default Charts with Updated UX

3. New: Custom Query added to Snowflake Data Source Item

4. New: Property for Warehouse in Snowflake Data Source

5. New: Custom Query added to Athena Data Source Item

6. New: Custom Query added for SQL Server in NodeJS Server

7. New: Support for ARM on Mac M1 / M2 Apple Native Silicon

8. New: Export to PDF/PPTX/Excel in NodeJS Server

9. New: Docs: Developer Playground - [https://help.revealbi.io/playground](https://help.revealbi.io/playground)

10. New: Docs: TypeScript / Java Code Snippets

11. New: Updated Github samples at [https://github.com/RevealBi/sdk-samples-javascript](https://github.com/RevealBi/sdk-samples-javascript)

12. Enhancement: Improved Title / Sub-Title Handling in Client-Side Data Source Configuration

13. Enhancement: Removed Requirement for Athena Data Source Item Database on Client

14. Enhancement: CVS Data Source Preview

15. Enhancement: Enabled More Than 2 Tables in Client-Side Joins

We’ve also moved support requests, bug reports, and feature requests to GitHub. [Submit an issue](https://github.com/RevealBi/Reveal.Sdk/issues/new/choose) or feature request! If you need more real-time support, Reveal product team members are ready to help - [sign up](https://discord.com/invite/Ped3sSK5Xw) for the Reveal Discord Server and join the Reveal Community today!

## **What’s Next?**

We are working hard on data connectors, UX & API improvements, and advanced analytics / artificial intelligence capabilities to help you and your customers get the most out of their data. Our Q2 release will be in the May / June timeframe, and our goals for the year are in the [roadmap blog](/blog/reveal-roadmap). For regular updates and interim builds, join the aforementioned Discord server for announcements and downloads.

If you are looking for features you don’t see, have a new product idea, product question, or product problem, email me directly at [CaseyM@revealbi.io](mailto:CaseyM@revealbi.io)  and let’s discuss! Thanks for being a Reveal customer!
