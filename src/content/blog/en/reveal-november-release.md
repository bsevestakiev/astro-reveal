Our latest release includes .NET 8 support, expanded tooltip customization, URL linking, dashboard selection improvements, and web component wrappers. Here’s what these updates mean for your projects.

## New Features

**.NET 8 Support: Performance and Security Upgrades**

With .NET 8, Reveal is fully compatible with the latest development framework, ensuring seamless integration into up-to-date tech environments. This compatibility means Reveal can utilize .NET 8’s improvements in performance and security, offering your applications enhanced stability, security, and access to modern features.

**Custom Tooltip Items: Improved Interactivity and Engagement**

Reveal allows custom items to be added directly into tooltips, enabling users to initiate custom actions straight from the tooltip. This feature is all about interactivity. It empowers you to tailor data visualization experiences by embedding actionable insights that improve user engagement and streamline workflows. Whether the action is launching a detailed report, triggering a custom event, or linking to an external resource, this level of customization enables a more dynamic user experience directly from data visualizations.

![.NET 8, Customizable Tooltips, & More: Enhance Your Dev Experience with Reveal](/images/2024/10/reveal-launch-nov-body-custom-tooltip-items.jpg)

**URL Linking and Dashboard Selector Flexibility**

Our latest update to URL linking brings additional control and simplicity to dashboard navigation. Now, URL links are available by default in the settings, separate from the dashboard linking UI. Previously, URL and dashboard linking had to be implemented together, which limited how users could navigate between dashboards and external sources. With this update, URL linking is independently enabled, providing flexibility for customers to create unique pathways for navigating data insights and external content without requiring dashboard linkage.

![.NET 8, Customizable Tooltips, & More: Enhance Your Dev Experience with Reveal](/images/2024/10/reveal-launch-nov-body-url-linking.jpg)

**Web Component Wrappers (Beta): Expanding Embed Flexibility**

Web Component Wrappers allow Reveal to be embedded more seamlessly into a wider variety of web applications and frameworks. Supporting modern web components means developers can integrate Reveal more smoothly across diverse tech stacks, expanding compatibility and improving the ease of embedding analytics in modern applications, and development practices.

## Bug Fixes

As with every release, our latest update addresses various bugs to ensure a more reliable experience. For details, please refer to our [release notes](https://help.revealbi.io/web/release-notes).

## Final Words

Reveal will always continue to prioritize performance, flexibility, and developer control. Our newest features are designed to support the latest tech standards while enabling tailored analytics experiences, enhancing how your users interact with data.
