## **Custom Toolbar Options: Full Control Over Menus**

Developers can now fully customize dashboard and visualization toolbars using the revealView.onMenuOpening event handler. This allows you to:

- Add custom menu items tailored to specific dashboards or visualizations.

- Dynamically adjust menu behavior based on user conditions (e.g., visualization title).

- Hide predefined menu items for a cleaner user interface.

**Example:** Add a “Refresh All Data” option to the entire dashboard or a “View Details” button to specific charts like “Tasks Completed.”

## **Interactive Filtering: Compare Data Instantly**

Reveal now enables users to filter and compare data within the same visualization. The new “Filter By” option in tooltips allows users to isolate and analyze data side-by-side without losing context.

**Key Enhancements:**

- Filters are now read-only once applied to protect data integrity.

- Date-based filtering allows single-date selection for precise analysis.

- Supports XMLA data sources and highlights selected countries in choropleth maps.

## **Axis Title Control: Sharpen Data Clarity**

Users can now toggle axis titles on the x-axis, y-axis, or both, giving them more flexibility to emphasize key data points and make visualizations easier to interpret.

## **Visualization & Data Source Enhancements**

**Improved Visualization Tools:**

- Customize axis gridlines: none, horizontal, vertical, or both.

- Donut charts now offer center label modes: none, label, value, or both.

**Expanded Data Source Support:**

- PostgreSQL now supports materialized views for faster data processing.

- BigQuery now supports data blending for deeper insights.

## **Developer-Centric Features: Smarter Customization**

**Reveal View Updates:**

- Show/Hide Dashboard Title with the new showTitle property.

- Toggle the Save Button with the ShowSave property.

- Control Visualization Filters with showVisualizationFilters.

**Platform Support:**

- SQLite support was added for ASP.NET & Node with optional encryption for enhanced security.
