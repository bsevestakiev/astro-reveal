**Reveal 1.8.1** は、組み込み分析の構築をより速く、よりスマートに、よりスケーラブルにする2つの主要なアップグレード、すなわち **条件付き書式設定** と **Redis Cache Provider** を導入しました。これらのアップデートは、開発者、データチーム、およびエンタープライズユーザーが、より少ない複雑さで、より明確なインサイトと高いパフォーマンスを提供できるように支援します。色ロジックでダッシュボードを強化する場合でも、高トラフィックアプリケーションのクエリ速度を最適化する場合でも、Reveal は、単に機能するカスタマイズ可能な組み込みBIの標準を確立し続けています。

## **条件付き書式設定：データに物語を語らせる**

![Conditional Formatting](https://static.infragistics.com/marketing/reveal/blogs/launch/2025/nov/reveal-conditional-formatting-grids.png)

データが重要になるのは、明確な場合のみです。条件付き書式設定を使用すると、チャートやダッシュボードに直接色ロジックを適用でき、トレンドや外れ値を即座に可視化できます。

**主な利点：**
• **柔軟なルールベースの配色：** >=100、<AmountField、または =’SalesPersonName’ のような、ロジックベースの色をシリーズ、カテゴリ、またはラベルに適用できます。
• **コード不要：** ダッシュボード内でビジュアルをビジネスロジックに直接合わせることができます。
• **チャートタイプを横断して動作：** 一貫したビジュアルデザインとユーザーエクスペリエンスを確保します。

これにより、アナリストやプロダクトマネージャーは、最も重要な点を強調表示する力を得ます。成長を緑、リスクを赤で示し、一目で物語を語るダッシュボードを作成できます。開発者は、複雑さを増すことなく、すべてのビジュアライゼーションにロジック駆動のデザインをもたらすことができます。

## **Redis Cache Provider：エンタープライズレベルの速度とスケーラビリティ**

![Redis Cache Provider](https://static.infragistics.com/marketing/reveal/blogs/launch/2025/nov/reveal-redis-cache-provider.png)

大規模な分析ワークロードを管理する組織にとって、速度は譲れません。新しい Redis Cache Provider は、分散インメモリキャッシングを導入し、エンタープライズ用途で SQLite を置き換えることで、チームがより速く、より一貫したパフォーマンスを提供できるように支援します。

**Redisの利点：**
• インメモリキャッシングによる超高速クエリ応答。
• 分散ワークロードのための水平スケーラビリティ。
• 設定可能なリトライロジック、有効期限ポリシー、およびセキュアな接続。

## **.NET Fluent APIによる簡単な統合：**

.AddRedisCache(options =>
{
options.ConnectionString = “your-redis-connection-string”;
options.CacheExpiration = TimeSpan.FromSeconds(30);
options.RetryDelayMs = 200;
})

**NuGet Package:** Reveal.Sdk.Caching.Redis

Redis Cache Provider は、マルチテナントSaaSプラットフォームおよびリアルタイムレポートシステムに安定性と応答性を保証し、高負荷時でも分析がスムーズに実行されるようにします。

## **Revealの今後の展望**

Reveal 1.8.1 は、開発者およびビジネスチームにとって、分析統合をより速く、よりシンプルに、より強力にするという使命を継続します。条件付き書式設定と Redis Cache の両方は、お客様からのフィードバックに基づいて構築され、より速くリリースし、よりスマートにスケールし、より良いインサイトを提供できるように設計されています。
