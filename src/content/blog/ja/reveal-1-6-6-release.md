## **Reveal 1.6.6の発表：分析体験の強化**

Reveal 1.6.6のリリースを発表できることを嬉しく思います。本バージョンでは、お客様の[組み込み分析](/embedded-analytics)体験を強化するいくつかの新機能と改善が盛り込まれています。主なハイライトは以下の通りです。

## **新機能**

- **サーバー側ページング**: サーバー側ページングを使用すると、グリッドビジュアライゼーションでデータを表示する際に、クライアントに送信される行数を制限できます。これにより、大規模なデータセットを操作する際のユーザーエクスペリエンスを保ちながら、パフォーマンスが大幅に向上します。これは現在ベータ機能であるため、フィードバックを募集しています！サーバー側ページングを有効にするには、クライアントJavaScriptで *$.ig.RevealSdkSettings.enableBetaFeatures=true* を設定し、グリッドビジュアライゼーションの「設定」タブで、新しいページングオプションが表示されるようになります。

![Reveal 1.6.6: What's New in Embedded Analytics](/images/2024/04/reveal-server-side-paging.png)

- **説明テキストボックス**: 新しい「説明」テキストボックスにより、ダッシュボードに追加のコンテキストを追加できるようになりました。これは、ダッシュボードのタイトル直下に配置されます。説明テキストボックスは、RevealViewの *canEdit* プロパティに設定されたのと同じルールに従います。ユーザーがダッシュボードの編集を許可されている場合、ダッシュボードの説明を編集できるようになります。説明テキストボックスの表示/非表示を切り替えるには、RevealViewの *showDescription* ブーリアンプロパティを変更してください。

![Reveal 1.6.6: What's New in Embedded Analytics](/images/2024/04/reveal-description-text-box.png)

- **PDFエクスポートの強化**: グリッドおよびピボットグリッドビジュアライゼーションのPDFエクスポートが刷新されました。新しいグリッドおよびピボットグリッドのエクスポート体験には、列幅のより良い処理、改善された列および行のオーバーフロー、そして可読性を向上させるためにエクスポートされたページ間で同じ行をよりよく追跡するための更新されたPDFレンダリングが含まれています。
- **エクスポートフィルター**: PowerPoint、PDF、またはMicrosoft Excelにエクスポートする際、適用されたフィルターを説明するカバーページが表示されるようになりました。これにより、ダッシュボードがエクスポートされた際、閲覧者がすべてのデータを見ているのか、それともデータのサブセットを見ているのかを把握できます。

![Reveal 1.6.6: What's New in Embedded Analytics](/images/2024/04/reveal-export-filters.png)

- **ロードパフォーマンスの改善**: 新しいビジュアライゼーションを作成する際のデータスキームのロード体験をより良くするため、データソースのフィールドリストでフィールドにカーソルを合わせたときにデータプレビューを表示するフラグを追加しました。デフォルトでは、ツールチップに各フィールドのサンプリングを表示するために、データソースから5行のデータをクエリします。大規模なデータセットでストアドプロシージャを使用している場合、これがパフォーマンスに影響を与える可能性があります。このデータツールチップ機能をオンにするには、*isPreviewDataInVisualizationEditorEnabled* を true に設定してください。これはデフォルトではオフになっています。
- **MySQLのサーバー側データブレンド**: MySQLがサーバー側データブレンドをサポートするようになりました。これは、結合されたテーブルがクエリをサーバーで実行することを意味し、大規模なデータセットのパフォーマンスが劇的に向上します。
- **新しいチャート**: ラジアルチャートを更新されたコードと新しいルック＆フィールで強化しました。古いチャートは引き続きクライアントライブラリに存在しますが、非推奨となっており、今年後半に永久に削除されます。以前のチャートを保持したい場合は、*RevealSdkSettings.EnableNewCharts = false* を設定できます。
- **更新された棒グラフと列グラフ**: ビジュアライゼーションエディターの「設定」ペインにある新しい「オーバーラップ」および「ギャップ」プロパティを使用すると、棒グラフと列グラフの間のオーバーラップ量、およびグループ間のスペース量を制御できます。この新しい設定により、棒グラフと列グラフを「マージ」することができ、データを視覚化し、データラベルを付ける新しい方法が提供されます。
- **ツリーマップビジュアライゼーションのツールチップ**: Revealでのツールチップ体験の改善を継続します。今回のリリースでは、マウスオーバー時にノードにハイライトが表示されるツールチップが利用可能になりました。
- **データソースダイアログフィルター**: Nodeサーバーで、RevealOptionsに新しい *dataSourceItemFilter* プロパティを追加しました。これは、.NET Coreサーバーの *IRVObjectFilter* を模倣しており、データソースダイアログ内のデータソースアイテムのフィルタリングを可能にします。この機能により、ユーザーがどのデータオブジェクトに対してクライアントで表示が許可されているかを決定する、サーバー側セキュリティを設定する能力が向上します。

## **バグ修正**

また、パイチャート、グリッドのクラッシュ、データブレンドのエラーなど、すべてのプラットフォームでよりスムーズで信頼性の高い分析体験を確保するため、いくつかのバグに対処しました。完全なリストは以下の通りです。

- UIからエクスポートする際に、パイチャートとドーナツチャートが表示されない。

- 計算フィールドが依存している状態でデータブレンドを削除しても、計算フィールドは削除されない。

- RedshiftおよびPostgresで関数を呼び出すと、エラーメッセージが発生する可能性がある。

- コンテナまたは祖先要素に transform:scale スタイルを使用している場合のRevealViewの配置とサイズ。

- canAddDateFilter の設定が例外を引き起こした。

- ダッシュボードプロパティが null または undefined に設定されている場合、Save event args.isNew が false になる。

- ストアドプロシージャのパラメータ画面が、以前のデータや何も表示しないことがある。

- 検索バーを使用している場合に、ポップアップ要素でのスクロールが機能しない。

- スキャッターマップのインジケーターのホバー領域がズームでシフトする。

- クロロプレスマップのツールチップに分数桁が表示されない。

- 3000以上のフィルター値が保持されない。

- ポスト計算フィールドUIでピボットフィールドの名前が変更された場合のエラー。

- プレビューデータセルが再利用されず、複数回レンダリングされる。

- MacOS ARM64でグリッドがクラッシュする。

- 十分なスペースがあるにもかかわらず、パイチャートの凡例が消える。

- スライスチャートでホバーイベントが意図通りに動作しない。

- ピボットグリッドビジュアライゼーションで合計が表示されない。

- Analysis Servicesデータプロバイダーを使用している場合に、誤った合計値が表示される。

- Analysis Servicesデータプロバイダーを使用している場合に、ダッシュボードおよびビジュアライゼーションのフィルターで誤った合計値が表示される。

- ピボットグリッドで値を再配置した後、フィールド名が変更される。

- Analysis Servicesで「…hierarchy already appears in the Axis1 axis.」というエラーが発生する。

- Analysis Servicesで「上位N」フィルターを適用した場合に誤った結果となる。

- リソースベースのビジュアライゼーションが誤ったキャッシュエントリを取得する。

- ブレンディングを使用した場合に誤ったキャッシュエントリがヒットする。

- ブラウザがバックグラウンドに移動した後、検索ボックスにフォーカスを設定できない。
